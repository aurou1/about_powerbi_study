## 这份教程是什么

从「什么是复杂度」讲起，顺着「线性结构 → 哈希 → 递归分治 → 排序 → 二分 → 树 → 堆 → 图 → 动态规划 → 贪心回溯」一条主线，把面试和工程里最高频的数据结构与算法讲透。**每一段代码都本机实跑**，输出直接贴给你，不是「理论上应该这样」。

> ✍️ **手推图示版**：本套教程不只是给代码和结论——**每个概念的每个步骤都配了 ASCII 手推图示**（内存模型、节点指针改动、递归树展开、区间收缩、DP 表逐格填充、图遍历顺序…），照图能自己推一遍，小白也能看懂「为什么」。链条：概念 → 图示 → 代码 → 实跑 → 练习。

## 统一约定

- **复杂度写法**：`O(1)` 常数、`O(log n)` 对数、`O(n)` 线性、`O(n log n)`、`O(n²)` 平方、`O(2ⁿ)` 指数。默认分析「最坏情况 + 时间复杂度」，空间单独说明。
- **衡量标准**：所有「快不快」的结论，教程里都给你 `timeit` 实测秒数，不是嘴上说。
- **命名**：链表节点统一用 `Node(val, next)`；树节点统一用 `TreeNode(val, left, right)`。
- **动手原则**：每章末尾 5 题练习，**答案 + 解析 + 预期数字**全给，和前面三套教程一个标准。

## 故障速查

- **代码跑不出**：先确认用的是 venv 里的 python（路径见上），不是系统 python。
- **递归报 `RecursionError`**：Python 默认递归深度 1000，树/链表太深时改 `sys.setrecursionlimit(...)` 或改迭代写法。
- **计时结果和我贴的不一样**：不同机器 CPU 不同，秒数会有差异，**看的是「倍数关系」不是绝对值**（比如 O(n²) 比 O(n) 慢几十倍）。
- **想验证复杂度**：直接 copy 章节里的 `timeit` 片段改 `n` 跑。
