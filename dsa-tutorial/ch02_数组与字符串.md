# ch02 数组与字符串

> 学习目标：理解数组「随机访问」的本质；掌握双指针、滑动窗口、前缀和三个最高频技巧；能区分「字符」和「字符串」的处理差异。

## 一、数组是什么：连续内存 + 下标

数组（Python 里的 `list` 在概念上对应「动态数组」）最大的优点是：**按下标取元素 O(1)**。CPU 知道首地址，第 i 个 = 首地址 + i × 元素大小，直接算出来，不用一个个数。

代价：**中间插入/删除是 O(n)**（后面的元素要集体搬家）——这正是 ch01 实测头插比尾插慢的原因。

```python
a = [10, 20, 30, 40]
print(a[0], a[-1], a[1:3])     # 10 40 [20, 30]  都是 O(1) 或 O(k)
```

字符串是「字符的数组」，但 Python 里**字符串不可变**：想改其中一位，得先转 `list` 再拼回。

## 二、双指针（最高频）

两个指针从两端或同向走，把 O(n²) 降成 O(n)。

### 2.1 反转字符串（原地、双指针）

```python
def reverse_str(s):
    a = list(s)
    i, j = 0, len(a) - 1
    while i < j:
        a[i], a[j] = a[j], a[i]
        i += 1
        j -= 1
    return "".join(a)

print(reverse_str("ST-BD-42静音球"))
print("回文:", reverse_str("上海自来水来自海上") == "上海自来水来自海上")
```

**预期输出：**

```text
球音静24-DB-TS
回文: True
```

> 因为是「回文」，反转后和原串相等。**Manacher 等高级算法面试才考，日常判断回文用这招就够了。**

### 2.2 合并两个有序数组（从后往前填）

LeetCode 经典。给 `nums1` 留了足够空位，要求**原地**合并成有序。

```python
def merge_sorted(nums1, m, nums2, n):
    i, j, k = m - 1, n - 1, m + n - 1
    while i >= 0 and j >= 0:
        if nums1[i] > nums2[j]:
            nums1[k] = nums1[i]; i -= 1
        else:
            nums1[k] = nums2[j]; j -= 1
        k -= 1
    while j >= 0:          # nums1 用完了，剩余 nums2 直接搬
        nums1[k] = nums2[j]; j -= 1; k -= 1
    return nums1

print(merge_sorted([1, 3, 5, 0, 0, 0], 3, [2, 4, 6], 3))
```

**预期输出：**

```text
[1, 2, 3, 4, 5, 6]
```

> 诀窍：**从大往小填**，避免覆盖还没比的数。时间 O(m+n)，空间 O(1)。

## 三、滑动窗口（子数组/子串问题神器）

窗口在数组上「滑动」，用两个边界 `i, j` 维护一个区间。适合「最长/最短满足条件的连续子段」。

### 3.1 固定窗口：连续 k 个的最大和

```python
def max_sliding_window(arr, k):
    res = [sum(arr[i:i+k]) for i in range(len(arr) - k + 1)]
    return res, max(res)

arr = [1, 4, 2, 10, 23, 3, 1, 0, 20]
wins, mx = max_sliding_window(arr, 4)
print("窗口和(4):", wins, "最大:", mx)
```

**预期输出：**

```text
窗口和(4): [17, 39, 38, 37, 27, 24] 最大: 39
```

> 这种每次重算区间和其实 O(n·k)。更优写法用「左出右进」维护滚动和，O(n)（ch05 哈希后你会更熟）。本例 k 小，重算无妨。

### 3.2 可变窗口：最长无重复字符子串（长子串通用模板）

```python
def longest_unique(s):
    seen = {}
    left = 0
    best = 0
    for right, ch in enumerate(s):
        if ch in seen and seen[ch] >= left:
            left = seen[ch] + 1      # 收缩左边界到重复字符之后
        seen[ch] = right
        best = max(best, right - left + 1)
    return best

print(longest_unique("abcabcbb"), longest_unique("静音球球静音"))
```

**预期输出：**

```text
3 4
```

> `left` 是窗口左边界，`seen` 记每个字符最近出现位置。遇到重复就右移 `left`。这是「可变窗口」的标准骨架，后面很多题套它就对。

## 四、前缀和（区间求和 O(1)）

先花 O(n) 预处理一个「前缀和数组」，之后任意区间 `[i, j)` 的和 = `pre[j] - pre[i]`，O(1)。

```python
def prefix_sum(arr):
    pre = [0]
    for x in arr:
        pre.append(pre[-1] + x)
    return pre

pre = prefix_sum([1, 4, 2, 10, 23, 3])
print("前缀和:", pre)
print("区间[1,4)和 =", pre[4] - pre[1])   # arr[1]+arr[2]+arr[3]
```

**预期输出：**

```text
前缀和: [0, 1, 5, 7, 17, 40, 43]
区间[1,4)和 = 16
```

> SQL 教程里 `SUM(order_amount) OVER (ORDER BY date)` 就是「前缀和」的窗口函数版；ch10 的「区间和查询」也会回到这。

## 五、字符统计（哈希的雏形，正式版 ch05）

统计一个字符串里各字符出现次数，是「计数类」题目的基础。

```python
from collections import Counter
print(Counter("静音球静音球球"))   # Counter({'球': 4, '静': 2, '音': 2})
```

## 小结

- 数组优势是 O(1) 随机访问，劣势是中间增删 O(n)。
- 双指针、滑动窗口、前缀和 = 数组/字符串三大高频套路。
- 字符串不可变，要改先 `list()` 再 `join()`。
- 这些都是「线性扫描 O(n)」，比嵌套循环 O(n²) 快一个数量级。

## 练习

1. **（双指针）** 写 `is_palindrome(s)` 判断字符串是否回文（忽略非字母可先不做），用双指针从两端比。测 `"level"` 和 `"hello"`。
2. **（滑动窗口）** 把 3.1 改成「滚动和维护」，使复杂度降到 O(n)（不用切片 `arr[i:i+k]` 重算）。
3. **（前缀和）** 给定 `pre = prefix_sum([5, -2, 3, 1])`，手算 `pre` 数组，并写出区间 `[0,3)`（即前 3 个）的和怎么用 `pre` 求。
4. **（字符串）** `remove_dup_sorted` 是「有序数组去重」，若数组无序，用集合去重会丢失顺序，怎么既去重又保序？（提示：遍历 + 已见集合）
5. **（实战联想）** 你 `sql-tutorial` 里算「每个省销售合计」是哈希分组；数组版怎么用？用 `arr=[("广东",1200),("浙江",340),("广东",800)]` 写一个累积各省合计的字典。

**答案与解析**

1.
   ```python
   def is_palindrome(s):
       i, j = 0, len(s) - 1
       while i < j:
           if s[i] != s[j]: return False
           i += 1; j -= 1
       return True
   print(is_palindrome("level"), is_palindrome("hello"))   # True False
   ```
   时间 O(n)，空间 O(1)。
2.
   ```python
   def max_window_roll(arr, k):
       if len(arr) < k: return None
       cur = sum(arr[:k]); best = cur
       for i in range(k, len(arr)):
           cur += arr[i] - arr[i - k]   # 右进左出
           best = max(best, cur)
       return best
   print(max_window_roll([1,4,2,10,23,3,1,0,20], 4))   # 39
   ```
   每个元素进出窗口各一次 → O(n)。
3. `pre = [0,5,3,6,7]`；前 3 个 = `pre[3]-pre[0] = 6`。
4.
   ```python
   def dedupe_keep_order(a):
       seen = set(); out = []
       for x in a:
           if x not in seen:
               seen.add(x); out.append(x)
       return out
   print(dedupe_keep_order([3,1,3,2,1,4]))   # [3, 1, 2, 4]
   ```
   时间 O(n)，空间 O(n)（存已见集合）。
5.
   ```python
   totals = {}
   for prov, amt in [("广东",1200),("浙江",340),("广东",800)]:
       totals[prov] = totals.get(prov, 0) + amt
   print(totals)   # {'广东': 2000, '浙江': 340}
   ```
   这就是哈希分组，和 SQL 的 `GROUP BY province` 一个思想。
