# ch03 链表

> 学习目标：理解链表「用指针串节点」的内存结构，搞懂**为什么插入删除 O(1) 而查找 O(n)**；能手推并默写五大操作——**反转、找中点、判环、合并有序、删倒数第 N 个**。链表是面试最高频的数据结构，没有之一。

---

## 一、为什么需要链表：数组的痛

数组（Python list）插入中间要搬元素：

```
数组 [10, 20, 30, 40]，想在 index=1 处插 25:

插入前:  [10][20][30][40]
           ↑ 这里想插 25

步骤: 先把 40 挪到后面，再挪 30，再挪 20:
       [10][20][30][  ][40]
       [10][20][  ][30][40]
       [10][  ][20][30][40]
       [10][25][20][30][40]      ← 搬了 3 个元素 → O(n)
```
n 很大时，头插/中间插就是灾难（ch01 实测头插比尾插慢 76 倍）。

**链表的思路**：元素不再排排坐，而是**每个节点记住"下一个节点在哪"**，像一串珠子。插入时只需把两边的"线"改一下，不用搬任何数据。

## 二、链表的内存模型（配图）

```
数组 = 一整块连续内存:
地址:   100  104  108  112
       ┌────┬────┬────┬────┐
       │ 10 │ 20 │ 30 │ 40 │
       └────┴────┴────┴────┘
        一个挨一个，下标 i 直接算地址

链表 = 节点散落在内存各处，靠 next 指针串起来:
地址:   0x1A   0x7F   0x9C   0x2B
       ┌───┬──┐ ┌───┬──┐ ┌───┬──┐ ┌───┬──┐
       │10 │  ┼─▶│20 │  ┼─▶│30 │  ┼─▶│40 │∅│
       └───┴──┘ └───┴──┘ └───┴──┘ └───┴──┘
        val next   val next   val next   (None)
```
每个节点 = `值(val)` + `指针(next)`。**最后一个节点的 next 指向 None（∅）**。

> 链表找第 i 个元素：必须从头节点顺着 next 一个个跳 → O(n)。
> 链表插入/删除（已知位置）：只改旁边两个指针 → O(1)。

### 复杂度对照（背下来）

```
操作          数组         链表
随机访问 a[i]  O(1) ✅     O(n) ❌（要一个个跳）
头部插入      O(n) ❌      O(1) ✅（改两个指针）
尾部插入      O(1)摊还 ✅  O(1)（有尾指针）/O(n)（要找到尾）
中间插入      O(n) ❌      O(1)（已知前驱节点）✅
内存         连续、省     散落、每个节点多存一个指针
```

Python 实现：

```python
class Node:
    def __init__(self, val, nxt=None):
        self.val = val
        self.next = nxt          # 指向下一个节点（默认 None）

def build(vals):
    """把列表变成链表，返回头节点"""
    head = None
    for v in reversed(vals):     # 倒着挂，正序出来
        head = Node(v, head)
    return head

def to_list(head):
    """链表转回 Python 列表，方便打印看结果"""
    out = []
    while head:
        out.append(head.val)
        head = head.next         # 顺着指针走
    return out

h = build([1, 2, 3, 4, 5])
print(to_list(h))                # [1, 2, 3, 4, 5]
```
**预期输出：** `[1, 2, 3, 4, 5]`

## 三、手推图示：遍历链表

遍历 = 从头节点开始，`head = head.next` 一步步跳，直到 None。

```
遍历 build([1,2,3]) 的过程:
        ┌───┬──┐   ┌───┬──┐   ┌───┬──┐
head ──▶│ 1 │  ┼──▶│ 2 │  ┼──▶│ 3 │∅│
        └───┴──┘   └───┴──┘   └───┴──┘

第1步: head.val=1 → 收下; head=head.next
第2步: head.val=2 → 收下; head=head.next
第3步: head.val=3 → 收下; head=head.next → None
第4步: head 是 None → 结束
结果 [1, 2, 3]
```
> 铁律：**遍历链表时永远用 `while head:`（或 `while cur:`），千万别把 head 弄丢**——除非你像反转那样刻意用 prev 记录。

## 四、手推图示：反转链表（最重要的链表题）

题目：`1→2→3→4→5` 反成 `5→4→3→2→1`。

核心思想：**逐个把节点的 next 掉头指向前一个**。难点是：掉头之前必须先存好下一个，否则后半段就"断链"找不到了。

```
经典三指针法: prev(前一个) / cur(当前) / nxt(下一个)

初始:
      prev=None
        ┌───┬──┐   ┌───┬──┐   ┌───┬──┐   ┌───┬──┐   ┌───┬──┐
cur ──▶│ 1 │  ┼──▶│ 2 │  ┼──▶│ 3 │  ┼──▶│ 4 │  ┼──▶│ 5 │∅│
        └───┴──┘   └───┴──┘   └───┴──┘   └───┴──┘   └───┴──┘

每轮循环干三件事:  ① nxt = cur.next  （先存下一个，防断链）
                   ② cur.next = prev （掉头指向前一个）
                   ③ prev=cur; cur=nxt（整体右移一格）

第1轮(cur=1):  1.next 指向 prev(None)
        ┌───┬──┐   ┌───┬──┐   ┌───┬──┐   ┌───┬──┐   ┌───┬──┐
prev=1◀─│ 1 │  ┼   │ 2 │  ┼──▶│ 3 │  ┼──▶│ 4 │  ┼──▶│ 5 │∅│
        └───┴──┘   └───┴──┘   └───┴──┘   └───┴──┘   └───┴──┘
           ↑next已断，靠 nxt 还指着 2
第2轮(cur=2):  2.next → 1
        ┌───┬──┐   ┌───┬──┐   ┌───┬──┐   ┌───┬──┐   ┌───┬──┐
        │ 1 │◀──┼──│ 2 │  ┼   │ 3 │  ┼──▶│ 4 │  ┼──▶│ 5 │∅│
        └───┴──┘   └───┴──┘   └───┴──┘   └───┴──┘   └───┴──┘
第3轮(cur=3):  3.next → 2 …… 依此类推
第5轮(cur=5):  5.next → 4，cur 走完变 None → 结束
返回 prev（此时 prev=5）→ 5→4→3→2→1 ✅
```
```python
def reverse_list(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next        # ① 先存下一个（关键！防断链）
        cur.next = prev       # ② 掉头指向前一个
        prev, cur = cur, nxt  # ③ 双双右移
    return prev               # 循环结束 prev 就是新头

h = build([1, 2, 3, 4, 5])
print("反转:", to_list(reverse_list(h)))    # [5, 4, 3, 2, 1]
```
**预期输出：** `反转: [5, 4, 3, 2, 1]`
复杂度 O(n)（每个节点走一遍）、空间 O(1)。

> 为什么先存 `nxt`？因为 `cur.next = prev` 一执行，原来的 `cur→下一个` 就断了；不先存好，后半段链表就"丢了"。**三句顺序不能换。**

## 五、手推图示：找中点（快慢指针）

题目：`1→2→3→4→5` 的中点 = 3；`1→2→3→4` 的中点 = 3（偶数取偏右那个也行，看题目约定，这里慢指针停在 3）。

```
slow 每次走 1 格，fast 每次走 2 格 → fast 到终点时 slow 正好在一半

初始:       1        2        3        4        5
           slow
           fast

第1轮:     slow→2   fast→3   (fast 走了2格到3)
第2轮:     slow→3   fast→5   (fast 到5)
第3轮:     fast.next 是 None → 停
结果 slow = 3 ✅

图解:
链表:   1 → 2 → 3 → 4 → 5
slow:  ●   ●   ●            (每轮1格)
fast:  ●       ●       ●    (每轮2格, 先到终点)
```
```python
def middle_node(head):
    slow = fast = head
    while fast and fast.next:     # fast 能走两步才走
        slow = slow.next          # 慢的走 1 格
        fast = fast.next.next     # 快的走 2 格
    return slow.val

print("中点:", middle_node(build([1,2,3,4,5])))   # 3
print("中点:", middle_node(build([1,2,3,4])))     # 3
```
**预期输出：** `中点: 3` `中点: 3`
> 为什么偶数长度停在 3 而不是 2？因为 fast 从 head 出发，`[1,2,3,4]` 时 fast 能走 1→3、3 的 next 是 4、4 的 next 是 None → 第二轮 `fast.next.next` 前检查 `fast.next` 为 4（非空）→ 还能走 → slow 到 3。**边界以实跑为准**，面试把 fast 判断条件写对即可。

## 六、手推图示：判环（Floyd 快慢指针）

题目：`1→2→3→4→2`（4 又指回 2）→ 有环 True。

```
快慢指针同时从 head 出发:
  slow 每轮 +1，fast 每轮 +2
  如果有环 → 快指针最终会"追上"慢指针（两者相遇）
  如果无环 → 快指针先走到 None

有环例子:  1 → 2 → 3 → 4
                  ↑_______↓   (4.next → 2)

走位:  slow: 1,2,3,4,2,3,4,2...
       fast: 1,3,2,4,3,2,4,3...    → 在某节点相遇! → True

为什么必相遇（数学）:
  进入环后，把环看成跑道，slow 每轮跑1、fast 跑2
  → 每轮 fast 比 slow 多跑 1 格
  → 环长 L，最多 L 轮后 fast 追上 slow
  （就像绕圈跑，速度快一倍必追上）
```
```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next          # 1 步
        fast = fast.next.next     # 2 步
        if slow is fast:          # 追上了 → 有环
            return True
    return False                  # 走到头 → 无环

# 造环: 5 的 next 指回 3
h2 = build([1, 2, 3, 4, 5])
h2.next.next.next.next.next = h2.next.next   # 5→3
print("有环:", has_cycle(h2))                # True
print("无环:", has_cycle(build([1,2,3])))    # False
```
**预期输出：** `有环: True` `无环: False`
复杂度 O(n)（最多走一圈环长）、空间 O(1)。进阶：找环入口用「相遇后 head 和 slow 同速走，再相遇处即入口」（数学推导：入口前距离 a，环长 L，相遇点距入口 b，则 a ≡ 环内剩余，两者同速必在入口会合）。

## 七、手推图示：合并两个有序链表（哑节点技巧）

题目：`1→2→4` 与 `1→3→4` 合并成 `1→1→2→3→4→4`。

```
用哑节点(dummy)当"假头"，tail 负责串新链；每次取两个链表头较小的接上。

l1: 1 → 2 → 4
l2: 1 → 3 → 4

第1轮: 1≤1 → 接 l1 的1, l1→2        结果: d→1
第2轮: 2>1 → 接 l2 的1, l2→3        结果: d→1→1
第3轮: 2≤3 → 接 l1 的2, l1→4        结果: d→1→1→2
第4轮: 4>3 → 接 l2 的3, l2→4        结果: d→1→1→2→3
第5轮: 4≤4 → 接 l1 的4, l1 空        结果: d→1→1→2→3→4
第6轮: l2 还剩 4 → 整段接上           结果: d→1→1→2→3→4→4
返回 dummy.next

图形（每轮取小的）:
l1: ①→②→④            l1: ②→④
l2: ①→③→④   →取①      l2: ①→③→④
out: ①
```
```python
def merge_two_lists(a, b):
    dummy = tail = Node(0)        # 哑节点：避免处理"空头"特例
    while a and b:
        if a.val <= b.val:
            tail.next = a
            a = a.next
        else:
            tail.next = b
            b = b.next
        tail = tail.next
    tail.next = a or b            # 剩下的整段接上
    return dummy.next

print("合并:", to_list(merge_two_lists(build([1,2,4]), build([1,3,4]))))
```
**预期输出：** `合并: [1, 1, 2, 3, 4, 4]`
复杂度 O(n+m)。哑节点 `dummy` 是链表题神器——**凡是"可能改头"的操作，先挂个假头就不用特判**。

## 八、手推图示：删除倒数第 N 个（双指针 + 哑节点）

题目：`1→2→3→4→5` 删倒数第 2 个（=4）→ `1→2→3→5`。

```
思路: fast 先走 n+1 步，然后 fast/slow 同步走
      → fast 到终点 None 时，slow 恰好停在"要删节点的前一个"

dummy→1→2→3→4→5→None     n=2

第1步: fast 先走 3 步 (n+1=3):  fast 停在 3
第2步: fast/slow 一起走:
       fast: 3→4→5→None (再走3步到终点)
       slow: d→1→2→3      (同步走3步, 停在3)
第3步: 删 slow.next(4): slow.next = slow.next.next
结果: dummy→1→2→3→5 ✅

图示:
dummy → 1 → 2 → 3 → 4 → 5 → None
              slow ↑     ↑ fast(先走3格)
  一起走到:   slow=3, fast=None
              slow.next 是 4 → 跳过它 → 3 直接接 5
```
```python
def remove_nth_from_end(head, n):
    dummy = Node(0, head)         # 哑节点（可能删的就是头）
    fast = slow = dummy
    for _ in range(n + 1):        # fast 先走 n+1 步
        fast = fast.next
    while fast:                   # 一起走到 fast 到底
        fast = fast.next
        slow = slow.next
    slow.next = slow.next.next    # 跳过要删的节点
    return dummy.next

print("删倒数第2:", to_list(remove_nth_from_end(build([1,2,3,4,5]), 2)))
```
**预期输出：** `删倒数第2: [1, 2, 3, 5]`
> 为什么 fast 走 n+1 而不是 n？因为要让 slow 停在**被删节点的前一个**（这样才能 `slow.next = slow.next.next`）。删头的情况（n=链表长）fast 先走到 None，slow 还在 dummy，一样能正确处理。

## 九、综合：回文链表（找中点 + 反转后半）

题目：`1→2→2→1` → True；`1→2` → False。

```
三步: ① 快慢找中点  ② 反转后半段  ③ 逐个比较前半/后半

1→2→2→1    找中点 slow=2(第二个2的位置, 看实现)
反转后半:   1→2  vs  1→2(反转后)  → 逐位相等 → True

手推: 原链: 1 → 2 → 2 → 1
      反转后半(从中间断开): 前半 1→2，后半反转 1→2
      比较: 1==1, 2==2 → True ✅
```
```python
def is_palindrome(head):
    vals = []                     # 简单做法: 全部读出来再比较
    while head:
        vals.append(head.val)
        head = head.next
    return vals == vals[::-1]

print("回文:", is_palindrome(build([1,2,2,1])))    # True
print("回文:", is_palindrome(build([1,2])))        # False
```
**预期输出：** `回文: True` `回文: False`
（进阶 O(1) 空间版 = 快慢找中点 + 反转后半 + 比较，正是上面三个技巧的组合。）

## 十、链表操作速查表

```
操作             核心技巧             复杂度
遍历             while head 顺 next     O(n)
反转             三指针 prev/cur/nxt     O(n)
找中点           快慢指针 slow+1 fast+2  O(n)
判环             Floyd 快慢相遇          O(n)
找环入口         相遇后 head+slow 同速    O(n)
合并有序         哑节点 + 取小            O(n+m)
删倒数第N        快指针先走 n+1          O(n)
删头/插头        哑节点 dummy            O(1)
```

## 十一、小结

1. 链表 = 节点散落 + `next` 指针串接；**插删 O(1)、随机访问 O(n)**
2. 遍历/构建用 `while head`，`head = head.next` 前进
3. **反转三指针**：先存 `nxt` → 掉头 → 右移；顺序不能乱
4. **快慢指针**是链表题的瑞士军刀：找中点、判环都靠它
5. Floyd 判环：fast 每轮多跑 1 格，环内必追上
6. **哑节点** dummy：处理"可能改头/删头"的操作免特判
7. 删倒数第 N：fast 先走 n+1 步，让 slow 停在目标前一个

## 十二、练习 5 题

### 练习 1：两两交换相邻节点

`1→2→3→4` → `2→1→4→3`。

**答案：**
```python
def swap_pairs(head):
    dummy = Node(0, head)
    cur = dummy
    while cur.next and cur.next.next:
        a = cur.next          # 第一个
        b = cur.next.next     # 第二个
        a.next = b.next       # 1 → 3
        b.next = a            # 2 → 1
        cur.next = b          # dummy → 2
        cur = a               # 下一轮从 1 开始
    return dummy.next

print("两两交换:", to_list(swap_pairs(build([1,2,3,4]))))    # [2,1,4,3]
```
**预期输出：** `两两交换: [2, 1, 4, 3]`
**解析**：画图最清楚。dummy 让头交换也统一处理；每轮把 `a→b` 改成 `dummy/前驱→b→a→(b原来的next)`。三个指针重连顺序：`a.next=b.next` → `b.next=a` → `cur.next=b`。

### 练习 2：链表中倒数第 k 个节点

`1→2→3→4→5`，倒数第 2 个 = 4（不是删除，只返回值）。

**答案：** 快指针先走 k 步，再同步走到头：
```python
def kth_from_end(head, k):
    fast = slow = head
    for _ in range(k):            # fast 先走 k 步
        if not fast: return None  # k 超长
        fast = fast.next
    while fast:                   # 同步走到 fast 到头
        fast = fast.next
        slow = slow.next
    return slow.val

print("倒数第2:", kth_from_end(build([1,2,3,4,5]), 2))    # 4
```
**预期输出：** `倒数第2: 4`
**解析**：fast 先走 k 步后，slow 与 fast 相距 k——fast 到终点时 slow 正好在倒数第 k 个。与"删倒数第 N"的差别：那个要让 slow 停在**前一个**（fast 走 n+1），这个要停在**本身**（fast 走 n）。

### 练习 3：删除排序链表的重复元素

`1→1→2→3→3` → `1→2→3`。

**答案：**
```python
def delete_duplicates(head):
    cur = head
    while cur and cur.next:
        if cur.val == cur.next.val:
            cur.next = cur.next.next     # 跳过重复的
        else:
            cur = cur.next               # 不同才前进
    return head

print("去重:", to_list(delete_duplicates(build([1,1,2,3,3]))))   # [1,2,3]
```
**预期输出：** `去重: [1, 2, 3]`
**解析**：链已排序 → 重复必相邻。发现 `cur.val == cur.next.val` 就 `cur.next = cur.next.next`（删除后**不移动 cur**，因为可能还有连续重复）；不同才 `cur = cur.next`。

### 练习 4：链表求和（两数相加，注意进位）

`2→4→3`（=342）加 `5→6→4`（=465）→ 7→0→8（=807）。数字按位反着存。

**答案：**
```python
def add_two(a, b):
    dummy = tail = Node(0)
    carry = 0
    while a or b or carry:
        v = carry
        if a: v += a.val; a = a.next
        if b: v += b.val; b = b.next
        carry, v = divmod(v, 10)      # v 可能 ≥10
        tail.next = Node(v)
        tail = tail.next
    return dummy.next

print("求和:", to_list(add_two(build([2,4,3]), build([5,6,4]))))   # [7,0,8]
```
**预期输出：** `求和: [7, 0, 8]`
**解析**：342+465=807 → 反着存正好从个位开始加，天然从左到右处理。`while a or b or carry` 处理"一个链更长 / 最后还有进位"两种情况（如 9+1 → 0 进位 1）。手推：2+5=7 进0；4+6=10 进1留0；3+4+1=8 进0 → [7,0,8] ✅。

### 练习 5：旋转链表（综合）

`1→2→3→4→5`，右移 2 → `4→5→1→2→3`。

**答案：**
```python
def rotate_right(head, k):
    if not head: return None
    n, tail = 1, head
    while tail.next:              # 先数长度，并记住尾节点
        tail = tail.next
        n += 1
    k %= n                        # k 可能比 n 大
    if k == 0: return head
    tail.next = head              # 先首尾相连成环
    for _ in range(n - k - 1):    # 走到新链表的尾
        head = head.next
    new_head = head.next          # 断开点之后是新头
    head.next = None              # 断开
    return new_head

print("右移2:", to_list(rotate_right(build([1,2,3,4,5]), 2)))   # [4,5,1,2,3]
```
**预期输出：** `右移2: [4, 5, 1, 2, 3]`
**解析**：三步——数长度并成环 → 算真正位移 `k%=n` → 走 `n-k-1` 步找到新尾断开。手推 n=5,k=2：新尾在 3（下标 n-k-1=2），3.next=4 是新头 → `[4,5,1,2,3]`。**成环再断环**是旋转类题目的通用解。
