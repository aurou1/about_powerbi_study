# ch03 链表

> 学习目标：理解链表「用指针串起来」的结构；能手写反转、找中点、测环、合并有序链表；明白它和数组的取舍。

## 一、为什么需要链表

数组的痛点：中间插入/删除要搬元素（O(n)）。**链表**把元素（节点）散落在内存各处，每个节点记「下一个节点在哪」，插入删除只改几个指针，**O(1)**。

代价：不能随机访问，想找第 i 个只能从头数（O(n)）。

```python
class Node:
    def __init__(self, val, nxt=None):
        self.val = val
        self.next = nxt

    def __repr__(self):
        return f"Node({self.val})"

def build(vals):
    """把列表变成链表，返回头节点"""
    head = None
    for v in reversed(vals):        # 倒着挂，正序出来
        head = Node(v, head)
    return head

def to_list(head):
    """链表转回 Python 列表，方便打印"""
    out = []
    while head:
        out.append(head.val)
        head = head.next
    return out

h = build([1, 2, 3, 4, 5])
print(to_list(h))
```

**预期输出：**

```text
[1, 2, 3, 4, 5]
```

## 二、反转链表（面试出现率第一）

### 2.1 迭代法（改指针方向）

三个指针：`prev`（已反转部分的头）、`head`（当前）、`nxt`（暂存下一个）。

```python
def reverse_iter(head):
    prev = None
    while head:
        nxt = head.next      # 先存下一个
        head.next = prev     # 当前指向前一个
        prev = head          # prev 前移
        head = nxt           # head 前移
    return prev              # 新的头
```

### 2.2 递归法（更短但吃递归栈）

```python
def reverse_rec(head, prev=None):
    if not head:
        return prev
    nxt = head.next
    head.next = prev
    return reverse_rec(nxt, head)
```

```python
print("迭代反转:", to_list(reverse_iter(build([1, 2, 3, 4, 5]))))
print("递归反转:", to_list(reverse_rec(build([1, 2, 3, 4, 5]))))
```

**预期输出：**

```text
迭代反转: [5, 4, 3, 2, 1]
递归反转: [5, 4, 3, 2, 1]
```

> 递归版代码漂亮，但 n 很大时递归深度 = 节点数，可能 `RecursionError`（ch01 提过）。工程上**迭代版更稳**。

## 三、快慢指针（链表专属技巧）

慢指针一次走 1 步，快指针一次走 2 步。这个「速度差」能解一堆题。

### 3.1 找中间节点

快指针到尾时，慢指针正好在中点。

```python
def middle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow.val

print("中间节点:", middle(build([1, 2, 3, 4, 5])), "| 偶数:", middle(build([1, 2, 3, 4])))
```

**预期输出：**

```text
中间节点: 3 | 偶数: 3
```

> 奇数 5 个取第 3 个；偶数 4 个取「后半段第一个」（第 3 个）。归并排序（ch07）要用它把链表切两半。

### 3.2 环检测（Floyd 判圈）

如果有环，快指针终会套圈追上慢指针。

```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

def make_cycle(vals, pos):
    """pos>=0 则尾连到第 pos 个节点，制造环"""
    head = build(vals)
    if pos < 0:
        return head
    tail = head
    while tail.next:
        tail = tail.next
    join = head
    for _ in range(pos):
        join = join.next
    tail.next = join
    return head

print("有环:", has_cycle(make_cycle([3, 2, 0, -4], 1)), "| 无环:", has_cycle(make_cycle([1, 2], -1)))
```

**预期输出：**

```text
有环: True | 无环: False
```

> `is` 比较「是不是同一个对象」（内存地址），比 `==` 更准——这里要的是「追上同一个节点」。

## 四、合并两个有序链表

和 ch02 的合并数组同理，但用指针串。

```python
def merge_lists(l1, l2):
    dummy = Node(0)          # 哨兵节点，省去判空
    cur = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1; l1 = l1.next
        else:
            cur.next = l2; l2 = l2.next
        cur = cur.next
    cur.next = l1 or l2      # 谁剩接谁
    return dummy.next

print("合并 [1,2,4]+[1,3,4]:", to_list(merge_lists(build([1, 2, 4]), build([1, 3, 4]))))
```

**预期输出：**

```text
合并 [1,2,4]+[1,3,4]: [1, 1, 2, 3, 4, 4]
```

> `dummy` 哨兵是链表题标配：不用单独处理「头节点为空」的分支，最后返回 `dummy.next`。

## 五、数组 vs 链表：怎么选

| 操作 | 数组 `list` | 链表 |
|---|---|---|
| 按下标访问 | O(1) | O(n) |
| 头部插入/删除 | O(n) | O(1) |
| 尾部插入 | O(1) 均摊 | O(n)（无尾指针时） |
| 中间插入/删除 | O(n) | O(1)（已知位置） |
| 内存 | 连续，缓存友好 | 零散，每个节点多存指针 |

> 实际工程：**90% 情况用数组就够了**（Python list 底层是动态数组，尾部操作为主时很快）。链表常见于「频繁在头部增删」的场景：如队列、LRU 缓存（ch05）、图的邻接表（ch11）。

## 小结

- 链表 = 节点 + 指针，插入删除 O(1)，访问 O(n)。
- 反转、快慢指针、环检测、合并有序链表 = 链表四件套，务必能手写。
- `dummy` 哨兵节点让代码更干净。
- ch01 练习 5 的答案：反转链表可原地改指针，空间 O(1)。

5. **（实战联想）** 你 `python-tutorial` 里算过「去重保序」。若数据存成链表且不能开额外数组，怎么去重？（提示：双指针，一个慢一个快，快遇到重复就跳过）

**答案与解析**

1.
   ```python
   def length(head):
       n = 0
       while head: n += 1; head = head.next
       return n
   print(length(build([10,20,30])))   # 3
   ```
   O(n)。
2. 思路：先走到第 m-1 个节点作「前驱」，对 [m, n] 区间用 ch02 的反转指针法反转，再把前驱接回。细节较多，建议学完 ch06 递归再写。核心仍是「改 `next` 方向」。
3.
   ```python
   def remove_val(head, val):
       dummy = Node(0, head)
       cur = dummy
       while cur.next:
           if cur.next.val == val:
               cur.next = cur.next.next   # 跳过
           else:
               cur = cur.next
       return dummy.next
   print(to_list(remove_val(build([1,2,2,3,2]), 2)))   # [1, 3]
   ```
   用 dummy 统一处理「头节点就是要删的」情况。
4. 设头到入口距离 a，入口到相遇 b，环长 c。快慢相遇时 `2(a+b)=a+b+k·c` → `a+b=k·c`。让一指针从 head 走 a 步、另一从相遇点同速走，会在入口重逢。
   ```python
   def get_cycle_start(head):
       slow = fast = head
       while fast and fast.next:
           slow = slow.next; fast = fast.next.next
           if slow is fast: break
       if not fast or not fast.next: return None
       slow = head
       while slow is not fast:
           slow = slow.next; fast = fast.next
       return slow.val
   ```
5.
   ```python
   def dedupe_list(head):
       seen = set()
       dummy = Node(0, head); cur = dummy
       while cur.next:
           if cur.next.val in seen:
               cur.next = cur.next.next
           else:
               seen.add(cur.next.val); cur = cur.next
       return dummy.next
   ```
   用了集合判重，仍 O(n) 时间，O(n) 空间。真正的「零额外空间」去重要排序或哈希，链表不常这么干。
