# ch04 栈与队列

> 学习目标：搞懂栈（后进先出）和队列（先进先出）的区别；能手写括号匹配、用栈实现队列、单调栈、滑动窗口最大值；明白 BFS 为什么用队列。

## 一、栈（Stack）：后进先出 LIFO

像一摞盘子，只能从顶上放/取。操作：`push`（压栈）、`pop`（弹栈）、`peek`（看顶，不弹）。

```python
st = []
st.append(1); st.append(2); st.append(3)   # push
print(st.pop())        # 3  ← 最后进的先出
print(st[-1])          # 2  ← peek
```

### 1.1 括号匹配（栈的经典应用）

遇到左括号压栈，遇到右括号看栈顶是不是配对的左括号。最后栈空才合法。

```python
def is_valid(s):
    st = []
    pair = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            st.append(ch)
        elif ch in pair:
            if not st or st.pop() != pair[ch]:
                return False
    return not st

print("()[]{}:", is_valid("()[]{}"), "| ({)}:", is_valid("({)}"), "| []:", is_valid("[]"))
```

**预期输出：**

```text
()[]{}: True | ({)}: False | []: True
```

> `({)}` 错在：遇到 `)` 时栈顶是 `(`...等等实际栈顶是 `{`（因为 `[` 之后压了 `{`），不匹配 → False。栈完美捕捉「顺序错乱」。

### 1.2 用栈实现队列（面试常考）

队列是先进先出，但栈只能后进先出。用**两个栈**玩个花样：

```python
class MyQueue:
    def __init__(self):
        self.in_stack = []
        self.out_stack = []
    def push(self, x):
        self.in_stack.append(x)
    def _move(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
    def pop(self):
        self._move(); return self.out_stack.pop()
    def peek(self):
        self._move(); return self.out_stack[-1]
    def empty(self):
        return not self.in_stack and not self.out_stack

q = MyQueue()
for v in [1, 2, 3]: q.push(v)
print("队列 pop:", q.pop(), "peek:", q.peek(), "pop:", q.pop())
```

**预期输出：**

```text
队列 pop: 1 peek: 2 pop: 2
```

> 诀窍：`in_stack` 管进，`out_stack` 管出。出栈空了，就把进栈整体倒过来——倒一次顺序就对了。**均摊**每个元素只搬一次，整体 O(1)。

## 二、单调栈（进阶但极高频）

栈里的元素保持「单调递增」或「单调递减」。用来快速找「左边/右边第一个比它大/小的元素」。

### 2.1 下一个更大元素

```python
def next_greater(arr):
    res = [-1] * len(arr)
    st = []
    for i, x in enumerate(arr):
        while st and arr[st[-1]] < x:     # 当前比栈顶大，栈顶找到了
            j = st.pop()
            res[j] = x
        st.append(i)
    return res

print("下一个更大 [2,1,2,4,3]:", next_greater([2, 1, 2, 4, 3]))
```

**预期输出：**

```text
下一个更大 [2,1,2,4,3]: [4, 2, 4, -1, -1]
```

> 过程：栈里始终「从底到顶递增」。遇到 4 时，把栈里比它小的 2、1、2 全弹出并填上 4。时间 O(n)（每个元素进出栈各一次）。

### 2.2 每日温度（需等几天才升温）

同一个套路，算「距离」而不是「值」。

```python
def daily_temperatures(temps):
    res = [0] * len(temps)
    st = []
    for i, t in enumerate(temps):
        while st and temps[st[-1]] < t:
            j = st.pop()
            res[j] = i - j
        st.append(i)
    return res

print("每日温度 [73,74,75,71,69,72,76,73]:", daily_temperatures([73, 74, 75, 71, 69, 72, 76, 73]))
```

**预期输出：**

```text
每日温度 [73,74,75,71,69,72,76,73]: [1, 1, 4, 2, 1, 1, 0, 0]
```

> 第 0 天 73°，第 1 天 74° 就升了 → 等 1 天；第 2 天 75° 之后要等 4 天到第 6 天 76° 才升 → 4。这是个**真实业务题**（库存/排期常算「还要几天」）。

## 三、队列与双端队列（deque）

Python 用 `collections.deque` 实现双端队列，两端进出都是 O(1)（普通 list 头部操作是 O(n)）。

### 3.1 滑动窗口最大值

维护一个「存下标的递减双端队列」，队首永远是窗口最大值的下标。

```python
from collections import deque

def max_sliding_window(arr, k):
    dq = deque()
    res = []
    for i, x in enumerate(arr):
        while dq and arr[dq[-1]] <= x:
            dq.pop()                 # 小的都踢掉（永远进不了队首了）
        dq.append(i)
        if dq[0] <= i - k:           # 队首滑出窗口，扔掉
            dq.popleft()
        if i >= k - 1:
            res.append(arr[dq[0]])
    return res

print("窗口最大 [1,3,-1,-3,5,3,6,7] k=3:", max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3))
```

**预期输出：**

```text
窗口最大 [1,3,-1,-3,5,3,6,7] k=3: [3, 3, 5, 5, 6, 7]
```

> 每个元素进出队各一次，O(n)。这比 ch02 里「每窗口重算和」的 O(n·k) 强太多——**单调队列是滑动窗口类题的标配**。

## 四、队列驱动 BFS（图/树层序遍历的底层）

队列「先进先出」的特性，天然适合**一层一层扩散**（广度优先搜索）。先放一层的节点，处理时把下一层节点加进队尾。

```python
# 层序遍历二叉树（TreeNode 见 ch09，这里先用列表模拟「孩子」）
def bfs_levels(graph, start):
    seen = {start}
    q = deque([start])
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nxt in graph.get(node, []):
            if nxt not in seen:
                seen.add(nxt)
                q.append(nxt)
    return order

graph = {0: [1, 2], 1: [3, 4], 2: [5], 3: [], 4: [], 5: []}
print("BFS 顺序:", bfs_levels(graph, 0))
```

**预期输出：**

```text
BFS 顺序: [0, 1, 2, 3, 4, 5]
```

> 队列保证「先发现的先处理」，于是 0 的孩子们（1,2）一定在 1 的孩子们（3,4）之前。这就是 ch11 图的 BFS 骨架。

## 小结

- 栈 LIFO（括号匹配、撤销、DFS）；队列 FIFO（BFS、缓冲、排队）。
- 单调栈 = 「找左右第一个更大/更小」，O(n) 神器。
- 双端队列 `deque` 两端 O(1)，滑动窗口最大值用它。
- 用栈实现队列、用两个栈倒一次就能反过来。

1.
   ```python
   def eval_postfix(s):
       st = []
       for tok in s.split():
           if tok.isdigit():
               st.append(int(tok))
           else:
               b, a = st.pop(), st.pop()
               st.append({'+': a+b, '-': a-b, '*': a*b, '/': a//b}[tok])
       return st.pop()
   print(eval_postfix("3 4 + 2 *"))   # 14
   ```
2.
   ```python
   class MinStack:
       def __init__(self): self.st = []
       def push(self, x): self.st.append((x, min(x, self.st[-1][1] if self.st else x)))
       def pop(self): self.st.pop()
       def top(self): return self.st[-1][0]
       def getMin(self): return self.st[-1][1]
   ```
   每个元素附带「入栈时的最小值」，弹出不影响。
3.
   ```python
   def prev_smaller(arr):
       res = [-1]*len(arr); st = []
       for i, x in enumerate(arr):
           while st and arr[st[-1]] >= x: st.pop()
           res[i] = arr[st[-1]] if st else -1
           st.append(i)
       return res
   print(prev_smaller([2,1,2,4,3]))   # [-1, -1, 1, 2, 2]
   ```
4.
   ```python
   from collections import deque
   hist = deque(maxlen=3)
   for x in "abcd": hist.append(x)
   print(list(hist))   # ['b', 'c', 'd']
   ```
   `deque(maxlen=3)` 自动丢最老。
