## 一、栈：后进先出（LIFO）

栈就像一摞盘子：**只能从最上面拿、只能往最上面放**。

```
push 3 → push 1 → push 2 → pop() 拿到谁？
                                              top
   │   │         │ 2 │         │ 2 │   pop →  │   │  ← 拿到 2（最后放的）
   │   │  push1  │ 1 │  push2  │ 1 │          │ 1 │
   │ 3 │         │ 3 │         │ 3 │          │ 3 │
   └───┘         └───┘         └───┘          └───┘
  空栈           [3]           [3,1,2]        [3,1]
```

```
操作图:
push(x): 把 x 放到栈顶        O(1)
pop():   取走栈顶元素          O(1)
top():   看栈顶（不拿走）      O(1)
empty(): 是否为空             O(1)
```

Python 里直接用 list 模拟栈（append=push, pop=pop, [-1]=top）。

## 二、手推图示：括号匹配（栈的经典应用）

题目：判断 `"()[]{}"` 是否合法、`"([)]"` 是否非法。

规则：**左括号入栈，遇到右括号就弹出栈顶比对**——最近未匹配的左括号必须和它配对。

```
输入 "()[]{}":

读 '(' → 入栈:  [ ( ]
读 ')' → 栈顶是 '(' 配对! → 弹出:  [ ]
读 '[' → 入栈:  [ [ ]
读 ']' → 栈顶是 '[' 配对! → 弹出:  [ ]
读 '{' → 入栈:  [ { ]
读 '}' → 栈顶是 '{' 配对! → 弹出:  [ ]
结束时栈空 → 合法 ✅

───── 反例 "([)]" ─────
读 '(' → [ ( ]
读 '[' → [ ( [ ]
读 ')' → 栈顶是 '[' ≠ '(' !!! → 非法 ❌
（画图看: ( [ ) ] 交叉嵌套，'[' 还没等到自己的 ']' 就被 ')' 抢走了）
```

```python
def is_valid(s):
    st = []
    pair = {')':'(', ']':'[', '}':'{'}   # 右括号 → 应配对的左括号
    for ch in s:
        if ch in '([{':          # 左括号入栈
            st.append(ch)
        else:                    # 右括号
            if not st or st[-1] != pair[ch]:
                return False     # 栈空(没得配) 或 栈顶不配对
            st.pop()             # 配对成功弹出
    return not st                # 全配完且栈空才算合法

print(is_valid("()[]{}"))   # True
print(is_valid("([)]"))     # False
print(is_valid("(]"))       # False
print(is_valid("((()))"))   # True
```
**预期输出：** `True False False True`

> 为什么"栈"正合适？因为括号匹配本质是**就近配对**：最近一个未匹配的左括号最先被匹配——正好是后进先出。这就是"看到嵌套/最近配对问题想栈"的直觉。

## 三、手推图示：最小栈（空间换时间）

题目：要一个栈，除了 push/pop/top，还能 **O(1) 返回最小值**。

难点：pop 掉最小值后，次小值从哪来？——再开一个"最小值栈"，每个状态都记录当时的 min。

```
操作序列         主栈 st      辅助 min 栈        getMin()
push 3           [3]          [3]              3
push 1           [3,1]        [3,1]   ← 1<3    1
push 2           [3,1,2]      [3,1]   ← 2>1 不压  1
pop  (弹2)       [3,1]        [3,1]            1
push 0           [3,1,0]      [3,1,0] ← 0<1    0
pop (弹0)        [3,1]        [3,1]            1

规律: min 栈只记录"更小的新低点"，高度和主栈错位也没关系
     取 min 永远看 min 栈顶
```
```python
class MinStack:
    def __init__(self):
        self.st = []
        self.mins = []          # 每个元素入栈时的"当时最小值"
    def push(self, x):
        self.st.append(x)
        cur_min = x if not self.mins else min(x, self.mins[-1])
        self.mins.append(cur_min)
    def pop(self):
        self.st.pop(); self.mins.pop()
    def top(self):
        return self.st[-1]
    def getMin(self):
        return self.mins[-1]

ms = MinStack()
for x in [3, 1, 2]: ms.push(x)
print("top:", ms.top(), "min:", ms.getMin())   # top: 2 min: 1
ms.pop()
print("after pop -> min:", ms.getMin())        # after pop -> min: 1
ms.push(0)
print("after push0 -> min:", ms.getMin())      # after push0 -> min: 0
```
**预期输出：**
```
top: 2 min: 1
after pop -> min: 1
after push0 -> min: 0
```
复杂度：所有操作 O(1)，空间 O(n)（多一个 min 栈，空间换时间）。

## 四、手推图示：单调栈 —— 下一个更大元素

单调栈 = **栈内元素保持单调**（递增或递减）。专治：「每个元素右边第一个比它大/小的元素」。

题目：每日温度 `[73,74,75,71,69,72,76,73]`，问每个温度要等几天才出现更高的温度？输出 `[1,1,4,2,1,1,0,0]`。

核心思想：**栈里存"还没找到答案的下标"，且从栈底到栈顶温度递减**（单调递减栈）。新来的温度更高 → 它就是栈顶那些"矮个子"的答案，逐个弹出结算。

```
过程（栈存下标，下面写温度方便看）:

i=0 t=73: 栈空 → 入栈 [73]
i=1 t=74: 74>73 → 弹73，ans[0]=1-0=1；入栈 [74]
i=2 t=75: 75>74 → 弹74，ans[1]=1；   入栈 [75]
i=3 t=71: 71<75 → 直接入栈 [75,71]
i=4 t=69: 69<71 → 入栈 [75,71,69]
i=5 t=72: 72>69 → 弹69，ans[4]=5-4=1
          72>71 → 弹71，ans[3]=5-3=2
          72<75 → 停，入栈 [75,72]
i=6 t=76: 76>72 → 弹72，ans[5]=1
          76>75 → 弹75，ans[2]=6-2=4
          栈空 → 入栈 [76]
i=7 t=73: 73<76 → 入栈 [76,73]
结束: 栈里剩 76(下标6)、73(下标7) 没有更高温度 → ans=0

ans = [1, 1, 4, 2, 1, 1, 0, 0] ✅

图形（为什么栈单调递减）:
温度轴:  73  74  75  71  69  72  76  73
                    ┌──────────┐
                    │75        │
              74    │  │  71   │
         73    │    │  │ 69│72 │   76
栈只保留"还没结算的"，而且它们从底到顶必须越来越矮，
一旦来个更高的，矮的全被"结算弹走"——每个元素最多进出栈一次 → O(n)
```
```python
def daily_temps(t):
    n = len(t)
    ans = [0] * n
    st = []                       # 存下标，温度从底到顶递减
    for i, x in enumerate(t):
        while st and t[st[-1]] < x:   # 栈顶温度 < 当前: 结算
            j = st.pop()
            ans[j] = i - j            # 等了 (i-j) 天
        st.append(i)
    return ans

print(daily_temps([73,74,75,71,69,72,76,73]))
```
**预期输出：** `[1, 1, 4, 2, 1, 1, 0, 0]`

> 为什么暴力是 O(n²)？每个 i 都往后找更高 → 两重循环。为什么单调栈是 O(n)？**每个元素只入栈一次、只出栈一次**，总操作 ≤ 2n。这是"用栈记住历史、避免回头"的典范。

## 五、手推图示：单调栈应用 —— 接雨水

题目：`[0,1,0,2,1,0,1,3,2,1,2,1]` 表示柱子高度，问能接多少雨水 → 6。

单调栈做法：**维护递减栈。当前柱子比栈顶高时，说明栈顶是个"坑底"，能算出它上面接的水。**

```
图形（柱子）:
        ■
    ■   ■ ■   ■
■   ■ ■ ■ ■ ■ ■ ■
0 1 0 2 1 0 1 3 2 1 2 1
    ↑   ↑   ↑   ↑
  左边 坑底 右边 ← 能接水的三件套

单调栈视角（遇更高柱子就结算坑）:
i=2 (t=0): 栈 [1,2]，此时来 2>0 → 坑底=0(下标2)
           左墙=下标1(高度1)，右墙=当前(高度2)
           接水 = (min(1,2)-0) × (2-1-1) = 0    ← 中间没空位
i=4 (t=1): 1>0 坑底0，左墙1，右墙1
           水 = (min(1,1)-0)×(4-2-1) = 1×1 = 1  ✅ 第1格水
...
累加所有"坑"的容量 = 6
```
```python
def trap(h):
    st = []          # 递减栈存下标
    ans = 0
    for i, x in enumerate(h):
        while st and h[st[-1]] < x:   # 出现右墙，结算坑底
            bot = st.pop()            # 坑底（最低那根）
            if not st: break          # 左边没墙了，接不住
            left = st[-1]             # 左墙
            ans += (min(h[left], x) - h[bot]) * (i - left - 1)
        st.append(i)
    return ans

print(trap([0,1,0,2,1,0,1,3,2,1,2,1]))
```
**预期输出：** `6`
复杂度：每根柱子进出栈各一次 → **O(n)、空间 O(n)**。

## 六、队列：先进先出（FIFO）

队列像排队买饭：**先来的先服务**。Python 里用 `collections.deque`（双端队列，两头都能 O(1) 增删）。

```
   tail ←──── head
   (队尾进)    (队头出)
   enqueue 1 → enqueue 2 → enqueue 3 → dequeue 拿到 1

   ┌────┬────┬────┐
   │ 3  │ 2  │ 1  │    ← 1 最先入队，也最先出队
   └────┴────┴────┘
   enqueue  → 从右边进来 append
   dequeue  → 从左边出去 popleft
```
> Python 的 `list` 当队列用 `pop(0)` 是 O(n)（要搬元素），**必须用 `deque`**（C 实现的双向链表，两头 O(1)）。

## 七、手推图示：用两个栈实现队列

题目：只用栈（后进先出）实现队列（先进先出）。

思路：**两个栈倒一手**——入队都进 `in` 栈；出队时若 `out` 空，把 `in` 全部倒进 `out`（倒过来后，顺序就正了）。

```
push 1 → in=[1]
push 2 → in=[1,2]
push 3 → in=[1,2,3]

pop() 时 out 空 → 把 in 倒进 out:
in:  [1,2,3]  →  逐个 pop 再 push 进 out → out=[3,2,1]
                 （1 现在在 out 栈顶！）
pop → out.pop() = 1 ✅（先进先出）

再 push 4 → in=[4]
pop() 时 out=[2,3] 不空 → 直接 out.pop() = 2 ✅

倒手图:
   in 栈(后进先出)           out 栈(后进先出)
   [1,2,3]  ──倒──▶  [3,2,1]
   底部是1，顶部是3         顶部变1 → pop 先出 1
```
```python
from collections import deque   # 这里只用 list 的 append/pop 即可当栈

class MyQueue:
    def __init__(self):
        self.in_ = []     # 入队栈
        self.out = []     # 出队栈
    def push(self, x):
        self.in_.append(x)
    def pop(self):
        self._shift()               # 保证 out 里有元素
        return self.out.pop()
    def peek(self):
        self._shift()
        return self.out[-1]
    def empty(self):
        return not self.in_ and not self.out
    def _shift(self):               # 核心：in → out 倒一手
        if not self.out:
            while self.in_:
                self.out.append(self.in_.pop())

mq = MyQueue()
mq.push(1); mq.push(2)
print("peek:", mq.peek(), "pop:", mq.pop(), "empty:", mq.empty())
```
**预期输出：** `peek: 1 pop: 1 empty: False`
摊还复杂度：每个元素被"倒"一次 O(1) 摊还，整体 O(1) 均摊。

## 九、小结

1. 栈 = 后进先出：`append`/`pop`/`[-1]`，用于**嵌套、最近配对、撤销**
2. 队列 = 先进先出：用 `deque`（list 的 pop(0) 是 O(n) 陷阱）
3. 括号匹配：左括号压栈、右括号弹栈比对 → O(n)
4. 最小栈：辅助 min 栈记录每个状态的当前最小值 → 所有操作 O(1)
5. **单调栈**：栈内单调，遇"破坏单调"的元素就结算——每个元素进出栈一次 → O(n)，专治"下一个更大/更小"
6. 接雨水：递减栈遇到更高右墙就结算坑底，O(n)
7. 两栈倒一手实现队列：摊还 O(1)

## 十、练习 5 题

### 练习 1：有效的括号变体（只含一种括号）

`"((()))"` 合法、`"(()"` 不合法、`"())("` 不合法。不借助栈，用计数器做。

**答案：**
```python
def is_valid_one(s):
    bal = 0
    for ch in s:
        if ch == '(': bal += 1
        else:
            bal -= 1
            if bal < 0: return False   # 右括号比左括号多 → 非法
    return bal == 0                    # 最后必须全配对

print(is_valid_one("((()))"))   # True
print(is_valid_one("(()"))      # False
print(is_valid_one("())("))     # False
```
**预期输出：** `True False False`
**解析**：计数法只适用于单一括号；多种括号必须用栈（因为要判断类型配对）。手推 `())`：`(`→1，`)`→0，`)`→-1<0 → False。

### 练习 2：逆波兰表达式求值

`["2","1","+","3","*"]` = (2+1)×3 = 9。数字压栈，遇到运算符弹出两个算完压回。

**答案：**
```python
def eval_rpn(tokens):
    st = []
    for t in tokens:
        if t in '+-*/':
            b = st.pop()      # 注意顺序: b 是后弹出的
            a = st.pop()      # a 是先压入的
            if t == '+': st.append(a+b)
            elif t == '-': st.append(a-b)
            elif t == '*': st.append(a*b)
            else: st.append(int(a/b))   # 向零取整
        else:
            st.append(int(t))
    return st[0]

print(eval_rpn(["2","1","+","3","*"]))          # 9
print(eval_rpn(["10","6","9","3","+","-11","*","/","*","17","+","5","+"]))
```
**预期输出：** `9` 与 `22`
**解析**：逆波兰 = 运算符跟在操作数后面，天然适合栈：`2 1 +` → 弹出 2、1 得 3。手推第二例较长，核心是"见数压栈、见符弹两数"。

### 练习 3：用队列实现栈

只用一个 `deque`：push 时把新元素放队尾后，把前面所有元素依次挪到后面，新元素就到"队头"了（pop 时直接 popleft）。

**答案：**
```python
from collections import deque

class MyStack:
    def __init__(self): self.q = deque()
    def push(self, x):
        self.q.append(x)
        for _ in range(len(self.q)-1):   # 把前面的都挪到后面
            self.q.append(self.q.popleft())
    def pop(self): return self.q.popleft()
    def top(self): return self.q[0]
    def empty(self): return not self.q

ms = MyStack()
ms.push(1); ms.push(2); ms.push(3)
print(ms.top(), ms.pop(), ms.empty())    # 3 3 False
```
**预期输出：** `3 3 False`
**解析**：push 后队里顺序是"后进的在队头"。手推：push1→`[1]`；push2→`[1,2]`挪1次→`[2,1]`；push3→`[2,1,3]`挪2次→`[3,2,1]`，top=3 ✅。

### 练习 4：下一个更大元素（单调栈，循环数组）

`[1,2,1]` 是循环数组（末尾接开头），每个元素的下一个更大元素 → `[2,-1,2]`。

**答案：** 把数组"虚拟复制一份"（下标走 2n，用 `i % n` 取真实值），从右往左维护递减栈：

```python
def next_greater(a):
    n = len(a)
    ans = [-1] * n
    st = []                       # 从右往左扫，栈里是"右边更大的候选"
    for i in range(2*n-1, -1, -1):    # 倒着走两圈
        idx = i % n
        while st and st[-1] <= a[idx]:
            st.pop()              # 比当前矮/相等的滚出（不可能是答案）
        if i < n and st:
            ans[idx] = st[-1]     # 栈顶就是右边第一个更大的
        st.append(a[idx])
    return ans

print(next_greater([1,2,1]))      # [2,-1,2]
print(next_greater([1,2,3,4,3]))  # [2,3,4,-1,4]
```
**预期输出：** `[2, -1, 2]` 和 `[2, 3, 4, -1, 4]`
**解析**：从右往左维护单调递减栈，栈顶永远是"右边第一个比当前大的"。走 2n 圈处理循环。手推 `[1,2,1]`：i=5→a[2]=1 栈空，i=2 记 ans[2]=-1 压1；i=4→a[1]=2 弹1，栈空，i=1 记 -1 压2；i=3→a[0]=1，栈顶2>1，i=0 记 ans[0]=2，压1 → 得 `[2,-1,2]`。

### 练习 5：有效的括号字符串（带 `*` 通配）

`"(*))"` 合法（`*` 可当 `(`/`)`/空）。问 s 是否合法。双栈：一个栈记 `(` 下标，一个记 `*` 下标。

**答案：**
```python
def check(s):
    left, star = [], []            # 存下标
    for i, ch in enumerate(s):
        if ch == '(': left.append(i)
        elif ch == '*': star.append(i)
        else:                       # ')'
            if left: left.pop()     # 优先用 '(' 配对
            elif star: star.pop()   # 没有 '(' 就用 '*' 当 '('
            else: return False
    # 还剩 '(' 没配对 → 用后面的 '*' 当 ')' 补
    while left and star:
        if left[-1] < star[-1]:     # '*' 必须出现在 '(' 之后才能当 ')'
            left.pop(); star.pop()
        else: break
    return not left

print(check("(*))"))     # True
print(check("()"))       # True
print(check(")("))       # False
print(check("((*)"))     # True
```
**预期输出：** `True True False True`
**解析**：贪心 + 双栈。右括号优先配 `(`；最后剩下的 `(` 必须能被**出现在它后面**的 `*` 补成 `)`。手推 `((*)`：下标0、1是`(`，下标2是`*`，遇到下标3`)` 弹出 left 的 `(`→left=[0]，star=[2]；最后 left 剩 0，star 剩 2，0<2 能补 → True。
