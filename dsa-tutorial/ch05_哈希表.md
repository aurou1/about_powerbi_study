# ch05 哈希表

> 学习目标：理解哈希表**为什么查得这么快（O(1)）**、**冲突怎么办**、**负载因子与扩容**；掌握三个高频套路——**哈希计数、哈希查重、哈希+链表（LRU）**。

---

## 一、哈希表：用"地址算得快"换"查找快"

数组按下标取数是 O(1)，因为**下标就是连续内存的偏移量**。但现实世界的键是"梁诗""ST-BD-42"这种，不是整数下标。哈希表的思想：

```
把任意键 → 用一个函数 hash() → 算出一个整数 → 当作"下标"去数组里取

键:  "梁诗"  ──hash()──▶  3  ──▶  数组[3] = {客户信息...}
键:  "ST-BD-42" ─hash()─▶ 7  ──▶  数组[7] = {料号信息...}

图:
              ┌─────────┬─────┬─────────┐
              │ 桶 0     │ ... │  桶 9    │
              └─────────┴─────┴─────────┘
   "梁诗" ──▶ hash("梁诗") % 10 = 3 → 桶3
   "ST-BD-42" ▶ hash("ST-BD-42") % 10 = 7 → 桶7
```
关键一步：**取模（% 桶数）把任意整数压进桶范围**。查"梁诗在不在"就变成：算 hash → 取模 → 看桶 3 ——和数组按下标取一样 O(1)。

> Python 的 `dict` / `set` 就是哈希表。`x in dict`、`x in set` 都是 O(1) 平均。

## 二、手推图示：哈希冲突与链表法

两个不同的键可能算进同一个桶 → **冲突**。最常见解法是**链表法**：同一个桶挂一条链表。

```
假设桶数 4:  hash("cat")%4=1, hash("dog")%4=1  ← 冲突！

图:
桶0: None
桶1: ──▶ [cat:🐱] ──▶ [dog:🐶] ──▶ None   ← 串成链表
桶2: None
桶3: ──▶ [fish:🐟] ──▶ None

查找 dog: 算 hash→桶1 → 沿链表逐个比 key，找到 dog → O(链表长度)
```
桶里链表越长，查找越慢。所以设计目标：**让元素尽量均匀散开**。

> 现实参考：Python dict 用的不是链表法而是**开放定址**（冲突就找下一个空位），效果类似——平均仍 O(1)，最坏（疯狂冲突）O(n)。

## 三、手推图示：负载因子与扩容

```
负载因子 = 已存元素数 / 桶数

桶数 4，已存 3 个:  负载因子 = 3/4 = 0.75
                    再存就频繁冲突 → 链表越来越长 → 退化 O(n)

策略: 负载因子 > 阈值(如 0.75) → 扩容翻倍，把所有元素重新散列

扩容前 (桶4):
桶0: ─▶ [a] ─▶ [e]
桶1: ─▶ [b]
桶3: ─▶ [d]

扩容为桶8, 重新 hash 每个 key:
桶0: ─▶ [a]
桶1: ─▶ [b]
桶4: ─▶ [e]        ← e 从桶0 挪到桶4（桶数变了，取模结果变）
桶5: ─▶ [d]
冲突变少，链表变短 → 又回到平均 O(1)
```
> 扩容一次 O(n)（全部重插），但翻倍扩容让"扩容次数"只有 O(log n) 次，**摊还仍是 O(1)**（和 Python list 的 append 扩容一个道理，ch02 讲过）。

## 四、套路一：哈希查重/找配对 → O(n)

### 4.1 两数之和（哈希版）

题目：`[2,7,11,15]` 找两数 = 9 → `[0,1]`。

```
暴力: 两两配对 O(n²)
哈希: 边走边记"见过的数 → 下标"；每来一个新数 x，查 target-x 见没见过

i=0 x=2: 需要 9-2=7，没见过 → 记 {2:0}
i=1 x=7: 需要 9-7=2，见过! → 返回 [0,1] ✅

手推图:
     [2, 7, 11, 15]   target=9
      ↑
     2 查"7在不在后面"？还没见到 → 把 2 记进哈希
     {2:0}

        [2, 7, 11, 15]
            ↑
     7 查"2在不在前面"？在! (哈希 {2:0}) → [0,1]
```
```python
def two_sum(a, target):
    seen = {}                     # 值 → 下标
    for i, x in enumerate(a):
        if target - x in seen:    # 需要的另一半见过了?
            return [seen[target-x], i]
        seen[x] = i               # 没见过就记下来
    return []

print(two_sum([2,7,11,15], 9))    # [0, 1]
print(two_sum([3,2,4], 6))        # [1, 2]
print(two_sum([3,3], 6))          # [0, 1]
```
**预期输出：** `[0, 1]` `[1, 2]` `[0, 1]`
复杂度 O(n)、空间 O(n)——**空间换时间**的教科书例子（对比 ch01 练习 3 的 O(n²) 版）。

### 4.2 最长连续序列

题目：`[100,4,200,1,3,2]` → 最长连续序列 `[1,2,3,4]` 长度 4。

关键：去重进 set，然后**只从"序列起点"（x-1 不在 set）开始往后数**，保证每个数最多被数一遍。

```
set = {100, 4, 200, 1, 3, 2}

x=100: 99在set吗? 否 → 起点! 数: 101在吗?否 → 长度1
x=4:   3在set! → 不是起点，跳过（它会被 x=1 那条数到）
x=1:   0在吗? 否 → 起点! 数: 2在→3在→4在→5在?否 → 长度4 ✅
x=3:   2在 → 跳过
...
best = 4
```
```python
def longest_consecutive(nums):
    s = set(nums)          # 去重，且查找 O(1)
    best = 0
    for x in s:
        if x - 1 not in s:     # 只从起点开始，避免重复数
            y, length = x, 1
            while y + 1 in s:  # 往后延伸
                y += 1; length += 1
            best = max(best, length)
    return best

print(longest_consecutive([100,4,200,1,3,2]))        # 4
print(longest_consecutive([0,3,7,2,5,8,4,6,0,1]))    # 9
```
**预期输出：** `4` `9`
复杂度：内层 while 每个数最多被数一次（只有起点才进内层）→ 整体 **O(n)**。

## 五、套路二：哈希计数 → O(n)

### 5.1 字母异位词分组

题目：`["eat","tea","tan","ate","nat","bat"]`，把字母相同顺序不同的词分到一组。

思路：**排序后的词当 key**（"eat"→"aet"），同组词共享 key。

```
手推:
"eat" → sorted → "aet"  组1: [eat]
"tea" → "aet"           组1: [eat, tea]      ← 同 key 归一组
"tan" → "ant"           组2: [tan]
"ate" → "aet"           组1: [eat, tea, ate]
"nat" → "ant"           组2: [tan, nat]
"bat" → "abt"           组3: [bat]

分组树:
            ┌─ "aet" → [eat, tea, ate]
sorted key ─┼─ "ant" → [tan, nat]
            └─ "abt" → [bat]
```
```python
from collections import defaultdict

def group_anagrams(words):
    d = defaultdict(list)
    for w in words:
        key = "".join(sorted(w))     # 排序后当钥匙
        d[key].append(w)
    return list(d.values())

print(group_anagrams(["eat","tea","tan","ate","nat","bat"]))
```
**预期输出：** `[['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]`

### 5.2 前 K 个高频元素

题目：`[1,1,1,2,2,3]` 里出现最多的前 2 个 → `[1,2]`。

```
第一步 计数（哈希）:
  1 → 3 次,  2 → 2 次,  3 → 1 次
  {1:3, 2:2, 3:1}

第二步 取前 K:
  排序 O(n log n)，或桶排/堆 O(n log k)（ch10 用堆再优化）
  这里直接用 Counter.most_common
```
```python
from collections import Counter

def top_k_frequent(nums, k):
    cnt = Counter(nums)                      # 哈希计数 O(n)
    return [x for x, _ in cnt.most_common(k)]

print(top_k_frequent([1,1,1,2,2,3], 2))      # [1, 2]
print(top_k_frequent([1], 1))                # [1]
```
**预期输出：** `[1, 2]` `[1]`

## 六、套路三：哈希 + 双向链表 = LRU 缓存

题目：实现容量 2 的 LRU（最近最少使用）缓存。`put(1,1), put(2,2), get(1)→1, put(3,3)` 后应淘汰 2（最久没用）。

```
为什么纯哈希不行？哈希能 O(1) 找，但"谁最久没用"需要顺序信息。
为什么纯链表不行？链表有顺序，但找 key 要 O(n)。

→ 合体: 哈希负责"按 key 定位到节点" O(1)
        双向链表负责"维护使用顺序" O(1) 增删

结构图:
   head ⇄ (2) ⇄ (1) ⇄ tail      ← 链表, 越靠 head 越"最近用过"
   key→节点:  {1:节点(1), 2:节点(2)}  ← 哈希

get(1): 找到节点1 → 移到 head 前
   head ⇄ (1) ⇄ (2) ⇄ tail
put(3,3): 插到 head 前; 超容量 → 删 tail 前的(2)
   head ⇄ (3) ⇄ (1) ⇄ tail
   哈希删掉 key=2 → 下次 get(2) 返回 -1 ✅

删除节点(双向链表的威力):
   要删 X:  X.pre.nxt = X.nxt;  X.nxt.pre = X.pre   ← O(1)
```
```python
class Node:
    def __init__(self, k=0, v=0):
        self.key, self.val = k, v
        self.pre = self.nxt = None

class LRUCache:
    def __init__(self, cap):
        self.cap = cap
        self.d = {}                      # key → 节点
        self.head, self.tail = Node(), Node()   # 哨兵
        self.head.nxt, self.tail.pre = self.tail, self.head
    def _remove(self, node):             # 摘下节点 O(1)
        node.pre.nxt = node.nxt
        node.nxt.pre = node.pre
    def _add_front(self, node):          # 插到 head 后 O(1)
        node.nxt = self.head.nxt; node.pre = self.head
        self.head.nxt.pre = node; self.head.nxt = node
    def get(self, key):
        if key not in self.d: return -1
        n = self.d[key]
        self._remove(n); self._add_front(n)   # 用了 → 提到最前
        return n.val
    def put(self, key, val):
        if key in self.d:
            n = self.d[key]; n.val = val
            self._remove(n); self._add_front(n); return
        n = Node(key, val)
        self.d[key] = n; self._add_front(n)
        if len(self.d) > self.cap:             # 超容 → 淘汰最久
            last = self.tail.pre
            self._remove(last); del self.d[last.key]

c = LRUCache(2)
c.put(1, 1); c.put(2, 2)
print("get1:", c.get(1))         # 1（并把 1 提到最前）
c.put(3, 3)                      # 超容 → 淘汰最久没用过的 2
print("get2(应-1):", c.get(2))   # -1
c.put(4, 4)                      # 再淘汰 1
print("get1(应-1):", c.get(1))   # -1
print("get3:", c.get(3), "get4:", c.get(4))
```
**预期输出：**
```
get1: 1
get2(应-1): -1
get1(应-1): -1
get3: 3 get4: 4
```
复杂度：get/put 全 O(1)——哈希定位 + 链表摘挂。**这是面试高频设计题**，图要会画。

## 七、手推图示：哈希查找为什么"平均 O(1)、最坏 O(n)"

```
平均情形（桶都均匀）:
  查找 = 算 hash O(1) → 到桶 → 链表极短(平均 1~2 个) → 几乎一次命中
  ⇒ O(1)

最坏情形（所有 key 撞同一桶，恶意构造）:
  桶0: ─▶ [a] ─▶ [b] ─▶ [c] ─▶ ... ─▶ [z]   长链表
  查找要沿链表比 n 次
  ⇒ O(n)

Python 缓解: hash 随机化种子（每次运行字符串 hash 不同），
            让攻击者无法预构造"全冲突"输入 → 实际接近平均 O(1)
```

## 八、哈希的坑：可变对象不能当 key

```
哈希要求: 同一对象每次 hash 相同
可变对象（list/dict/set）会变 → hash 会变 → 存进去后找不到

[1,2] 能当 key 吗?
  hash([1,2])  ← TypeError: unhashable type: 'list'

那如果把 list 转 tuple 再存:
  hash((1,2))  ✅ 元组不可变，能当 key
```
> 记忆：**不可变类型（int/str/tuple）可哈希，可变类型（list/dict/set）不可哈希**。想用"数组"当 key → 转成 tuple 或字符串。

---

## 九、小结

1. 哈希表 = hash 函数把键变成"下标" → 平均 O(1) 查找/插入/删除
2. 冲突用**链表法/开放定址**解决；负载因子过高就**扩容重散列**（摊还 O(1)）
3. 套路一**查重/找配对**：边遍历边记 `seen`，把 O(n²) 变 O(n)（两数之和、连续序列）
4. 套路二**计数**：`dict`/`Counter` 统计频次（异位词分组、TopK）
5. 套路三**哈希+链表**：哈希定位、链表排序 → LRU 全 O(1)
6. 可变对象不能当 key；Python 字符串 hash 有随机化种子防攻击
7. Python `dict`/`set`/`Counter`/`defaultdict` 都是哈希家族的现成工具

## 十、练习 5 题

### 练习 1：判断两个字符串是否互为字母异位词

`"anagram"` 与 `"nagaram"` → True；`"rat"` 与 `"car"` → False。

**答案：** 计数两个串的每个字符出现次数，比较是否相同：
```python
def is_anagram(s, t):
    if len(s) != len(t): return False
    cnt = {}
    for ch in s: cnt[ch] = cnt.get(ch, 0) + 1
    for ch in t:
        if ch not in cnt: return False
        cnt[ch] -= 1
        if cnt[ch] < 0: return False
    return True

print(is_anagram("anagram","nagaram"))   # True
print(is_anagram("rat","car"))           # False
```
**预期输出：** `True` `False`
**解析**：s 加计数、t 减计数，最后所有计数应为 0（途中出现负数/缺失即 False）。O(n)。

### 练习 2：只出现一次的数字

`[4,1,2,1,2]` 里只有一个数出现 1 次，其他都 2 次 → 找出它 = 4。（进阶：不用哈希，用异或）

**答案（哈希版）：**
```python
def single(nums):
    cnt = {}
    for x in nums: cnt[x] = cnt.get(x, 0) + 1
    for k, v in cnt.items():
        if v == 1: return k

print(single([4,1,2,1,2]))   # 4
```
**答案（异或版，O(1) 空间）：** `a^a=0`、`a^0=a`，全部异或一遍，成对的抵消，剩的就是它：
```python
def single_xor(nums):
    r = 0
    for x in nums: r ^= x
    return r

print(single_xor([4,1,2,1,2]))   # 4
```
**预期输出：** `4` `4`
**解析**：异或满足交换结合律，`4^1^2^1^2 = 4^(1^1)^(2^2) = 4^0^0 = 4`。手推：`1^1=0, 2^2=0, 4^0=4`。

### 练习 3：同构字符串

`s="egg"`、`t="add"` → True（e→a, g→d 一一映射）；`s="foo"`、`t="bar"` → False（o 同时映射 a 和 r）。

**答案：** 双向映射都要检查（防两个字符映射到同一个）：
```python
def is_isomorphic(s, t):
    m1, m2 = {}, {}          # s→t 和 t→s 两张映射表
    for a, b in zip(s, t):
        if a in m1 and m1[a] != b: return False
        if b in m2 and m2[b] != a: return False
        m1[a] = b; m2[b] = a
    return True

print(is_isomorphic("egg","add"))    # True
print(is_isomorphic("foo","bar"))    # False
print(is_isomorphic("paper","title"))# True
```
**预期输出：** `True` `False` `True`
**解析**：手推 `foo/bar`：f→b 记下，o→a 记下，第二个 o→r 时 m1 里 o 已=a≠r → False。**必须双向映射**，单向会漏掉"两个不同字符映射到同一字符"的情况。

### 练习 4：存在重复元素 II（滑动窗口 + 哈希）

`nums=[1,2,3,1]`, `k=3` → True（两个 1 距离 3 ≤ k）；`nums=[1,0,1,1]`, `k=1` → True；`nums=[1,2,3,1,2,3]`, `k=2` → False。

**答案：** 只记**最近一次**出现的下标就够了（更早的一定更远，不可能满足 ≤k）：
```python
def contains_nearby_duplicate(nums, k):
    last = {}                # 值 → 最近一次出现的下标
    for i, x in enumerate(nums):
        if x in last and i - last[x] <= k:
            return True
        last[x] = i          # 更新为更近的下标
    return False

print(contains_nearby_duplicate([1,2,3,1], 3))     # True  (两个1距离3)
print(contains_nearby_duplicate([1,0,1,1], 1))     # True  (下标2和3的两个1)
print(contains_nearby_duplicate([1,2,3,1,2,3], 2)) # False (同类距离都=3>2)
```
**预期输出：** `True` `True` `False`
**解析**：只记**最近一次**下标就够（更早的一定更远，不可能满足 ≤k）。手推第三例：1 在 0 和 3，距离 3>2；2 在 1 和 4，距离 3>2；3 在 2 和 5，距离 3>2 → False。O(n)。

### 练习 5：哈希集合设计题——判断数独部分是否有效

只检查 `board` 里已填的数字是否同行/同列/同 3×3 宫冲突（空位 '.' 跳过）。

**答案：** 三组 set 分别记录"行 r 出现过 x""列 c 出现过 x""宫 (r//3,c//3) 出现过 x"：
```python
def is_valid_sudoku(board):
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]
    for r in range(9):
        for c in range(9):
            x = board[r][c]
            if x == '.': continue
            b = (r // 3) * 3 + c // 3       # 宫编号 0..8
            if x in rows[r] or x in cols[c] or x in boxes[b]:
                return False
            rows[r].add(x); cols[c].add(x); boxes[b].add(x)
    return True

board = [
    ["5","3",".",".","7",".",".",".","."],
    ["6",".",".","1","9","5",".",".","."],
    [".","9","8",".",".",".",".","6","."],
    ["8",".",".",".","6",".",".",".","3"],
    ["4",".",".","8",".","3",".",".","1"],
    ["7",".",".",".","2",".",".",".","6"],
    [".","6",".",".",".",".","2","8","."],
    [".",".",".","4","1","9",".",".","5"],
    [".",".",".",".","8",".",".","7","9"],
]
print(is_valid_sudoku(board))   # True

bad = [row[:] for row in board]
bad[0][0] = "8"                 # 第一行第一列与 (8,0) 的 8 冲突
print(is_valid_sudoku(bad))     # False
```
**预期输出：** `True` `False`
**解析**：宫编号公式 `(r//3)*3 + c//3` 把 9×9 分成 9 个 3×3。手推：r=0,c=0 → 宫 0；r=8,c=8 → (2)*3+2=8。O(1)（固定 81 格）。
