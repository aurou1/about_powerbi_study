## 一、二分在干什么：每次砍掉一半

前提：**数组必须有序**（升序）。每次看中间元素，和目标比大小，**一定可以丢掉一半**。

```
在 [1, 3, 5, 7, 9, 11, 13] 里找 7:

数组:    1   3   5   7   9   11   13
下标:    0   1   2   3   4   5    6
         lo              mid        hi

第1步: mid=(0+6)//2=3 → a[3]=7 == 目标 → 直接命中! 返回 3

如果找 8:
第1步: mid=3, a[3]=7 < 8 → 7 及左边全比 8 小 → 丢掉左半边
        lo=4:  数组只剩 [9, 11, 13]
                lo=4        hi=6
第2步: mid=(4+6)//2=5 → a[5]=11 > 8 → 丢掉右半边 hi=5
        lo=4, hi=5
第3步: mid=(4+5)//2=4 → a[4]=9 > 8 → hi=4 → lo==hi 结束
找不到 → 返回 -1

图形（区间收缩）:
[1 3 5 7 9 11 13] 找8
[1 3 5 7 | 9 11 13]    ← 7<8, 左半全扔
        [9 | 11 13]    ← 11>8, 右半全扔
        [9]            ← lo=hi=4, 结束, 无 8
```
```python
def binary_search(a, t):
    lo, hi = 0, len(a)            # 搜索区间 [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] == t:
            return mid            # 命中
        if a[mid] < t:
            lo = mid + 1          # 目标在右半：丢掉 [lo, mid]
        else:
            hi = mid              # 目标在左半：丢掉 [mid+1, hi) → 区间 [lo, mid)
    return -1

arr = [1, 3, 5, 7, 9, 11, 13]
print("找7:", binary_search(arr, 7))    # 3
print("找8:", binary_search(arr, 8))    # -1
```
**预期输出：** `找7: 3` `找8: -1`

### 🔍 原理深挖 1：为什么是 O(log n)？——每次砍半的数学

```
区间长度从 n 开始，每轮变一半:
  第1轮后: n/2
  第2轮后: n/4
  第3轮后: n/8
  ...
  第 k 轮后: n / 2^k

问: 砍多少轮区间变空(长度<1)?
  解: n / 2^k < 1  ⇒  2^k > n  ⇒  k > log₂(n)

n=100万 → log₂(100万)≈20 步
n=10亿  → log₂(10亿)≈30 步

对比线性查找:
  100 万个数线性找最坏 100 万步，二分只要 20 步 → 快 5 万倍
```
```
图（区间长度每轮减半）:
长度 n ────────────────
          └────────────  n/2
               └──────── n/4
                    └──── n/8
                        └─ n/16 … 大约 log₂n 层就没了
```

### 🔍 原理深挖 2：为什么边界这么写不会死循环？

用**循环不变式**证明。我们维护一个不变式：

> **不变式：目标 t 若存在，必在 [lo, hi) 这个半开区间里；每次迭代都保持它成立。**

```
证明分三部分:

① 初始化: [0, len(a)) 包含整个数组 → t 若存在必在其中 ✅

② 保持: 每轮取 mid，分三种情况:
   - a[mid] == t → 直接返回，结束 ✅
   - a[mid] < t  → 因为数组升序，a[0..mid] 全都 < t
                    → 它们不可能含 t → 丢掉! lo = mid+1
                    新区间 [mid+1, hi) 仍含 t(若存在) ✅
   - a[mid] > t  → a[mid..len-1] 全都 > t → 不可能含 t
                    → hi = mid（注意不是 mid-1! 因为区间是 [lo,hi) 开区间,
                      hi 本身不含, 设为 mid 刚好把 a[mid] 也排除）
                    新区间 [lo, mid) 仍含 t(若存在) ✅

③ 终止: lo == hi 时区间为空 → t 不存在 → 返回 -1 ✅
   （且每轮 lo 增大或 hi 减小, 区间严格变小 → 必然终止, 不会死循环）
```
> **半开区间 [lo, hi) 的心智模型**：`hi` 永远指向"第一个不可能含答案的位置"。所以：
> - `hi` 初始 = `len(a)`（数组最后一个也不可能是答案时，越界一个）
> - 往左收缩写 `hi = mid`（mid 自己也被排除，因为它是"大于 t"的）
> - 往右收缩写 `lo = mid + 1`（mid 自己也被排除，因为它是"小于 t"的）
>
> 这两条写对了，**永远不会漏答案、永远不会死循环**——这是全章最值钱的一段。

## 二、模板一：lower_bound —— 找"第一个 ≥ target"的位置

比"找精确值"更常用（Python 的 `bisect.bisect_left` 就是它）。用途：**插入位置、统计某个值出现了几次、二分答案**。

```
a = [1, 2, 2, 2, 3, 5]  找第一个 ≥ 2 的位置:

下标: 0   1   2   3   4   5
      1   2   2   2   3   5
      lo              mid  hi

第1轮: mid=(0+6)//2=3 → a[3]=2 ≥ 2 → 可能是答案但左边可能还有 → hi=3
第2轮: mid=(0+3)//2=1 → a[1]=2 ≥ 2 → hi=1
第3轮: mid=(0+1)//2=0 → a[0]=1 < 2 → lo=1
       lo==hi==1 → 返回 1 ✅ (下标1是第一个2)

图（区间收缩到第一个 ≥2）:
[1 2 2 2 3 5]
        ↑hi=3 (a[3]=2≥2, 收缩左)
[1 2 | 2 2 3 5]? 不, 是 [1 2 2 | 2 3 5]
  ↑hi=1
[1 | 2 2 2 3 5]   lo=1=hi → 答案 1
```
```python
def lower_bound(a, t):
    lo, hi = 0, len(a)            # [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] >= t:           # 关键: >= 而非 ==
            hi = mid              # 够大 → 往左找更小的可行位置
        else:
            lo = mid + 1          # 太小 → 往右
    return lo

a = [1, 2, 2, 2, 3, 5]
print("第一个≥2:", lower_bound(a, 2))    # 1
print("第一个≥4:", lower_bound(a, 4))    # 5 (4~5之间, 插在5的位置)
```
**预期输出：** `第一个≥2: 1` `第一个≥4: 5`
> 和标准二分的唯一差别：`a[mid] == t` 时**不返回**，而是继续 `hi = mid` 往左压，压到"第一个"。
> 用途 1：统计 t 出现次数 = `lower_bound(t+1) - lower_bound(t)`。
> 用途 2：Python 里 `bisect_left(a, t)` 就是它。

## 三、模板二：二分答案 —— 对"答案"二分而不是对"数组"二分

有些题数组无序，但**答案有单调性**：`can(x)` 是单调函数（x 越大越容易/越难），就可以对 x 二分。

经典题：**整数开方**。求 `√x` 向下取整（x=8 → 2，x=16 → 4）。

```
转化: 找最大的 m 使 m*m ≤ x。这个性质是单调的:
      m=0: 0≤8 ✅   m=1: 1≤8 ✅  m=2: 4≤8 ✅  m=3: 9≤8 ❌
      → ✅✅✅✅ | ❌❌❌  分界点就是答案
      单调性: m 越大, m²≤x 越难成立 → 可以二分!

对答案空间 [0, x+1) 二分:
x=8:
第1轮: mid=4: 16≤8? 否 → hi=4 (4及更大的都不行)
第2轮: mid=2: 4≤8?  是 → lo=3
第3轮: mid=3: 9≤8?  否 → hi=3 → lo==hi==3
返回 lo-1 = 2 ✅  (最大的满足者是 2)
```
```python
def sqrt_int(x):
    lo, hi = 0, x + 1             # 答案空间 [0, x+1)
    while lo < hi:
        mid = (lo + hi) // 2
        if mid * mid <= x:        # 满足条件 → 答案在右边(含mid)
            lo = mid + 1
        else:                     # 不满足 → mid 及更大都不行
            hi = mid
    return lo - 1                 # lo 是"第一个不满足的", 减1

print("sqrt(8):", sqrt_int(8))       # 2
print("sqrt(16):", sqrt_int(16))     # 4
print("sqrt(99):", sqrt_int(99))     # 9
```
**预期输出：** `sqrt(8): 2` `sqrt(16): 4` `sqrt(99): 9`

### 🔍 原理深挖：为什么二分答案能成立？——单调性论证

```
二分答案的合法条件是 can(x) 是单调的（只允许一次翻转）:

如果 can(x) 单调递减:
   x:   1  2  3  4  5  6  7  8
  can:  ✅ ✅ ✅ ✅ ❌ ❌ ❌ ❌
              ↑分界点 → 二分找到第一个 ❌, 减1就是最大 ✅
如果 can(x) 单调递增:
   x:   1  2  3  4  5  6  7  8
  can:  ❌ ❌ ❌ ✅ ✅ ✅ ✅ ✅
              ↑分界点 → 二分找到第一个 ✅

如果 can(x) 乱跳(不单调):  ❌✅❌✅…  → 不能二分!

所以套路: 写二分答案前, 先在纸上确认 "x 越大, can 越(难/易)"
是单调的, 再决定往哪边收。
```

## 四、模板三：旋转数组找最小值

有序数组从某处"旋转"（如 `[4,5,6,7,0,1,2]` 由 `[0,1,2,4,5,6,7]` 旋转来），找最小值。

```
数组: 4 5 6 7 0 1 2     特征: 断点(0) 左边都比右边大

二分要点: 比较 a[mid] 和 a[hi]:
  - a[mid] > a[hi] → mid 在断点左侧 → 最小值在右边 → lo = mid+1
  - a[mid] ≤ a[hi] → mid 在右侧有序段(或断点就是 mid 位置)
                      → 最小值在 [lo, mid] → hi = mid

手推 [4,5,6,7,0,1,2]:
第1轮: lo=0 hi=6 mid=3: a[3]=7 > a[6]=2 → 最小值在右 → lo=4
第2轮: lo=4 hi=6 mid=5: a[5]=1 ≤ a[6]=2  → hi=5
第3轮: lo=4 hi=5 mid=4: a[4]=0 ≤ a[5]=1  → hi=4
       lo==hi==4 → 返回 a[4]=0 ✅

图（断点定位）:
  值:  4  5  6  7 | 0  1  2
       递增段↑        ↑递增段
              mid=7>2 → 断点在右半 → 丢掉左半
                    mid=1≤2 → 收缩 hi → 找到 0
```
```python
def find_min_rotated(a):
    lo, hi = 0, len(a) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] > a[hi]:      # 断点在右侧 → 最小值在右
            lo = mid + 1
        else:                   # 右侧有序 → 最小值在左(含 mid)
            hi = mid
    return a[lo]

print(find_min_rotated([4,5,6,7,0,1,2]))    # 0
print(find_min_rotated([1,2,3,4,5]))        # 1 (没旋转)
```
**预期输出：** `0` `1`
> 变体：旋转数组里找某个值（ch14 题 5 已讲）——核心都是先判断"哪一半有序"。

## 五、二分边界终极对照表

```
场景                    用哪个         收缩写法
────────────────────────────────────────────────
精确找一个值            标准二分        a[mid]<t→lo=mid+1; 否则 hi=mid
找第一个 ≥ target       lower_bound    a[mid]>=t→hi=mid; 否则 lo=mid+1
找第一个 > target       lower_bound(t+1) 同上
统计 t 出现次数          lower(t+1)-lower(t)
旋转数组找最小           a[mid]>a[hi]→lo=mid+1 否则 hi=mid
二分答案(最大可行)       满足→lo=mid+1; 否则 hi=mid; 答案 lo-1
二分答案(最小可行)       满足→hi=mid;   否则 lo=mid+1; 答案 lo
```
> 记忆口诀：**"找左边界往左压（hi=mid），找右边界往右拉（lo=mid+1）"**——想清楚"我到底要第一个还是最后一个满足的"，边界自然就对了。

## 六、手推验证：为什么 mid 这样算不溢出

```
Java/C++ 里 (lo+hi)//2 可能溢出(lo+hi 超 int 上限)
  安全写法: mid = lo + (hi-lo)//2
Python 整数无限大, 没这问题, 但面试官可能问
  答: 用 lo + (hi-lo)//2 避免 lo+hi 溢出 → 加分项
```

## 七、小结

1. 二分前提：**有序**（或答案空间单调）
2. 半开区间 `[lo, hi)` + 循环不变式 = **不错、不漏、不死循环**的保证
3. 收缩两条铁律：往左 `hi=mid`；往右 `lo=mid+1`（mid 自己总被排除）
4. 三个模板：**标准二分**（精确值）、**lower_bound**（第一个 ≥）、**二分答案**（对答案空间二分）
5. 二分答案必须确认 `can(x)` 单调，否则失效
6. 旋转数组：比 `a[mid]` 与 `a[hi]` 判断断点侧
7. 复杂度 O(log n)：每次砍半，`k>log₂n` 轮必停

## 八、练习 5 题

### 练习 1：搜索插入位置（就是 lower_bound）

`[1,3,5,6]`：插 5 → 下标 2；插 2 → 下标 1；插 7 → 下标 4；插 0 → 下标 0。

**答案：**
```python
def search_insert(a, t):
    return lower_bound(a, t)     # 第一个 ≥ t 的位置 = 插入位

print(search_insert([1,3,5,6], 5))    # 2
print(search_insert([1,3,5,6], 2))    # 1
print(search_insert([1,3,5,6], 7))    # 4
print(search_insert([1,3,5,6], 0))    # 0
```
**预期输出：** `2` `1` `4` `0`
**解析**：插入位置 = 第一个 ≥ target 的下标。手推插 2：a[0]=1<2，a[1]=3≥2 → 返回 1。**这就是二分查找最常考的变体**。

### 练习 2：山脉数组找峰值

`[0,2,1,0]` 先升后降（像山），峰在 index 1。要求 O(log n)。提示：比较 `a[mid]` 与 `a[mid+1]`——升则峰在右，降则峰在左（含 mid）。

**答案：**
```python
def peak_index(a):
    lo, hi = 0, len(a) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < a[mid + 1]:   # 还在上坡 → 峰在右
            lo = mid + 1
        else:                     # 开始下坡 → 峰在左(含mid)
            hi = mid
    return lo

print(peak_index([0,2,1,0]))     # 1
print(peak_index([1,2,3,1]))     # 2
```
**预期输出：** `1` `2`
**解析**：本质也是"二分答案/单调性"——`a[mid]<a[mid+1]` 判断 mid 在上坡还是下坡段。手推 [0,2,1,0]：mid=1，a[1]=2 < a[2]=1? 否 → hi=1 → 返回 1 ✅。

### 练习 3：第一个错误的版本（二分答案模板）

版本 1..n，某版本起全是坏的。接口 `is_bad(v)` 单调（一旦坏就永远坏）。找第一个坏的。`n=5`，`is_bad=[F,F,T,T,T]` → 版本 3。

**答案：**
```python
def first_bad(n, is_bad):
    lo, hi = 1, n + 1           # 答案在 [1, n+1)
    while lo < hi:
        mid = (lo + hi) // 2
        if is_bad(mid):         # mid 坏了 → 第一个坏的 ≤ mid
            hi = mid
        else:
            lo = mid + 1
    return lo

is_bad = lambda v: v >= 3       # 版本3起全坏
print(first_bad(5, is_bad))     # 3
```
**预期输出：** `3`
**解析**：坏的单调 `[F,F,T,T,T]` → 找第一个 T = lower_bound 思想。手推：mid=3 坏 → hi=3；mid=2 好 → lo=3 → 返回 3。

### 练习 4：爱吃香蕉的珂珂（二分答案，最大吃速）

`piles=[3,6,7,11]`，要在 `h=8` 小时内吃完，求最小吃速 k（每小时吃 k 根，一堆没吃完也要花一小时）。

**答案：** 对速度 k 二分，`can(k) = 总耗时 ≤ h` 单调递减（k 越大越快）：
```python
import math

def min_eating_speed(piles, h):
    lo, hi = 1, max(piles)      # 速度空间
    while lo < hi:
        mid = (lo + hi) // 2
        hours = sum(math.ceil(p / mid) for p in piles)   # 每堆耗时
        if hours <= h:          # 能吃完 → 试着更慢
            hi = mid
        else:                   # 吃不完 → 必须更快
            lo = mid + 1
    return lo

print(min_eating_speed([3,6,7,11], 8))     # 4
print(min_eating_speed([30,11,23,4,20], 5))  # 30
print(min_eating_speed([30,11,23,4,20], 6))  # 23
```
**预期输出：** `4` `30` `23`
**解析**：速度 k 越大，总耗时越少 → 单调 → 二分找"最小可行 k"。手推 piles=[3,6,7,11],h=8：k=4 → 1+2+2+3=8 小时 ✅；k=3 → 1+2+3+4=10>8 ❌ → 答案 4。

### 练习 5：x 的 n 次方（快速幂的二分亲戚）

实现 `pow(x, n)`，n 可为负。O(log n)。

**答案：**
```python
def my_pow(x, n):
    if n < 0:                   # 负次幂 = 倒数
        x, n = 1/x, -n
    res = 1
    while n:
        if n % 2 == 1:          # 奇数位: 乘一次
            res *= x
        x *= x                  # 底数平方
        n //= 2                 # 指数减半
    return res

print(my_pow(2.0, 10))     # 1024.0
print(my_pow(2.0, -2))     # 0.25
print(my_pow(2.0, 0))      # 1.0
```
**预期输出：** `1024.0` `0.25` `1.0`
**解析**：`x^n` 把 n 看成二进制，逐位平方。手推 2^10：10=1010₂ → 第2位(2¹)和第4位(2³)贡献 → 2² × 2⁸ = 1024。循环里 `x` 每次平方（2→4→16→256），n 每次砍半 → O(log n)。
