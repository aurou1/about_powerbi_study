# ch09 树与二叉树

> 学习目标：理解**树 = 分层的链表**（每个节点有多个 next）；掌握二叉树的**四种遍历**（前/中/后/层序）并会画访问顺序图；吃透**二叉搜索树（BST）**的插入/查找路径与"中序必有序"性质；会**从前序+中序重建二叉树**。

---

## 一、树的结构：一个节点多个"指针"

链表每个节点只有 1 个 next 指针 → 一条线。树每个节点有多个子指针 → 分叉。**二叉树 = 最多两个子节点（left/right）**。

```
链表（一条线）:                 二叉树（一棵树）:
┌───┬──┐  ┌───┬──┐            ┌───┐
│ 1 │──┼─▶│ 2 │──┼─▶ ...      │ 1 │      ← 根 root
└───┴──┘  └───┴──┘            └─┬─┘
                                │
                          ┌─────┴─────┐
                        ┌─┴─┐       ┌─┴─┐
                        │ 2 │       │ 3 │   ← 左右孩子
                        └─┬─┘       └─┬─┘
                          │      ┌────┴───┐
                        ┌─┴─┐  ┌─┴─┐  ┌─┴─┐
                        │ 4 │  │ 5 │  │ 6 │ 7 …（叶子）
```
```
术语:
  根(root): 最上面的节点（唯一没有父）
  叶子: 没有孩子的节点（4,5,6,7…）
  子树: 任一节点往下整棵
  深度: 根到某节点的边数 | 树高: 根到最远叶子的层数
```
> 树是递归结构：**每个子树本身也是一棵树** → 递归遍历天然契合（ch06 学过递归就够用）。

## 二、四种遍历：访问顺序配图（同一棵树）

用下面这棵满二叉树走一遍：

```
          ①
        /    \
      ②       ③
     / \      / \
    ④   ⑤   ⑥   ⑦
```
```
前序(preorder):  根 → 左 → 右          = ① ② ④ ⑤ ③ ⑥ ⑦
中序(inorder):   左 → 根 → 右          = ④ ② ⑤ ① ⑥ ③ ⑦
后序(postorder): 左 → 右 → 根          = ④ ⑤ ② ⑥ ⑦ ③ ①
层序(levelorder): 一层层从左到右        = ① ② ③ ④ ⑤ ⑥ ⑦
```
手推前序的递归展开（图）：
```
preorder(①) = ① + preorder(②) + preorder(③)
                    │               │
            = ②+pre(④)+pre(⑤)   = ③+pre(⑥)+pre(⑦)
               =④        =⑤         =⑥        =⑦
逐层套回去: ① ② ④ ⑤ ③ ⑥ ⑦ ✅
```
```python
class Node:
    def __init__(self, v):
        self.v = v
        self.left = None
        self.right = None

def preorder(r):            # 根左右
    if not r: return []
    return [r.v] + preorder(r.left) + preorder(r.right)

def inorder(r):             # 左根右
    if not r: return []
    return inorder(r.left) + [r.v] + inorder(r.right)

def postorder(r):           # 左右根
    if not r: return []
    return postorder(r.left) + postorder(r.right) + [r.v]

def levelorder(r):          # 层序: 用队列一层层扫
    from collections import deque
    q = deque([r]); out = []
    while q:
        x = q.popleft()
        out.append(x.v)
        if x.left:  q.append(x.left)
        if x.right: q.append(x.right)
    return out

# 搭树
def n(v): return Node(v)
root = n(1); root.left = n(2); root.right = n(3)
root.left.left = n(4); root.left.right = n(5)
root.right.left = n(6); root.right.right = n(7)

print("前序:", preorder(root))     # [1,2,4,5,3,6,7]
print("中序:", inorder(root))      # [4,2,5,1,6,3,7]
print("后序:", postorder(root))    # [4,5,2,6,7,3,1]
print("层序:", levelorder(root))   # [1,2,3,4,5,6,7]
```
**预期输出：**
```
前序: [1, 2, 4, 5, 3, 6, 7]
中序: [4, 2, 5, 1, 6, 3, 7]
后序: [4, 5, 2, 6, 7, 3, 1]
层序: [1, 2, 3, 4, 5, 6, 7]
```
> 记忆口诀：**前中后说的是"根"什么时候访问**（前=先根、中=中间、后=最后）；层序=队列 BFS（ch11 会再见）。三种 DFS 递归都 O(n)，层序 O(n)。

## 三、手推图示：二叉搜索树（BST）——"左小右大"的字典

BST 性质：**左子树所有值 < 根 < 右子树所有值**（每个子树也满足）。

```
插入序列 [5, 3, 7, 2, 4, 6, 8] 的建树过程:

5 →       5
3 →       5          3<5 去左
         /
        3
7 →       5          7>5 去右
         / \
        3   7
2 →      5          2<5→左; 2<3→左
         / \
        3   7
       /
      2
4 →      5          4<5→左; 4>3→右
         / \
        3   7
       / \
      2   4
6 →      5          ...最终:
         / \             5
        3   7         /    \
       / \ / \       3      7
      2  4 6 8      / \    / \
                   2   4  6   8
```
### 查找路径（每次走一边，O(log n)）

```
在树里找 7:   5 → 7>5 走右 → 7==7 命中（1 步）
在树里找 9:   5 → 9>5 右 → 9>7 右 → 无 → 不存在（3 步=树高）

找 4:  5 → 4<5 走左 → 4>3 走右 → 命中（2 步）
```
```python
def bst_insert(r, v):
    if not r: return Node(v)          # 空位 → 挂新节点
    if v < r.v: r.left = bst_insert(r.left, v)    # 小 → 左
    else:       r.right = bst_insert(r.right, v)  # 大/等 → 右
    return r

def bst_search(r, v, depth=0):
    if not r: return (False, depth)   # 走到底没有
    if r.v == v: return (True, depth)
    if v < r.v: return bst_search(r.left, v, depth+1)
    return bst_search(r.right, v, depth+1)

bst = None
for v in [5,3,7,2,4,6,8]:
    bst = bst_insert(bst, v)

print("BST中序(应有序):", inorder(bst))        # [2,3,4,5,6,7,8]
print("找7:", bst_search(bst, 7))              # (True, 1)
print("找9:", bst_search(bst, 9))              # (False, 3)
```
**预期输出：**
```
BST中序(应有序): [2, 3, 4, 5, 6, 7, 8]
找7: (True, 1)
找9: (False, 3)
```
> **BST 中序遍历必得升序序列**——这是"验证一棵树是不是 BST"的最快方法。查找/插入复杂度 = 树高：平衡时 O(log n)，退化成链时 O(n)。

## 四、手推图示：验证 BST——为什么不能只比父节点

只检查"每个节点 左<根<右"够吗？**不够**！下面的树每层都满足，却不是 BST：

```
     10
    /  \
   15   20     ← 15 在 10 的左子树，却 > 10 → 违反全局性质!

只查父子: 10的左孩子15? 15<10 否 → 其实这层就错了（更隐蔽的案例）:

      10
     /  \
    5    20
   / \
  2   12    ← 12 在 10 的左子树却 >10（但它 > 它的父 5，局部对）

正确做法: 给每个子树传"取值范围 (lo, hi)"
  遍历时收窄范围: 进左子树 → hi 收成当前值; 进右子树 → lo 收成当前值
  节点值必须落在 (lo, hi) 内
```
```python
def is_bst(r, lo=float('-inf'), hi=float('inf')):
    if not r: return True
    if not (lo < r.v < hi): return False      # 超出范围 → 不是 BST
    return (is_bst(r.left, lo, r.v) and       # 左子树: 上界收紧为 r.v
            is_bst(r.right, r.v, hi))         # 右子树: 下界收紧为 r.v

# 好树
bst = None
for v in [5,3,7,2,4,6,8]: bst = bst_insert(bst, v)
print("是BST:", is_bst(bst))                  # True

# 坏树: 15 在 10 的左子树却比 10 大
bad = n(10); bad.left = n(15); bad.right = n(20)
print("坏树是BST:", is_bst(bad))              # False
```
**预期输出：** `是BST: True` `坏树是BST: False`

## 五、手推图示：前序 + 中序 → 重建二叉树

为什么需要两个序？只给前序，根的左右子树分不清。**前序定根、中序分左右**，递归重建。

```
前序 pre = [3, 9, 20, 15, 7]
中序 ino = [9, 3, 15, 20, 7]

第1层: pre[0]=3 是根
       中序里 3 在位置1 → 左子树=ino[:1]=[9], 右子树=ino[2:]=[15,20,7]
       前序剩下的 [9, 20, 15, 7]: 前 1 个归左子树, 后 3 个归右子树
       左子树 pre=[9], 右子树 pre=[20,15,7]

第2层 左: pre[0]=9 → 叶子 9
第2层 右: pre[0]=20 是根; 中序 [15,20,7] 里 20 在中间
       左子树 ino=[15] pre=[15], 右子树 ino=[7] pre=[7]
       15、7 都是叶子

完整树:
          3
         / \
        9   20
           /  \
          15   7
```
```python
def build(pre, ino):
    if not pre: return None
    v = pre[0]                        # 前序第一个 = 根
    idx = ino.index(v)                # 根在中序的位置 → 分开左右
    r = Node(v)
    r.left  = build(pre[1:1+idx],    ino[:idx])     # 左子树
    r.right = build(pre[1+idx:],     ino[idx+1:])   # 右子树
    return r

pre = [3, 9, 20, 15, 7]
ino = [9, 3, 15, 20, 7]
rt = build(pre, ino)
print("重建后前序:", preorder(rt))    # [3,9,20,15,7]
print("重建后中序:", inorder(rt))     # [9,3,15,20,7]
```
**预期输出：**
```
重建后前序: [3, 9, 20, 15, 7]
重建后中序: [9, 3, 15, 20, 7]
```
> 中序 + 前序（或后序）可唯一重建；**只有前序+后序不行**（分不清左右）。复杂度：朴素 `ino.index` 每层 O(n) → O(n²)；用哈希表记中序位置可优化到 O(n)。

## 六、手推图示：BST 最近公共祖先（LCA）

题目：BST 上找两个节点的最近公共祖先。利用 BST 大小关系：**第一个值落在 a、b 之间的节点就是答案**。

```
树:
           5
         /   \
        3     7
       / \   / \
      2   4 6   8

求 LCA(2, 8):
  根 5: 2<5<8 → 5 正好在 2 和 8 之间 → 答案就是 5 ✅
  （5 是 2 和 8 的"分叉点": 一个在左子树一个在右子树）

求 LCA(4, 6):
  根 5: 4<5<6 → 答案 5 ✅

求 LCA(6, 8):
  根 5: 6>5 且 8>5 → 两个都在右子树 → 下到右子树
  右根 7: 6<7<8 → 答案 7 ✅
```
```python
def lca(r, a, b):
    if r.v < a and r.v < b:           # 两个都比根大 → 都在右子树
        return lca(r.right, a, b)
    if r.v > a and r.v > b:           # 两个都比根小 → 都在左子树
        return lca(r.left, a, b)
    return r.v                        # 根在 a、b 之间 → 就是 LCA

print("LCA(2,8):", lca(bst, 2, 8))    # 5
print("LCA(4,6):", lca(bst, 4, 6))    # 5
```
**预期输出：** `LCA(2,8): 5` `LCA(4,6): 5`
复杂度 O(树高)。

## 七、手推图示：对称树检查

```
判断一棵树是否镜像对称:
          1
        /   \
       2     2        ← 左右值相同
      / \   / \
     3   4 4   3      ← 左左(3)=右右(3), 左右(4)=右左(4)

递归配对: f(a,b) 检查 a 和 b 互为镜像
  f(左2, 右2): 值同 → 检查 f(2.left, 2.right) 和 f(2.right, 2.left)
    f(3,3): True     ← 左树的左 对 右树的右
    f(4,4): True     ← 左树的右 对 右树的左
  → True ✅

不对称例子:
          1
        /   \
       2     2
      /       \
     3         3    ← 左树的左是3, 右树的右是3; 但右树没有左子树和3对应
```
```python
def is_symmetric(root):
    def f(a, b):                    # a、b 是否互为镜像
        if not a and not b: return True
        if not a or not b: return False      # 一边空一边不空
        return (a.v == b.v and
                f(a.left, b.right) and       # 外侧配外侧
                f(a.right, b.left))          # 内侧配内侧
    return f(root.left, root.right) if root else True

sym = n(1); sym.left = n(2); sym.right = n(2)
sym.left.left = n(3); sym.left.right = n(4)
sym.right.left = n(4); sym.right.right = n(3)
print("对称树:", is_symmetric(sym))          # True
print("普通树对称:", is_symmetric(root))      # False
```
**预期输出：** `对称树: True` `普通树对称: False`

## 八、树的复杂度速查

```
操作           链表      平衡BST       哈希表
─────────────────────────────────────────────
查找           O(n)      O(log n)     O(1)平均
按序输出       O(n)排序  O(n)中序     ❌无序
找最大/最小    O(n)      O(log n)     ❌
前驱/后继      O(n)      O(log n)     ❌
```
> 树的独特价值：**既快又能保持有序**（哈希查得快但无序；链表有序但查得慢）。数据库索引、红黑树、堆都用这个思想。

## 九、小结

1. 树 = 分层链表，每个节点多个 child；二叉树最多两个
2. 四种遍历：前(根左右)/中(左根右)/后(左右根)/层序(队列BFS)，都会画顺序图
3. **BST 左小右大；中序必升序** —— 验证/输出都靠它
4. 验证 BST 要给子树传 (lo,hi) 范围，**不能只查父子**
5. 前序定根 + 中序分左右 → 递归重建二叉树
6. LCA（BST 版）：第一个落在两值之间的节点
7. 对称树：递归检查 左左=右右 且 左右=右左
8. 树的杀手锏：有序 + O(log n)

### 练习 3：验证 BST（陷阱题）

`is_bst` 只查"每个节点 左<根<右"的**朴素递归版**，对下面的树会误判为 True 吗？
```
     10
    /  \
   5    15
  / \
 2   12
```
**答案：** 会误判 True。因为 5 的右孩子 12 > 5 但 12 > 10（根）——**它在根的左子树却比根大**。朴素版只看父子不看祖先范围 → 必须用 `(lo, hi)` 收窄版：进 5 的右子树时 hi=10，12>10 → False ✅。

### 练习 4：树的最大深度（递归）

**答案：**
```python
def max_depth(r):
    if not r: return 0
    return 1 + max(max_depth(r.left), max_depth(r.right))

print(max_depth(root))    # 3（前面那棵 1..7 的树）
```
**预期输出：** `3`
**解析**：空树 0；否则 1 + 左右子树深度较大者。手推叶子：max_depth(叶子)=1+max(0,0)=1。

### 练习 5：二叉树反转（镜像翻转）

把左右子树全部互换。对练习 1 的树反转后层序是什么？

**答案：**
```python
def invert(r):
    if not r: return None
    r.left, r.right = r.right, r.left     # 交换左右
    invert(r.left); invert(r.right)       # 递归翻转子树
    return r

# 用练习1的树: 根1, 左2(4,5), 右3
t = n(1); t.left = n(2); t.right = n(3)
t.left.left = n(4); t.left.right = n(5)
t = invert(t)
print("反转后层序:", levelorder(t))       # [1,3,2,5,4]
```
**预期输出：** `反转后层序: [1, 3, 2, 5, 4]`
**解析**：每层左右互换：根1不变，左右孩子 2↔3；2 的孩子 4、5 互换 → 层序 1,3,2,5,4。
