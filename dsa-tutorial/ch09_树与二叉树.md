# ch09 树与二叉树

> 学习目标：理解树/二叉树的节点结构；能手写四种遍历（前序/中序/后序/层序）；会由前序+中序重建；理解 BST（二叉搜索树）及其与「有序」的关系。数据库索引（B+ 树）就是树的工业版。

## 一、树的基本概念

- **节点**：树的元素。**根**是最上面的；**叶子**是没有孩子的。
- **深度/高度**：从根往下数几层。
- **二叉树**：每个节点最多两个孩子（左、右）。
- **满/完全二叉树**：完全二叉树用数组存最省（堆 ch10 就这么干）。

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

# 用层序列表建树（None 表示空）
import collections
def build_from_level(vals):
    if not vals: return None
    root = TreeNode(vals[0]); q = collections.deque([root]); i = 1
    while q and i < len(vals):
        node = q.popleft()
        if vals[i] is not None:
            node.left = TreeNode(vals[i]); q.append(node.left)
        i += 1
        if i < len(vals) and vals[i] is not None:
            node.right = TreeNode(vals[i]); q.append(node.right)
        i += 1
    return root
```

## 二、四种遍历（必背）

`[1,2,3,4,5,None,6]` 建成树：
```
        1
       / \
      2   3
     / \   \
    4   5   6
```

```python
def preorder(n, out):
    if n: out.append(n.val); preorder(n.left, out); preorder(n.right, out)
def inorder(n, out):
    if n: inorder(n.left, out); out.append(n.val); inorder(n.right, out)
def postorder(n, out):
    if n: postorder(n.left, out); postorder(n.right, out); out.append(n.val)
def levelorder(root):
    if not root: return []
    q = collections.deque([root]); out = []
    while q:
        n = q.popleft(); out.append(n.val)
        if n.left: q.append(n.left)
        if n.right: q.append(n.right)
    return out

root = build_from_level([1, 2, 3, 4, 5, None, 6])
po, io, so, lo = [], [], [], []
preorder(root, po); inorder(root, io); postorder(root, so)
print("层序:", levelorder(root))
print("前序:", po, "| 中序:", io, "| 后序:", so)
```

**预期输出：**

```text
层序: [1, 2, 3, 4, 5, 6]
前序: [1, 2, 4, 5, 3, 6] | 中序: [4, 2, 5, 1, 3, 6] | 后序: [4, 5, 2, 6, 3, 1]
```

> 命名看「根节点什么时候访问」：前序根在最前、中序根在中间、后序根在最后。**中序遍历 BST 会得到有序序列**——这是树和「有序」的桥梁。层序用队列（ch04 BFS）。

## 三、最大深度

```python
def max_depth(n):
    return 0 if not n else 1 + max(max_depth(n.left), max_depth(n.right))

print("最大深度:", max_depth(root))
```

**预期输出：**

```text
最大深度: 3
```

> 递归：深度 = 1 + max(左子树深, 右子树深)。面试常考「是否平衡二叉树」就是在此加个高度差判断。

## 四、由前序 + 中序重建

前序第一个是根；在中序里根的左边是左子树、右边是右子树；递归切分。

```python
def build_tree(pre, ino):
    if not pre: return None
    root = TreeNode(pre[0])
    idx = ino.index(pre[0])
    root.left = build_tree(pre[1:idx+1], ino[:idx])
    root.right = build_tree(pre[idx+1:], ino[idx+1:])
    return root

rebuilt = build_tree([3, 9, 20, 15, 7], [9, 3, 15, 20, 7])
lv = []
preorder(rebuilt, lv)
print("重建前序:", lv, "(应等于原前序 [3,9,20,15,7])")
```

**预期输出：**

```text
重建前序: [3, 9, 20, 15, 7] (应等于原前序 [3,9,20,15,7])
```

> 前序给「根」，中序给「左右边界」。这是「分治 + 递归」的树版。注意：必须**前序+中序**或**后序+中序**才能唯一确定；只有前序+后序不行（无法区分左右）。

## 五、二叉搜索树（BST）

**BST 性质**：左子树所有值 < 根 < 右子树所有值。后果：**中序遍历一定有序**。

### 5.1 插入 + 验证

```python
class BST:
    def insert(self, root, val):
        if not root: return TreeNode(val)
        if val < root.val:
            root.left = self.insert(root.left, val)
        else:
            root.right = self.insert(root.right, val)
        return root
    def is_valid(self, n, lo=float('-inf'), hi=float('inf')):
        if not n: return True
        if not (lo < n.val < hi): return False
        return self.is_valid(n.left, lo, n.val) and self.is_valid(n.right, n.val, hi)

bst = None
for v in [5, 3, 7, 1, 4, 6, 9]:
    bst = BST().insert(bst, v)
iv = []
inorder(bst, iv)
print("BST 中序(应有序):", iv, "| 合法:", BST().is_valid(bst))
```

**预期输出：**

```text
BST 中序(应有序): [1, 3, 4, 5, 6, 7, 9] | 合法: True
```

> 验证 BST 不能只比「根和左右孩子」（那是错的！），要维护「当前节点允许的取值范围 `[lo, hi]`」向下传。中序有序是 BST 的充要条件。

### 5.2 BST 与二分查找的关系

在 BST 里查找 = 从根开始，比目标大走左、小走右，**本质就是二分查找的树形版**，平均 O(log n)。但 BST 最坏会退化成链表（插入有序数据时不旋转）→ O(n)。**工业方案是「自平衡 BST」（AVL / 红黑树）**，数据库索引用 **B+ 树**（矮胖、适合磁盘块）。

## 六、树为什么重要

- `python-tutorial` 的 JSON、`sql-tutorial` 的查询计划、文件系统的目录、公司的组织结构——全是树。
- 数据库的 `INDEX`（B+ 树）：查找 O(log n)，这就是为什么 `WHERE id = ?` 比全表扫快。
- 你 FDE 岗位要做「把平台适配客户场景」，客户数据常有层级（区域→门店→订单），树遍历是基本功。

## 小结

- 树节点 = 值 + 左右孩子；完全二叉树可数组存。
- 四种遍历：前/中/后序（递归，根的位置不同）+ 层序（队列 BFS）。
- 前序+中序可重建树。
- BST 左<根<右，中序有序；查找是二分树形版；工业用自平衡/B+ 树。

**答案与解析**

1. 队列：入 1→出 1 入 2,3→出 2 入 4,5→出 3 入 6→出 4,5,6。输出 `[1,2,3,4,5,6]`。
2. 后序最后 `3` 是根；中序里 3 左边 `[9]` 是左子树、右边 `[15,20,7]` 是右子树；右子树后序 `[15,7,20]` 根是 20，中序 `[15,20,7]` 切出 15 左、7 右。
3.
   ```python
   def search(node, val):
       if not node: return False
       if node.val == val: return True
       return search(node.left, val) if val < node.val else search(node.right, val)
   print(search(bst, 6))   # True
   ```
4. 高度差：根1 的左右子树高都是 2（左：2-4-5 高2；右：3-6 高2）→ 差 0。其他节点也平衡 → True。
   ```python
   def is_balanced(n):
       def h(node):
           if not node: return 0
           return 1 + max(h(node.left), h(node.right))
       def check(node):
           if not node: return True
           if abs(h(node.left) - h(node.right)) > 1: return False
           return check(node.left) and check(node.right)
       return check(n)
   ```
5. 普通 BST 每个节点存一个键值 + 两个指针，树高 ≈ log n 但「瘦高」，每次比较可能跨一个磁盘块（一次 IO）。B+ 树一个节点存很多键（填满一个磁盘页），树很「矮胖」，查找只要 3~4 次 IO 就能从千万级数据里定位；且叶子节点用链表串起来，范围查询（如 `BETWEEN`）极快。数据库要的是「少 IO」，不是「少比较」。
