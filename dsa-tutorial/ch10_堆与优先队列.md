# ch10 堆与优先队列

> 学习目标：理解**堆 = 用数组存的"部分有序"完全二叉树**（父 ≤ 子），掌握两个核心操作**上浮/下沉**的图示，会用 `heapq` 解决三类高频题——**TopK、动态中位数、合并 K 个有序序列**。

---

## 一、堆是什么：一颗"藏在数组里"的完全二叉树

堆有两个性质：
1. **完全二叉树**：除最后一层外全满，最后一层靠左填 → 能用数组连续存
2. **堆序**：小顶堆父 ≤ 子（堆顶 = 全局最小）；大顶堆父 ≥ 子（堆顶 = 全局最大）

```
小顶堆示例: [1, 2, 3, 5, 4]   （就是上面 heapq 实跑结果）

数组下标:     0   1   2   3   4
值:           1   2   3   5   4

画成树（下标 i 的左孩子 = 2i+1, 右孩子 = 2i+2, 父 = (i-1)//2）:

                   1(下标0)               ← 堆顶 = 最小
                 /        \
            2(下标1)     3(下标2)
           /      \
      5(下标3)   4(下标4)

验证堆序: 1≤2, 1≤3, 2≤5, 2≤4 ✅ 每个父都不大于子
```
```
父→子 与 子→父 的下标公式（必须背）:
  找左孩子: left  = 2*i + 1
  找右孩子: right = 2*i + 2
  找爸爸:   parent = (i-1) // 2
```
> 为什么堆"省钱"？因为完全二叉树**不需要指针**——下标就是"地址"。n 个元素只用一块连续数组。

## 二、手推图示：上浮（sift up）——新元素"爬"到该在的位置

往堆里插入：先放末尾，再一路和父比，比父小就换上去（小顶堆）。

```
往 [1, 5, 3, 8, 7] 插 2 （先放末尾下标5）

初始:      1              数组 [1,5,3,8,7,2]
         /   \                 ↑
        5     3             新元素 2 在末尾
       / \   /
      8   7 2

第1步: 2 的父是下标2(值3): 2<3 → 换
      1                   数组 [1,5,2,8,7,3]
     / \
    5   2
   / \ /
  8 7 3

第2步: 2 的新父是下标0(值1): 2<1? 否 → 停
      堆序恢复 ✅ 堆顶仍最小
```
```python
import heapq
h = [5, 2, 3, 1, 4]
heapq.heapify(h)
print("小顶堆数组:", h)          # [1, 2, 3, 5, 4]
print("弹出最小:", heapq.heappop(h), "→", h)   # 1 → [2,4,3,5]
heapq.heappush(h, 0)
print("push 0 后:", h)           # [0, 2, 3, 5, 4]
```
**预期输出：**
```
小顶堆数组: [1, 2, 3, 5, 4]
弹出最小: 1 → [2, 4, 3, 5]
push 0 后: [0, 2, 3, 5, 4]
```
> push = 放末尾 + 上浮，沿树高走 → **O(log n)**。注意弹出后数组变成 `[2,4,3,5]`（把末尾 4 提上来顶替堆顶再下沉），顺序不必"整齐"——只要满足堆序。

## 三、手推图示：下沉（sift down）——弹出堆顶后修复

弹出堆顶：把**最后一个元素**挪到堆顶，然后一路和较小的孩子换（小顶堆），直到比两个孩子都小。

```
堆 [1, 2, 3, 5, 4] 弹堆顶 1:

第0步: 取走 1，末尾 4 挪到堆顶（同时树少一个节点）
      4
     / \
    2   3        数组 [4,2,3,5]
   / \
  5  (4原位置已删)

第1步: 4 的孩子是 2 和 3，较小的 2 < 4 → 换
      2
     / \
    4   3        数组 [2,4,3,5]
   /
  5

第2步: 4 的孩子只剩 5: 4<5 不用换 → 停
      2
     / \
    4   3
   /
  5            数组 [2,4,3,5] ✅ 堆序恢复
```
> 下沉每层换一次 → O(log n)。**堆的任何修改都逃不出"上浮 or 下沉"两个动作**——这是堆全部原理的核心。

## 四、手推图示：heapify——把一个乱数组变成堆（O(n)）

```
把 [3, 9, 2, 1, 4, 5] 变成小顶堆:
从最后一个"非叶子"开始逐个下沉（从下往上）→ 结果 [1, 3, 2, 9, 4, 5]

       3                 3                 1
      / \               / \               / \
     9   2   下沉9     1   2   下沉3     3   2
    / \ / \           / \ / \          / \ / \
   1  4 5           9  4 5           9 4 5

数组: [3,9,2,1,4,5] → 下标2是2(叶子区上边)… 逐个处理 → [1,3,2,9,4,5]
```
```python
raw = [3, 9, 2, 1, 4, 5]
h2 = raw[:]
heapq.heapify(h2)
print(f"heapify({raw}) -> {h2}")    # heapify([3,9,2,1,4,5]) -> [1, 3, 2, 9, 4, 5]
```
**预期输出：** `heapify([3, 9, 2, 1, 4, 5]) -> [1, 3, 2, 9, 4, 5]`
> 数学上 heapify 是 O(n)（不是 O(n log n)）——因为越往下的节点越多但下沉距离越短，总工作量是收敛的。面试能说出"heapify 是 O(n)"会加分。

## 五、套路一：TopK —— 用大小为 K 的小顶堆"踢走最小的"

题目：从海量数据里找**最大的 K 个**。不排序全量，只维护 K 个候选。

```
思路（找最大K个 → 用小顶堆）:
  堆里永远只留"当前见过的最大的 K 个"，堆顶是其中最小的（守门员）
  新数 > 守门员 → 踢掉守门员，新数进门
  新数 ≤ 守门员 → 没资格，跳过

示例: nums=[41,19,50,83,6,...], K=3
  41 → 堆 [41]
  19 → [19,41]
  50 → [19,41,50]
  83 → 83>19 踢19 → [41,50,83]
  6  → 6<41 跳过
  ...
  最后堆 = [68,83,74] → 排序输出 [83,74,68] ✅

图（K=3 的小顶堆滚动）:
   [19] → [19,41] → [19,41,50] → 83进来踢19 → [41,50,83]
                                                        ↑守门员=41
```
```python
import heapq, random

def topk(nums, k):
    h = []                              # 小顶堆，容量 K
    for x in nums:
        if len(h) < k:
            heapq.heappush(h, x)        # 没满直接进
        elif x > h[0]:                  # 比守门员大
            heapq.heapreplace(h, x)     # 弹出最小的，换入 x
    return sorted(h, reverse=True)

random.seed(7)
nums = [random.randint(0, 100) for _ in range(20)]
print("数据:", nums)
print("最大3个:", topk(nums, 3), "| 正确:", sorted(nums, reverse=True)[:3])
```
**预期输出：**
```
数据: [41, 19, 50, 83, 6, 9, 68, 12, 46, 74, 7, 64, 27, 4, 11, 55, 53, 8, 30, 11]
最大3个: [83, 74, 68] | 正确: [83, 74, 68]
```
> 复杂度：n 个数各做一次 O(log K) 的堆操作 → **O(n log K)**。K 远小于 n 时（比如 100 亿里取 top 10）比全排序 O(n log n) 省得多，而且**不用一次性装下全部数据**（流式处理）。

## 六、套路二：动态中位数 —— 大顶堆 + 小顶堆

题目：数据流不断进来，随时问中位数。排序每次 O(n log n) 太慢 → 双堆法 O(log n) 每次。

```
设计: 把数据分成两半
  small（大顶堆，存负值实现）= 较小的一半，堆顶 = 这半的最大
  large（小顶堆）           = 较大的一半，堆顶 = 这半的最小
  中位数 = 两堆顶的平均 或 元素多的那堆的堆顶

示例: 依次来 5, 15, 1, 3

add 5 :  small=[-5] large=[]   → 中位 5
add 15:  small=[-15,-5]? 平衡 → large=[15] small=[-5] → (5+15)/2=10.0
add 1 :  small=[-5,-1] large=[15] → 堆顶 5 → 中位 5
add 3 :  平衡后 small=[-5,-3] large=[15] → (5+15)/2=10? 不对…

正确平衡规则（见代码）: 保证 |small| - |large| ≤ 1 且 small 顶 ≤ large 顶
add 3 后: small 存 [5,3,1]? 看代码推 → 中位 4.0（排序后 [1,3,5,15] 中位 (3+5)/2=4）
```
```python
import heapq

class MedianFinder:
    def __init__(self):
        self.small = []     # 大顶堆: 存 -x，顶 = 较小半的最大
        self.large = []     # 小顶堆: 顶 = 较大半的最小
    def add(self, x):
        heapq.heappush(self.small, -x)          # 先入小半
        # 修正1: 小半顶不能 > 大半顶
        if self.small and self.large and -self.small[0] > self.large[0]:
            heapq.heappush(self.large, -heapq.heappop(self.small))
        # 修正2: 两半数量差 ≤ 1
        if len(self.small) > len(self.large) + 1:
            heapq.heappush(self.large, -heapq.heappop(self.small))
        if len(self.large) > len(self.small):
            heapq.heappush(self.small, -heapq.heappop(self.large))
    def median(self):
        if len(self.small) > len(self.large):   # 奇数 → 小半多一个
            return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2   # 偶数 → 平均

mf = MedianFinder()
for x in [5, 15, 1, 3]:
    mf.add(x)
    print(f"add {x}: median={mf.median()}")
```
**预期输出：**
```
add 5: median=5
add 15: median=10.0
add 1: median=5
add 3: median=4.0
```
**验证**：数据排序 `[1,3,5,15]`，中位 (3+5)/2=4.0 ✅；`[1,5,15]` 中位 5 ✅。复杂度：每次 add 做常数次 O(log n) 堆操作 → **O(log n)**。

## 七、套路三：合并 K 个有序序列 —— "多路归并"

题目：`[[1,4,5],[1,3,4],[2,6]]` 合成一个有序列表。

```
思路: 把 K 个序列的"当前队头"放进小顶堆，每次弹出最小者，
      再从那个序列取下一个补进堆 → 永远只比 K 个队头

堆: [(1,行0,列0), (1,行1,列0), (2,行2,列0)]
弹 1(行0) → 结果[1]; 行0取4入堆 → [(1,行1),(2,行2),(4,行0)]
弹 1(行1) → [1,1]; 行1取3入堆 → [(2,行2),(3,行1),(4,行0)]
弹 2(行2) → [1,1,2]; 行2取6 → [(3,行1),(4,行0),(6,行2)]
弹 3 → ... 依次得 [1,1,2,3,4,4,5,6] ✅

图形:
   行0: 1 → 4 → 5 ──┐
   行1: 1 → 3 → 4 ──┼── 每次从堆顶取一个，再从对应行补一个
   行2: 2 → 6 ──────┘
```
```python
def merge_k(lists):
    h = []
    for i, lst in enumerate(lists):
        if lst:
            heapq.heappush(h, (lst[0], i, 0))   # (值, 哪个序列, 第几个)
    out = []
    while h:
        val, i, j = heapq.heappop(h)            # 取全局最小队头
        out.append(val)
        if j + 1 < len(lists[i]):               # 同一序列下一个补进
            heapq.heappush(h, (lists[i][j+1], i, j+1))
    return out

print(merge_k([[1,4,5],[1,3,4],[2,6]]))         # [1,1,2,3,4,4,5,6]
```
**预期输出：** `[1, 1, 2, 3, 4, 4, 5, 6]`
> 复杂度：总 N 个元素，每个进出堆 O(log K) → **O(N log K)**。比"两两合并"（ch06 练习 3）更通用，也是**外部排序/数据库归并**的地基。

## 八、堆 vs 其他"取最值"方案

```
操作          排序数组    链表     平衡BST     堆
取最大/最小   O(1)取端   O(1)取端  O(log n)   O(1)看堆顶
插入          O(n)搬移   O(1)头插  O(log n)   O(log n)
删除最大/最小 O(n)      O(1)删头  O(log n)   O(log n)
找任意值      O(log n)   O(n)      O(log n)   ❌不支持
```
> 堆的定位：**只擅长"反复取最值 + 插入"**（优先队列 = 任务调度、Dijkstra、哈夫曼）。**它不擅长"查找任意元素"**——要查任意值用哈希/BST。

## 九、小结

1. 堆 = 完全二叉树 + 堆序（父≤子 小顶 / 父≥子 大顶），用数组连续存储
2. 下标公式：left=2i+1, right=2i+2, parent=(i-1)//2
3. 两个核心动作：**上浮**（插入：末尾爬上去）、**下沉**（弹出：末尾提顶再沉下去），都 O(log n)
4. `heapq` 是小顶堆；要**大顶堆就存负值**
5. heapify 建堆 O(n)
6. 三套路：**TopK**（K 容量小顶堆，O(n log K)）、**动态中位数**（大+小双堆）、**合并 K 个有序**（多路归并 O(N log K)）
7. Python 里 `heapq` 的 heappush/heappop/heapify/heapreplace 一套搞定

## 十、练习 5 题

### 练习 1：手推插入

小顶堆 `[1, 3, 2, 6, 5, 7]` 插入 0，画出上浮过程与最终数组。

**答案：** 0 放末尾下标6；父=下标2(值2)：0<2 换 → `[1,3,0,6,5,7,2]`；新父=下标0(值1)：0<1 换 → `[0,3,1,6,5,7,2]`；到顶停。**最终 `[0,3,1,6,5,7,2]`**（堆顶 0 ✅）。

### 练习 2：找最小的 K 个（反着用）

`[7,10,4,3,20,15]` 找最小的 2 个 → [3,4]。用大顶堆（存负值）维护 K 个最小。

**答案：**
```python
def bottomk(nums, k):
    h = []                       # 大顶堆: 存负值
    for x in nums:
        if len(h) < k:
            heapq.heappush(h, -x)
        elif x < -h[0]:          # 比"最大的守门员"小才值得进
            heapq.heapreplace(h, -x)
    return sorted(-v for v in h)

print(bottomk([7,10,4,3,20,15], 2))    # [3, 4]
```
**预期输出：** `[3, 4]`
**解析**：找最小 K 个用大顶堆（守门员 = K 个候选里最大的）；新数比守门员**小**才替换。手推：7→[7]；10→[10,7]；4→4<10踢10→[7,4]；3→3<7→[4,3]；20、15 都比守门员 4 大 → 跳过 → [3,4]。

### 练习 3：数组第 K 大元素（heapq.nlargest 一行版）

**答案：**
```python
import heapq
def find_kth_largest(nums, k):
    return heapq.nlargest(k, nums)[-1]

print(find_kth_largest([3,2,1,5,6,4], 2))     # 5
print(find_kth_largest([3,2,3,1,2,4,5,5,6], 4))  # 4
```
**预期输出：** `5` `4`
**解析**：`nlargest(k)` 内部就是 K 容量小顶堆（TopK 套路）；取最后一个 = 第 K 大。另一解是 ch06 快速选择 O(n)，堆解 O(n log K)。

### 练习 4：堆排序手推

用小顶堆对 `[4,1,3,2]` 排序（堆排=反复弹堆顶）。写出过程。

**答案：** heapify → `[1,4,3,2]`；弹 1 → 剩余 `[2,4,3]`；弹 2 → `[3,4]`；弹 3 → `[4]`；弹 4 → 弹出序 `[1,2,3,4]` = 升序 ✅。注意：小顶堆**弹出来天然升序**（每次弹全局最小）。若要不稳定也没关系——堆排本来就不稳定。

### 练习 5：任务调度（最小执行时间）

有任务耗时 `[3, 1, 2, 5, 4]`，两台机器并行，每次把最短的任务派给当前最闲的机器，求最短完工时间（贪心 + 堆）。

**答案：**
```python
def min_finish(times, machines):
    heapq.heapify(times)          # 小顶堆按耗时取最短任务
    loads = [0] * machines        # 每台机器的负载，用小顶堆取最闲的
    h = [0] * machines            # 维护"机器空闲时间"的堆
    for t in sorted(times, reverse=True):   # 长的先派（贪心经典）
        load = heapq.heappop(h)   # 最闲的机器
        heapq.heappush(h, load + t)
    return max(h)

print(min_finish([3,1,2,5,4], 2))    # 8  (方案: 5+3=8 与 4+2+1=7)
```
**预期输出：** `8`
**解析**：任务从长到短派给当前负载最小的机器。手推：5 派机器A(A=5)；4 派机器B(B=4)；3 派A(A=8)；2 派B(B=6)；1 派B(B=7)。完工 max=8 ✅。（任务降序是关键——短的用来"填缝"。）
