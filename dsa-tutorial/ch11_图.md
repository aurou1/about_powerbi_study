# ch11 图

> 学习目标：理解图的两种表示（邻接表/邻接矩阵）；能手写 DFS、BFS、拓扑排序、Dijkstra 最短路、并查集。图是「关系」的通用语言：社交网络、依赖、路网、组织层级全是图。

## 一、图怎么存

- **邻接表**（Python 用 `dict[str, list]`）：每个节点存它的邻居。省空间（稀疏图），遍历邻居 O(度)。
- **邻接矩阵**（`list[list[bool]]`）：`matrix[u][v]` 表示是否相连。查边 O(1)，但占 O(V²)，稠密图才划算。

```python
graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [], 'E': [], 'F': []
}
```

```
    A
   / \
  B   C
 / \   \
D   E   F
```

## 二、DFS（深度优先，栈/递归）

一条路走到黑，走不通回退。用递归 + `visited` 集合。

```python
def dfs(graph, start, visited=None):
    if visited is None: visited = set()
    visited.add(start)
    order = [start]
    for nxt in graph[start]:
        if nxt not in visited:
            order += dfs(graph, nxt, visited)
    return order

print("DFS:", dfs(graph, 'A'))
```

**预期输出：**

```text
DFS: ['A', 'B', 'D', 'E', 'C', 'F']
```

> A→B→D（D 没邻居）→回 E→回 C→F。DFS 适合「找路径、连通性、拓扑」。

## 三、BFS（广度优先，队列）

一层一层扩（ch04 讲过队列驱动）。

```python
import collections

def bfs(graph, start):
    seen = {start}; q = collections.deque([start]); order = []
    while q:
        node = q.popleft(); order.append(node)
        for nxt in graph[node]:
            if nxt not in seen:
                seen.add(nxt); q.append(nxt)
    return order

print("BFS:", bfs(graph, 'A'))
```

**预期输出：**

```text
BFS: ['A', 'B', 'C', 'D', 'E', 'F']
```

> BFS 第一次碰到某个节点，走的一定是最短路径（边数最少）。**「最短路径」和「层序」都靠 BFS。**

## 四、拓扑排序（依赖顺序）

有向无环图（DAG）里，把「前置任务」排在「依赖它的任务」之前。Kahn 算法：不断找「入度为 0」的节点输出，删掉它的边。

```python
def topo_sort(graph):
    indeg = {n: 0 for n in graph}
    for u in graph:
        for v in graph[u]:
            indeg[v] += 1
    q = collections.deque([n for n in graph if indeg[n] == 0])
    out = []
    while q:
        u = q.popleft(); out.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return out if len(out) == len(graph) else None   # None = 有环

# 邻接：graph[u] = 必须在 u 之后做的事（u 是 v 的前置）
deps = {'shirt': ['tie'], 'pants': ['belt'], 'belt': ['jacket'], 'tie': ['jacket'], 'jacket': []}
print("穿衣拓扑:", topo_sort(deps))
print("有环:", topo_sort({'A': ['B'], 'B': ['C'], 'C': ['A']}))   # None
```

**预期输出：**

```text
穿衣拓扑: ['shirt', 'pants', 'tie', 'belt', 'jacket']
有环: None
```

> 穿衣服：先穿衬衫/裤子，再系领带/皮带，最后穿外套。**返回 None 表示有环**（死锁检测）。你 FDE 做「任务编排 / ETL 依赖」就是拓扑排序。

## 五、Dijkstra 最短路（带权）

求「从源点到所有点的最短距离」。核心：**用最小堆每次取当前距离最小的节点扩展**（贪心 + 正确性由非负权保证）。

```python
import heapq

def dijkstra(graph, src):
    dist = {n: float('inf') for n in graph}
    dist[src] = 0
    h = [(0, src)]
    while h:
        d, u = heapq.heappop(h)
        if d > dist[u]: continue        # 过期堆顶，跳过
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(h, (dist[v], v))
    return dist

wg = {
    'A': [('B', 4), ('C', 1)],
    'B': [('D', 1)],
    'C': [('B', 2), ('D', 5)],
    'D': []
}
print("Dijkstra A:", dijkstra(wg, 'A'))
```

**预期输出：**

```text
Dijkstra A: {'A': 0, 'B': 3, 'C': 1, 'D': 4}
```

> A→C(1)→B(2) 共 3 比直达 A→B(4) 更短！所以 B 距离 3 不是 4。D 走 A→C→B→D = 1+2+1 = 4。**这就是导航软件算路线的算法**（高德/百度）。负权边要用 Bellman-Ford，这里不展开。

## 六、并查集（连通分量 / 团伙归类）

「动态连通性」：不断加边，随时问「a 和 b 连通吗」。两个操作：找根 `find`、合并 `union`，路径压缩后接近 O(1)。

```python
class UnionFind:
    def __init__(self, n):
        self.p = list(range(n))
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]      # 路径压缩
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra != rb: self.p[ra] = rb

edges = [(0, 1), (2, 3), (1, 2)]
uf = UnionFind(5)
for a, b in edges: uf.union(a, b)
print("0与3同组:", uf.find(0) == uf.find(3), "| 0与4同组:", uf.find(0) == uf.find(4))
```

**预期输出：**

```text
0与3同组: True | 0与4同组: False
```

> 并查集一眼看出 {0,1,2,3} 连通、{4} 孤立。应用场景：社交网络的「朋友圈」、Kruskal 最小生成树、 islands 计数（岛屿数量题）。

## 七、图算法速查

| 算法 | 解决 | 复杂度 | 用到的结构 |
|---|---|---|---|
| DFS | 连通性、路径、拓扑 | O(V+E) | 栈/递归 |
| BFS | 最短路（无权）、层序 | O(V+E) | 队列 |
| 拓扑排序 | 依赖顺序、死锁检测 | O(V+E) | 队列 + 入度 |
| Dijkstra | 单源最短路（非负权） | O((V+E)log V) | 最小堆 |
| 并查集 | 动态连通分量 | ≈O(1) | 数组 + 路径压缩 |

## 小结

- 邻接表省空间（稀疏图），邻接矩阵查边快（稠密图）。
- DFS 递归走深度，BFS 队列走广度（最短路径）。
- 拓扑排序排依赖、检测环；Dijkstra 算带权最短路；并查集管连通。
- 这些就是「关系数据」的通用工具——FDE 处理客户层级、任务依赖、路网全用得上。

   ```python
   def has_cycle(graph):
       seen = set()
       def dfs(u, parent):
           seen.add(u)
           for v in graph[u]:
               if v not in seen: 
                   if dfs(v, u): return True
               elif v != parent:        # 遇到已访问的非父节点=环
                   return True
           return False
       for n in graph:
           if n not in seen and dfs(n, None): return True
       return False
   ```
