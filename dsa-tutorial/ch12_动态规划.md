# ch12 动态规划

> 学习目标：掌握 DP 的四步法（状态定义 → 转移方程 → base case → 填表/记忆化）；能手写 0/1 背包、LIS、编辑距离、股票买卖。DP 是「把重叠子问题记下来」的递归升级版，面试难度天花板之一。

## 一、DP 是什么

ch06 朴素斐波那契慢，因为**子问题重复算**。DP = **用一个表把子问题答案存起来，算过不再算**。本质是「递归 + 记忆化 + 状态定义」。

四步法（背下来）：
1. **定义状态** `dp[?]` 表示什么。
2. **写转移方程**：`dp[i]` 怎么由更小的 `dp` 得到。
3. **base case**：最小的子问题直接给值。
4. **填表顺序 / 或记忆化递归**。

## 二、0/1 背包（DP 的标杆）

n 个物品，每个有重量和价值，**每个最多选一次**，容量 cap 下最大价值。

```python
def knapsack(weights, values, cap):
    n = len(weights)
    dp = [[0] * (cap + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        w, v = weights[i - 1], values[i - 1]
        for c in range(cap + 1):
            dp[i][c] = dp[i - 1][c]                     # 不选第 i 个
            if c >= w:
                dp[i][c] = max(dp[i - 1][c], dp[i - 1][c - w] + v)   # 选
    # 还原选了哪些
    c = cap; chosen = []
    for i in range(n, 0, -1):
        if dp[i][c] != dp[i - 1][c]:
            chosen.append(i - 1); c -= weights[i - 1]
    return dp[n][cap], sorted(chosen)

w = [2, 3, 4, 5]; v = [3, 4, 5, 6]; cap = 8
val, items = knapsack(w, v, cap)
print(f"背包 cap={cap} 最大价值={val} 选物品下标={items}")
```

**预期输出：**

```text
背包 cap=8 最大价值=10 选物品下标=[1, 3]
```

> 选下标 1（重3价4）和 3（重5价6），重量 8 正好塞满，价值 10。dp 表是「自底向上」填的（先小容量、小物品）。**背包问题是资源分配的通用模型**：预算有限挑项目、时间有限排任务。

## 三、爬楼梯（最小状态 DP）

ch06 用记忆化写过。DP 表版只要两个变量滚。

```python
def climb(n):
    if n < 2: return 1
    a, b = 1, 1
    for _ in range(2, n + 1):
        a, b = b, a + b        # 滚动，O(1) 空间
    return b

print("climb(5)=", climb(5), "| climb(10)=", climb(10))
```

**预期输出：**

```text
climb(5)= 8 | climb(10)= 89
```

> `dp[i] = dp[i-1] + dp[i-2]`。只用到前两个，所以不存整张表，滚动变量即可——**DP 常能「降维」省空间**。

## 四、最长递增子序列 LIS

```python
def lis(a):
    dp = [1] * len(a)
    for i in range(len(a)):
        for j in range(i):
            if a[j] < a[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

print("LIS [10,9,2,5,3,7,101,18]:", lis([10, 9, 2, 5, 3, 7, 101, 18]))
```

**预期输出：**

```text
LIS [10,9,2,5,3,7,101,18]: 4
```

> `[2,3,7,101]` 或 `[2,5,7,101]` 长度 4。这是「找最长合法子序列」的模板，可优化到 O(n log n)（用 ch10 的二分），面试先写 O(n²) 再优化。

## 五、编辑距离（二维 DP）

把一个字符串变成另一个，最少删/插/改几次。经典二维 DP。

```python
def edit_distance(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1): dp[i][0] = i
    for j in range(n + 1): dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
    return dp[m][n]

print("编辑距离 'horse'->'ros':", edit_distance("horse", "ros"))
```

**预期输出：**

```text
编辑距离 'horse'->'ros': 3
```

> horse→rorse（改 h→r）→rose（改 r→o）→ros（删 e），3 步。DNA 比对、拼写纠错、GitHub diff 全用这个思想。

## 六、股票买卖（一次交易）

```python
def max_profit(prices):
    if not prices: return 0
    min_p, best = prices[0], 0
    for p in prices:
        min_p = min(min_p, p)
        best = max(best, p - min_p)
    return best

print("股票 [7,1,5,3,6,4] 最大利润:", max_profit([7, 1, 5, 3, 6, 4]))
```

**预期输出：**

```text
股票 [7,1,5,3,6,4] 最大利润: 5
```

> 第 2 天买（1）第 5 天卖（6），赚 5。遍历时维护「历史最低价」，O(n)。这其实是 DP 的状态压缩版（状态=「是否持有」）。

## 七、DP 解题 checklist

1. 问题能不能拆成「子问题」？子问题是不是**重叠**（重复算）？
2. 没有后效性（未来的选择不依赖过去的细节，只依赖状态）？
3. 状态怎么定义最简单？维度尽量少。
4. 先写**记忆化递归**（好想），再改**自底向上填表**（快、省栈）。

## 小结

- DP = 记忆化 + 状态表，专治重叠子问题。
- 四步法：状态 / 转移 / base / 填表。
- 背包、LIS、编辑距离、股票 = DP 四大样题。
- 能滚动变量就降维省空间；先递归后填表。

## 练习

1. **（背包）** 把上面背包的 `cap` 改成 5，`w=[2,3,4,5], v=[3,4,5,6]`，最大价值多少？手推 dp 表前 2 行。
2. **（LIS）** `lis([1,3,2,4])` 是多少？写出 dp 数组。
3. **（编辑距离）** `edit_distance("kitten","sitting")` 是多少？（经典例子，答案 3）
4. **（状态压缩）** 股票题为什么只用一个 `min_p` 变量就够了？它隐含了什么 DP 状态？
5. **（实战联想）** 你 `sql-tutorial` 里「客户等级 241/149/83/27 人、折扣 0.02/0.08/0.15/0.20」。若预算有限要给高等级客户发权益，等价于什么 DP 模型？（提示：背包——等级=物品，人数=重量，预算=容量）

**答案与解析**

1. cap=5：最优选下标 0（重2价3）+ 下标 1（重3价4）= 重量5 价值7。dp 表：dp[0][*]=0；dp[1][c]=max(dp[0][c], dp[0][c-2]+3)（物品0重2价3），c≥2 时为 3。
2. `lis([1,3,2,4])`：dp=[1,2,2,3]（1→1, 3→2, 2→2(接1), 4→3(接3或2)），最长 3（如 1,3,4）。
3. kitten→sitten（k→s）+ sitten→sittin（e→i）+ sittin→sitting（加 g）= 3。
4. `min_p` 隐含状态「到第 i 天为止的历史最低买入价」，`best` 隐含「当前最大利润」。本质上是 `dp[i] = max(dp[i-1], price[i]-min_p[i])`，但 min_p 和 best 各一个变量滚完了，O(1) 空间。
5. 等价于 **0/1 背包**：每个「等级」是一个物品，其「人数」是重量（占预算/人力），「价值」可以是该等级的产出或留存提升；在总预算（容量）内选等级组合使总价值最大。人数和价值可能不成比例，所以不能直接贪心，要用 DP。
