## 一、见题知法：拿到一道题先问 5 个问题

面试/刷题不要凭感觉，按下面的决策流走：

```
拿到题目
  │
  ├─ ① 数据规模多大?
  │     n≤20        → 指数级(回溯/状态压缩)可行
  │     n≤10⁵       → O(n) 或 O(n log n)
  │     n≤10⁸       → 必须 O(n) 以下 / O(log n) 数学
  │
  ├─ ② 是"数组/字符串"线性结构吗?
  │     ├─ 有序+查找 → 二分(ch08)
  │     ├─ 连续子数组/子串 → 滑动窗口 或 前缀和(ch02)
  │     ├─ 两两配对/比大小 → 双指针(ch02)
  │     ├─ 下一个更大/更小 → 单调栈(ch04)
  │     └─ 查重/计数/见没见过 → 哈希(ch05)
  │
  ├─ ③ 是"关系/依赖/路径"吗?
  │     ├─ 最少步数/分层 → BFS(ch11)
  │     ├─ 一条路/回溯所有解 → DFS / 回溯(ch11/ch13)
  │     ├─ 依赖顺序/判环 → 拓扑排序(ch11)
  │     ├─ 最短路径(有权) → Dijkstra(ch11)
  │     └─ 连通性 → 并查集(ch11)
  │
  ├─ ④ 要"最优值"吗?
  │     ├─ 能证明局部最优=全局 → 贪心(ch13)
  │     └─ 子问题重叠/可拆 → 动态规划(ch12)
  │
  └─ ⑤ 要"最大/最小 K 个 / 动态中位数"吗?
        → 堆(ch10)
```

## 二、八大高频综合题（题题带图）

### 题 1：最大子数组和（Kadane 算法）

题目：`[-2,1,-3,4,-1,2,1,-5,4]` 找**和最大**的连续子数组 → 6（`[4,-1,2,1]`）。

```
核心状态: cur = "以当前元素结尾的最大子数组和"
         cur = max(元素本身, cur+元素)   ← 前面的和拖后腿就甩掉
         best = 全程 cur 的最大值

逐元素手推:
元素      cur(max(x, cur+x))    best
-2        max(-2,0-2)=-2        -2
 1        max(1,-2+1)=1          1     ← 甩掉 -2, 重新开始
-3        max(-3,1-3)=-2         1
 4        max(4,-2+4)=4          4     ← 又是新开始
-1        max(-1,4-1)=3          4
 2        max(2,3+2)=5           5
 1        max(1,5+1)=6           6     ✅ best=6
-5        max(-5,6-5)=1          6
 4        max(4,1+4)=5           6

图（cur 的起伏）:
  值: -2   1  -3   4  -1   2   1  -5   4
  cur: -2   1  -2   4   3   5   6   1   5
                     ↑从4重新起跑, 一路爬到6
```
```python
def max_subarray(nums):
    cur = best = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)      # 要么续前缘, 要么重开
        best = max(best, cur)
    return best

print(max_subarray([-2,1,-3,4,-1,2,1,-5,4]))    # 6
print(max_subarray([-1,-2]))                    # -1  (全负→取最大的)
```
**预期输出：** `6` `-1`
复杂度 O(n)、空间 O(1)。这是"DP 降维成滚动变量"的活教材（ch12 股票题同理）。

### 题 2：最长回文子串（中心扩展）

题目：`"babad"` 最长回文子串 → `"bab"`（或 `"aba"`）；`"cbbd"` → `"bb"`。

```
回文 = 正读反读一样 → 以每个位置为中心向两边扩
中心有两种: 单字符中心 "a" 和 双字符中心 "aa"

手推 "babad" 以 i=1 的 'a' 为中心(单中心):
  l=1,r=1: 'a'=='a' → 扩
  l=0,r=2: 'b'=='b' → 扩 → "bab" 长3
  l=-1,r=3: 越界停 → 得 "bab"
以 i=1,o=1(双中心 'ab'): 不等 → 跳过
全部中心试完, 最长 = "bab"(3)

图（中心扩展）:
  b a b a d
    ↑ 中心a
  b←a→b  对称! → bab
```
```python
def longest_pal(s):
    def expand(l, r):                  # 从中心向两边扩
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1; r += 1
        return s[l+1:r]                # 回退一格就是回文
    best = ""
    for i in range(len(s)):
        for o in (0, 1):               # 单中心 / 双中心
            t = expand(i, i+o)
            if len(t) > len(best): best = t
    return best

print(longest_pal("babad"))    # bab
print(longest_pal("cbbd"))     # bb
```
**预期输出：** `bab` `bb`
复杂度 O(n²)（n 个中心 × 每次扩 O(n)），比暴力 O(n³) 好。

### 题 3：前 K 个高频单词（堆 + 排序键）

题目：统计词频，返回前 K 个；**同频按字典序**。`["i","love","leetcode","i","love","coding"], k=2` → `["i","love"]`。

```
两步:
① Counter 计数:  i:2, love:2, leetcode:1, coding:1
② 堆/排序: 先按 -次数, 再按 词(字典序) 排

排序键: (-count, word)   ← 次数降序 + 词升序
堆里存 (-count, word), 小顶堆自动按这个顺序弹
```
```python
import heapq
from collections import Counter

def top_k_words(words, k):
    cnt = Counter(words)
    h = []
    for w, c in cnt.items():
        heapq.heappush(h, (-c, w))       # 负次数 → 高词频优先
    return [heapq.heappop(h)[1] for _ in range(k)]

print(top_k_words(["i","love","leetcode","i","love","coding"], 2))
print(top_k_words(["the","day","is","sunny","the","the","the","sunny","is","is"], 4))
```
**预期输出：**
```
['i', 'love']
['the', 'is', 'sunny', 'day']
```
> 记忆：**Python 元组排序 = 逐个元素比**。要"次数多优先、同次字典序小优先"，就用 `(-次数, 词)`——负号反转第一键。

### 题 4：买卖股票的最佳时机（一次交易）

题目：`[7,1,5,3,6,4]` 只能买卖一次，最大利润 → 5（1 买 6 卖）。

```
核心: 遍历时记录"见过的最低买价", 每天算"当天卖能赚多少", 取最大

手推:
价格  7  1  5  3  6  4
最低  7  1  1  1  1  1     ← min(之前最低, 今天)
利润  -  0  4  2  5  3     ← 今天 - 最低
best = 5 ✅（第5天卖: 6-1=5）

图:
价格: 7  1     5     3     6     4
            ↑买   ↑      ↑卖 5   ↑
           最低价1        赚 6-1=5
```
```python
def max_profit(prices):
    buy = float('inf')
    profit = 0
    for p in prices:
        buy = min(buy, p)            # 更新历史最低买价
        profit = max(profit, p-buy)  # 今天卖赚多少
    return profit

print(max_profit([7,1,5,3,6,4]))     # 5
print(max_profit([7,6,4,3,1]))       # 0  (一直跌 → 不买不卖)
```
**预期输出：** `5` `0`
复杂度 O(n)、O(1)。进阶版（允许多次交易/带冷冻期）本质就是 ch12 的 DP 状态机。

### 题 5：旋转排序数组查找（二分变体）

题目：`[4,5,6,7,0,1,2]` 由有序数组旋转而来，找 `0` → 下标 4；找 `3` → -1。

```
旋转数组特点: 从某处断开, 但"总有一半是有序的"
二分每步: 判断 mid 在左半有序区还是右半有序区 → 在有序区里定方向

手推找 0:
lo=0 hi=6 mid=3: a[3]=7; a[lo]=4 ≤ 7 → 左半[4..7]有序
    target=0 不在 [4,7] 内 → 去右半 lo=4
lo=4 hi=6 mid=5: a[5]=1; a[4]=0 ≤ 1 → 左半[0..1]有序
    target=0 在 [0,1] 内 → hi=5
lo=4 hi=5 mid=4: a[4]=0 == target → 返回 4 ✅

图:
  索引: 0  1  2  3  4  5  6
  值:   4  5  6  7  0  1  2
                ↑mid=7        ↑target=0 在右半 → 搜右
                      ↑mid=1
                   ↑mid=0 命中!
```
```python
def search_rotated(a, t):
    lo, hi = 0, len(a)-1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == t: return mid
        if a[lo] <= a[mid]:               # 左半有序
            if a[lo] <= t < a[mid]:       # t 落在左半
                hi = mid - 1
            else: lo = mid + 1            # 否则去右半
        else:                             # 右半有序
            if a[mid] < t <= a[hi]:
                lo = mid + 1
            else: hi = mid - 1
    return -1

print(search_rotated([4,5,6,7,0,1,2], 0))    # 4
print(search_rotated([4,5,6,7,0,1,2], 3))    # -1
```
**预期输出：** `4` `-1`
复杂度 O(log n)。**判断"哪半有序"是旋转二分的灵魂**。

### 练习 3：打家劫舍（DP 入门）

`[2,7,9,3,1]` 相邻不能偷，最大偷多少 → 12（2+9+1）。

**答案：**
```python
def rob(nums):
    prev2, prev1 = 0, 0          # prev2=前2家最优, prev1=前1家最优
    for x in nums:
        cur = max(prev1, prev2 + x)   # 不偷这家 或 偷这家+前2家
        prev2, prev1 = prev1, cur
    return prev1

print(rob([2,7,9,3,1]))    # 12
```
**预期输出：** `12`
**解析**：状态 = 到第 i 家时的最大金额。手推：2→max(0,2)=2；7→max(2,0+7)=7；9→max(7,2+9)=11；3→max(11,7+3)=11；1→max(11,11+1)=12。O(n)、O(1)。

### 练习 4：判断链表是否有环（快慢指针）

`1→2→3→4→2`（4 指回 2）→ True。

**答案：**（见 ch03）快指针每次 2 步、慢 1 步，相遇即有环：
```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next          # 1 步
        fast = fast.next.next     # 2 步
        if slow is fast: return True   # 追上了 → 有环
    return False
```
**预期输出：** `True`（有环）/ `False`（无环）。**决策路径**：链上"循环"问题 → 快慢指针 Floyd 判圈。
