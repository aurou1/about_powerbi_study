# ch14 综合实战与面试套路

> 学习目标：把 13 章串成一张「见题知法」的决策图；拿到复杂度速查表；知道怎么刷题、怎么把算法用在 FDE 岗位上。这是收尾章，也是你以后回来翻的那一页。

## 一、见题知法：决策图

拿到一道题，按这个顺序想：

```
问题是什么 →
├─ 要「查/存」很多东西？            → 哈希表（ch05）：两数之和、计数、去重、LRU
├─ 数据「有序」或要「最值」？
│   ├─ 找某个值/边界               → 二分（ch08）：精确找、边界、二分答案
│   ├─ 取 TopK / 中位数 / 合并K路  → 堆（ch10）
│   └─ 整体排序                    → 排序（ch07）
├─ 是「线性关系」要扫描？
│   ├─ 两端/窗口                  → 双指针/滑动窗口（ch02）
│   └─ 后进先出/层序扩散           → 栈/队列（ch04）
├─ 是「节点串起来」？
│   ├─ 频繁头插删/未知长度         → 链表（ch03）
│   └─ 层级/父子                  → 树（ch09）
├─ 是「关系网」？
│   ├─ 连通/最短路/依赖           → 图（ch11）：DFS/BFS/拓扑/Dijkstra/并查集
├─ 要「所有解」或「约束满足」？
│   ├─ 能证明局部最优？           → 贪心（ch13）：区间调度、硬币
│   └─ 要穷举                     → 回溯（ch13）：子集/排列/N皇后
└─ 有「重叠子问题」？
    └─ 动态规划（ch12）：背包/LIS/编辑距离/股票
        └─ 问题能拆、子问题重叠、无后效 → 先记忆化递归，再改填表
```

> 记住一句话：**数组/哈希是地基，栈/队列/链表是零件，树/图/堆是结构，贪心/回溯/DP 是组合这些结构的「策略」。** ch06 递归是它们的通用实现手段。

## 二、复杂度速查（贴墙版）

| 结构/算法 | 时间 | 空间 | 章 |
|---|---|---|---|
| 数组随机访问 | O(1) | O(1) | ch02 |
| 哈希 增/查/删 | O(1) 均摊 | O(n) | ch05 |
| 二分查找 | O(log n) | O(1) | ch08 |
| 快排/归并/堆排 | O(n log n) | O(log n)/O(n)/O(1) | ch07 |
| 冒泡/插入/选择 | O(n²) | O(1) | ch07 |
| 堆 TopK | O(n log k) | O(k) | ch10 |
| BFS/DFS | O(V+E) | O(V) | ch11 |
| Dijkstra | O((V+E)log V) | O(V) | ch11 |
| 0/1 背包 | O(n·cap) | O(n·cap) | ch12 |
| 编辑距离 | O(m·n) | O(m·n) | ch12 |
| 子集/排列 | O(2ⁿ)/O(n!) | O(n) | ch13 |
| 并查集 | ≈O(1) 路径压缩 | O(n) | ch11 |

> 面试被问「这题多快」：先说**最坏复杂度**，再说「能不能优化一阶」（O(n²)→O(n log n) 是最常见的一步）。

## 三、刷题路线（按顺序，别跳）

不用刷 2000 道，**吃透经典 50 道**比刷 500 道水题有用：

1. **数组/字符串**（ch02）：两数之和、最长无重复子串、盛水最多、合并区间
2. **链表**（ch03）：反转、环检测、合并有序、LRU
3. **栈/队列/堆**（ch04/ch10）：有效括号、每日温度、TopK、数据流中位数
4. **哈希**（ch05）：字母异位词、分组、最长连续序列
5. **二叉树**（ch09）：四种遍历、最大深度、重建、BST 验证、层序
6. **二分**（ch08）：精确找、旋转数组、二分答案（吃香蕉/分书）
7. **图**（ch11）：岛屿数量（并查集/DFS）、拓扑排序、Dijkstra
8. **回溯/DP**（ch12/ch13）：子集/排列/组合、背包、LIS、编辑距离、股票、N 皇后

> 每道题按「五分钟想思路 → 写 → 跑通 → 看题解优化」循环。本教程每章末尾 5 题练习就是缩微版。

## 四、和 FDE 岗的结合（Tom 重点看）

你目标是 **FDE（前沿部署工程师）**——把数据平台改造成客户能用的系统。算法在哪用？

| FDE 日常任务 | 用的算法 | 章 |
|---|---|---|
| 取数后「按省/品类聚合」 | 哈希分组（ch05） | SQL `GROUP BY` 底层 |
| 取「各省 Top 5 客户」 | 堆 TopK（ch10） | 大数据 TopN |
| 报表「按月累计 / 区间求和」 | 前缀和（ch02） | 窗口函数底层 |
| 客户层级 / 组织树遍历 | 树 DFS（ch09） | 目录、BOM |
| 任务依赖 / ETL 编排 | 拓扑排序（ch11） | 死锁检测 |
| 路网 / 配送 / 距离 | Dijkstra（ch11） | 导航、调度 |
| 预算有限挑项目 / 权益分配 | 0/1 背包 DP（ch12） | 资源分配 |
| 去重 / 判重 / 缓存淘汰 | 哈希 + LRU（ch05） | 缓存、幂等 |
| 排查「数据里的环 / 死循环」 | 并查集 / 环检测（ch11/ch03） | 数据质量 |

> 一句话：**FDE 不是「刷题」，是「遇到慢/乱/重复的数据问题，能认出它属于哪类算法、用哪招」**。前面三套教程（Python/SQL/Power BI）给你工具，本教程给你「工具为什么快、怎么选型」的判断力。

## 五、避坑清单（血泪总结）

1. **忘了复杂度**：先问「数据量多大、能承受几阶」，再写。O(n²) 在 10 万行直接超时。
2. **二分死循环**：两个模板背熟一个（`lo<=hi ±1` 或 `lo<hi hi=mid`），别现场编。
3. **贪心没证明**：看着对不等于对，区间调度/硬币都栽过（ch13）。
4. **递归爆栈**：深度大改迭代（链表反转、树遍历都演示过）。
5. **哈希键可变**：`list`/`dict` 不能做 dict 键，先转 `tuple`。
6. **遍历时改容器**：dict/set 遍历中增删会报错，先收集再改。
7. **忽略空间**：TopK 用堆 O(k) 而非全排序 O(n log n)；DP 能滚动就降维。

## 练习（毕业考）

1. **（综合）** 给 1000 万行订单，要「实时」输出「当前销售额最高的 10 个省份」。用什么结构？复杂度？能不排序吗？
2. **（综合）** 客户数据有环（A 的上级是 B，B 的上级是 A），遍历时会怎样？用哪章的什么算法检测？
3. **（综合）** 让你「在 1 亿个整数里找缺失的那个」（已知 0~1亿 各一个少一个），O(n) 空间和 O(n) 时间之外，能不能 O(1) 空间？（提示：位运算 XOR，或二分答案）
4. **（综合）** 一个函数传入「已按日期排序的销售数组」，要找「首个销售额 ≥ 100 万的日期」，二分还是全扫？写 `lower_bound` 思路。
5. **（元认知）** 回头看 ch12 背包：如果物品有「无限个」（完全背包），转移方程怎么改？（提示：`dp[i][c] = max(dp[i-1][c], dp[i][c-w]+v)`，注意是 `dp[i]` 不是 `dp[i-1]`）

**答案与解析**

1. 用**堆（最小堆，大小 10）**滚动维护 Top10：每来一行，若大于堆顶就替换。O(n log 10) ≈ O(3.3n)，**完全不用全排序**（全排序 O(n log n) 慢且占内存）。实时流场景这是标准解法（同 ch10 第 K 大）。
2. 递归/BF遍历会**无限循环**（A→B→A→…）。用 **ch03 的 Floyd 环检测（快慢指针）** 或 **ch11 的 DFS 访问标记（遇已访问非父节点=环）** 检测。数据质量校验必备。
3. 能。法一：**XOR 所有下标和所有值**，缺的数 = 期望 XOR 实际（因为成对抵消）。法二：**二分答案**——统计 `<= mid` 的个数是否等于 mid，O(log n) 轮 × O(n) 计数 = O(n log n) 时间、O(1) 空间。位运算法最优 O(n) 时间 O(1) 空间。
4. 二分。`lower_bound(sales, 1_000_000)` 在「已按日期排序」的数组上 O(log n) 返回首个 ≥ 阈值的下标，比全扫 O(n) 快得多（同 ch08 模板二）。前提是「有序」——日销售额单调不减才成立。
5. 完全背包（物品无限）：选第 i 个后**还能继续选第 i 个**，所以转移用 `dp[i][c]`（同一行）而非 `dp[i-1][c-w]`：
   `dp[i][c] = max(dp[i-1][c], dp[i][c-w] + v)`（内层循环正序遍历 c）。对比 0/1 背包用 `dp[i-1][c-w]`（需逆序或开新行防重复使用）。这是 ch12 背包的状态微小改动，差异很大。
