# ch09 可视化与报表交互 📊

> 本章目标：把数字变成**一眼能看懂、能自助探索**的报表页面。
> 前面 8 章解决"算得对"，本章解决"看得懂、用得顺"。

---

## 一、本章学习目标

学完本章你应该能：

1. 根据**要回答的问题**选对图表类型
2. 用切片器和筛选器窗格做出好用的筛选体系
3. 用「编辑交互」控制图表之间的联动行为
4. 用**钻取 + 层级**实现从总览到明细的探索
5. 用**书签 + 按钮**做页面切换和状态保存
6. 用条件格式、工具提示页提升信息密度

---

## 二、视觉对象选型：回答什么问题，用什么图

**这是本章最重要的一张表。** 选错图表，数据再准也白搭。

| 你想回答的问题 | 用什么图 | 为什么 |
|---|---|---|
| 各省销售额谁高谁低？ | **条形图**（横向） | 类别名长，横向好读；长度比高度更易比较 |
| 全年销售趋势？ | **折线图** | 时间趋势用线，一眼看起落 |
| 各省销售额对比（类别少） | **柱状图**（纵向） | 类别少时纵向更自然 |
| 各品类占多少？ | **饼图/环形图**（≤5类）或**树状图** | 展示构成；超过 5 类改用条形 |
| 省 × 品类的交叉数据 | **矩阵** | 二维交叉表，支持下钻 |
| 一个关键数字 | **卡片图** | 突出单一 KPI |
| 销售额和毛利率的关系 | **散点图** | 看相关性 |
| TOP 10 客户 | 条形图 + 前 N 筛选 | |
| 完成率/达标率 | **仪表盘**或**KPI** | 有目标值时用 |

### 2.1 三个最常见的选型错误

| ❌ 错误 | 问题 | ✅ 正确 |
|---|---|---|
| 用**饼图**展示 10 个省份占比 | 扇区太多，看不出大小差异 | 用**条形图**排序 |
| 用**柱状图**展示 36 个月趋势 | 柱子太密，看不清 | 用**折线图** |
| 用**折线图**展示各省销售额 | 折线暗示"连续/趋势"，但省份是无序类别 | 用**条形图** |

> **判断口诀**：
> - **时间趋势 → 折线**
> - **类别比较 → 条形/柱状**
> - **构成占比 → 饼图(≤5) / 树状图 / 100%堆叠**
> - **二维交叉 → 矩阵**
> - **单一数字 → 卡片**

### 2.2 本库推荐页面布局

一个标准的「销售总览页」：

```
┌─────────────────────────────────────────────┐
│  标题：电商销售分析看板                        │
│  [年份切片器] [品类切片器] [等级切片器]        │
├──────────┬──────────┬──────────┬────────────┤
│ 有效销售额 │ 有效利润  │  毛利率   │   客单价    │  ← 4 个卡片
│ 719.5万   │ 170.7万  │  23.72%  │  3,041.21  │
├──────────────────────┬─────────────────────┤
│  月度销售趋势（折线）  │  各省销售额（条形）    │
│  看 618/双11 冲高     │  广东 107.8万居首    │
├──────────────────────┼─────────────────────┤
│  品类销售额×毛利率矩阵 │  TOP10 客户（条形）   │
└──────────────────────┴─────────────────────┘
```

## 三、切片器与筛选器窗格

### 3.1 切片器的三种层级

| 层级 | 在哪设置 | 作用范围 |
|---|---|---|
| **视觉对象级** | 选中某图 → 筛选器面板 | 只影响这一个图 |
| **页面级** | 筛选器面板 → "此页上的筛选器" | 当前页所有图 |
| **报表级** | 筛选器面板 → "所有页面上的筛选器" | 所有页 |

**切片器默认是页面级**（放在页面上，影响该页所有图）。

### 3.2 切片器的样式选择

| 样式 | 适合 |
|---|---|
| **下拉** | 选项多（>10），省空间 |
| **列表** | 选项少（3-8），一眼看全 |
| **按钮/磁贴** | 状态类（2023/2024/2025），点击快 |
| **介于（滑块）** | 数值范围（金额区间） |
| **相对日期** | 时间（最近 30 天、本月） |
| **层级** | 年 > 季 > 月，可展开 |

**本库推荐配置**：

- 年份：按钮样式（2023/2024/2025，横排三个按钮）
- 品类：下拉（5 个，支持多选）
- 客户等级：列表或按钮（4 个）
- 日期：相对日期（业务方最常用"最近 N 天"）

### 3.3 切片器的两个实用设置

**① 显示"全选"项**

切片器右上角 ⋯ → 勾选「显示"全选"项」→ 用户可以一键回到全部。

**② 同步切片器**（多页报表必备）

视图 → 同步切片器 → 勾选要在哪些页面同步。

> 没有同步时，用户在第 1 页选了 2024，翻到第 2 页筛选就重置了 —— **这是多页报表最常见的体验问题**。

## 四、交互：控制图表之间的联动

当一个页面有多个图表时，点击其中一个，其他的会怎样？

### 4.1 设置方法

选中**源图表**（比如条形图）→ 格式 → **编辑交互** → 这时其他图表上方出现三个小图标：

| 图标 | 行为 | 效果 |
|---|---|---|
| 🔍 **筛选** | 筛选（默认） | 其他图只显示被点中的数据 |
| 💡 **突出显示** | 高亮 | 其他图显示全量，但被点中的部分高亮 |
| ⊘ **无** | 不联动 | 其他图完全不变 |

### 4.2 三种行为的区别（举例）

报表上有「各省销售额条形图」和「月度趋势折线图」，点击条形图里的**广东**：

| 行为 | 月度趋势折线图显示 |
|---|---|
| 筛选 | 只有广东的月度趋势（**其他省消失**） |
| 突出显示 | 全部省份的月度趋势，但广东部分**高亮**（其他变灰） |
| 无 | 全部省份趋势，无变化 |

### 4.3 怎么选

| 场景 | 推荐 |
|---|---|
| 主图 + 明细图（点省份看该省趋势） | **筛选** |
| 想看"这部分在整体中的位置" | **突出显示** |
| KPI 卡片（不该被点击改变） | **无** |

> **重要经验**：**卡片图一定要设为「无」**。
> 否则用户点一下图表，KPI 卡片数字就变了，会以为报表出错。
> KPI 卡片应该由**切片器**控制，而不是被图表点击影响。

## 五、钻取与层级

### 5.1 层级下钻（ch02 已建）

ch02 建了两个层级：`商品层级`（品类>品牌>商品）和 `时间层级`（年>季>月）。

**用法**：

1. 把 `商品层级` 拖到条形图的「轴」
2. 图表右上角出现**下钻按钮**（向下的箭头 ⤓）
3. 点击 → 从"品类"下钻到"品牌"，再点 → "商品"
4. 点击**向上箭头** ⤒ 回到上层

**两种下钻模式**：

| 模式 | 行为 | 什么时候用 |
|---|---|---|
| **下钻**（⤓） | 整个图表切换到下一层 | 想看所有品类的品牌明细 |
| **展开**（分叉箭头） | 保持上层，同时展开下一层 | 想看"品类1 > 它的品牌"的树状结构 |

### 5.2 钻取页（Drillthrough）

**作用**：右键某个数据点 → 钻取到专门的明细页。

**做法**：

1. 新建一个页面，命名为「省份明细」
2. 在「筛选器」面板的**钻取**区域，拖入 `dim_region[province_name]`
3. 在这个页面上放该省的详细图表（月度趋势、品类构成、TOP 客户）
4. 回到总览页，右键条形图里的"广东" → **钻取** → 「省份明细」

**关键设置**：

- 钻取字段必须在目标页的**钻取筛选器**区域
- Power BI 会自动在钻取页生成一个"返回"按钮（左上角 ←）
- 钻取会**继承**源页面的其他筛选（比如年份切片器）

> **这是提升报表专业度最有效的功能之一**：总览页看全局，右键下钻看单省详情，用户不用自己做筛选。

### 5.3 工具提示页（Tooltip）

**作用**：鼠标悬停在某数据点上，显示一个小浮层，里面是**迷你图表**。

**做法**：

1. 新建页面 → 页面信息 → **页面类型**改为「**工具提示**」
2. 页面尺寸设为小尺寸（比如 320×240）
3. 在这个小页面上放图表（比如该省的月度趋势迷你折线）
4. 回到主图 → 格式 → **工具提示** → 类型选「报表页」→ 选刚才那页

**效果**：鼠标悬停在"广东"柱子上，浮出广东的月度趋势。

> **这个功能用好了非常惊艳**，但不要滥用 —— 只在"用户确实想快速看一眼趋势"时用。

## 六、书签与按钮（做交互的利器）

### 6.1 书签是什么

**书签 = 保存报表的一个"状态快照"**，包括：

- 当前的筛选器状态
- 切片器的选择
- 哪些对象显示/隐藏
- 当前的页面

### 6.2 典型用法一：总览 / 明细 切换

**场景**：一个区域，点按钮切换显示"销售额"或"利润"。

**做法**：

1. 放两个图表（销售额图、利润图），位置重叠
2. 视图 → **选择**窗格 → 给两个图命名（"图_销售额"、"图_利润"）
3. 显示"图_销售额"、隐藏"图_利润" → 插入 → 书签 → 命名「书签_显示销售额」
4. 反过来，隐藏销售额图、显示利润图 → 新建书签「书签_显示利润」
5. 插入 → 按钮 → 空白 → 在按钮的「操作」里设：类型=书签，书签=对应的书签
6. 复制一个按钮，绑定另一个书签

**最终效果**：两个按钮，点击切换显示不同指标。

> ⚠️ **踩坑提醒**：建完书签后，如果你又增删了视觉对象，书签可能失效或行为异常。
> **建议：先把所有对象放好，最后再建书签。**

### 6.3 典型用法二：页面导航

底部放一排按钮（总览 / 客户分析 / 品类分析），每个按钮的「操作」设为**页面导航** → 选择目标页。

这比让用户点底部的页面标签更直观。

### 6.4 典型用法三：重置筛选

建一个书签，命名为「重置」，在**无筛选状态**下创建，并勾选「**数据**」（这样它会恢复筛选状态）。

然后放一个"重置"按钮绑定它。

> 用户把切片器点得乱七八糟后，一键回到初始状态 —— 非常实用。

## 七、条件格式：让异常自己跳出来

### 7.1 矩阵/表格里的条件格式

选中矩阵里的某个值列 → 条件格式 → 可选：

| 类型 | 效果 | 本库用法 |
|---|---|---|
| **数据条** | 单元格内显示横向条 | 销售额列 |
| **色阶** | 背景色深浅 | 毛利率列（低=红，高=绿） |
| **图标** | 箭头/红绿灯 | 同比列（↑↓） |
| **字体颜色** | 按规则改色 | 负增长标红 |

> ⚠️ **中国区注意**：Power BI 默认色阶是"红=低、绿=高"，这与**中国股市习惯相反**（中国：涨=红、跌=绿）。
> 做财务/销售报表时，业务方往往期望"**好=红/暖色，差=绿/冷色**"或至少明确标注。
> **建议：做销售报表时把色阶反过来**，或者在报表角落加图例说明。**这个细节经常被忽略，但业务方会立刻感觉到"不舒服"。**

### 7.2 基于字段的条件格式（进阶）

条件格式可以**基于另一个度量值**：

1. 条件格式 → 背景色 → 格式样式选「**字段值**」
2. 依据字段选 `[毛利率]`

**效果**：销售额单元格的背景色，由**毛利率**决定 —— 一眼看出"哪些高销售额其实是低毛利的"。

**本库的应用**：

| 品类 | 销售额 | 毛利率 | 视觉提示 |
|---|---:|---:|---|
| 数码 | 2,612,383.09 | 1.16% | 销售额最高但毛利率最低 → **标红警告** |
| 美妆 | 1,381,720.47 | 49.47% | 毛利率最高 → 标绿 |

> 这是本库最值得展示的洞察 —— **规模大 ≠ 赚钱**。用条件格式能一眼传达。

## 八、主题与移动端布局

### 8.1 主题（Theme）

视图 → 主题 → 可选内置主题，或导入 JSON 主题文件。

**作用**：一次性统一所有图表的配色、字体、背景。

> **FDE 视角**：客户几乎都会要求"用我们公司的配色"。做法是：
> 1. 视图 → 主题 → **自定义当前主题** → 改 `dataColors`（图表配色数组）
> 2. 导出 JSON，保存为项目资产
> 3. 后续所有报表导入同一个 JSON → 全公司视觉统一
>
> **这一步能省掉后面无数次手动改颜色。**

### 8.2 移动端布局

视图 → **移动布局** → 把视觉对象拖到手机画布上重新排布。

**为什么需要**：默认 PC 布局在手机上会挤成一团。移动布局让你为手机单独排一版（通常是**纵向单列**）。

**建议**：

- 手机上只保留 3-5 个核心图表
- 卡片放最上面（KPI 优先）
- 图表纵向排列，一个一屏

## 十、FDE 现场场景

### 场景 1：客户说"图太多了，找不到重点"

**典型症状**：一个页面塞了 12 个图，业务方说"看不过来"。

**解法**：

| 做法 | 说明 |
|---|---|
| **分层分多页** | 总览页只放 4-6 个核心图，明细拆到其他页 |
| **卡片置顶** | KPI 用大卡片，一眼看到关键数字 |
| **删掉低效图** | 饼图如果类别>5，换成条形；重复信息的图删掉 |
| **加导航按钮** | 让用户知道去哪找更深的分析 |

> **经验法则**：**一个页面最多 6 个图表**。超过就拆页，用按钮导航。

### 场景 2：客户要求"能导出 Excel"

**这是 100% 会出现的需求。**

| 方式 | 怎么做 | 限制 |
|---|---|---|
| 视觉对象导出 | 图右上角 ⋯ → 导出数据 | 只能导当前图，最多几万行 |
| 矩阵导出 | 矩阵图 → ⋯ → 导出数据 | 最常用 |
| 分页报表（Paginated Report） | Power BI Report Builder 单独做 | 适合大批量、格式固定的导出 |
| "在 Excel 中分析" | 语义模型 → 在 Excel 中分析 | 适合财务人员自助 |

**建议**：在报表右上角明确放一个「导出说明」按钮（书签或工具提示），告诉用户"点图右上角 ⋯ → 导出数据"。

### 场景 3：报表打开很慢

**排查顺序**：

1. **视觉对象数量**：一页超过 15 个图就会明显变慢（每个图都是一次查询）
2. **高基数分组**：按 `customer_name`（500 个值）分组比按 `category`（5 个）慢很多
3. **度量值复杂度**：含 `FILTER(整表)` 的度量值是重灾区（ch10）
4. **数据模型**：见 ch10

**快速优化**：

- 减少单页图表数
- 默认折叠矩阵层级
- 用"导入"模式（已是）
- 关掉不必要的视觉对象交互

## 十一、本章小结

| 你学到了 | 关键点 |
|---|---|
| 选型 | 趋势→折线、比较→条形、占比→饼(≤5)/树图、交叉→矩阵、单值→卡片 |
| 筛选层级 | 视觉对象级 / 页面级 / 报表级；多页报表要**同步切片器** |
| 交互 | 筛选（只留选中）/ 突出（高亮）/ 无（不联动）；**KPI 卡片设"无"** |
| 下钻 | 层级下钻（⤓）+ 钻取页（右键 → 明细页） |
| 工具提示页 | 页面类型改成"工具提示"，悬停显示迷你图 |
| 书签 | 保存状态快照；做指标切换、页面导航、重置筛选 |
| 条件格式 | 数据条/色阶/图标；**可基于其他字段**（销售额按毛利率着色） |
| **中国区提醒** | 默认色阶红低绿高，与国内习惯相反，**销售报表建议反转** |
| 验证基准 | 卡片 7,195,492.73 / 23.72% / 3,041.21；广东 1,078,152.70；梁诗 70,022.89 |

### 练习 1：把各省条形图改成"突出显示"（考：交互行为）

**题目**：页面上有「各省条形图」和「月度趋势折线图」。把条形图对折线图的交互从「筛选」改成「突出显示」，点击"广东"，观察折线图变化。

**预期结果**：

| 交互模式 | 点击"广东"后折线图显示 |
|---|---|
| 筛选（默认） | **只剩广东**的月度趋势，其他省消失 |
| 突出显示 | **所有省**的月度趋势都在，但广东高亮、其他变灰 |

**解析**：

- **筛选**：其他图的数据被过滤，只保留广东 → 适合"聚焦单个对象深入分析"
- **突出显示**：保留全量作为背景参照，广东被强调 → 适合"看个体在整体中的位置"

**怎么选**：

| 业务问题 | 用哪个 |
|---|---|
| "广东的销售趋势是怎样的？" | 筛选 |
| "广东跟其他省比，趋势有什么不同？" | 突出显示 |

**验证**：点击广东后，如果折线图只剩一条线 → 是筛选模式；如果有多条线但一条深色其他浅色 → 是突出显示模式。

### 练习 2：给毛利率加色阶，并反转配色（考：条件格式）

**题目**：在品类矩阵上给「毛利率」列加背景色阶。观察默认配色，然后按中国区习惯反转。

**默认设置**：条件格式 → 背景色 → 色阶 → 最低值红色、最高值绿色

**预期结果**：

| 品类 | 毛利率 | 默认配色 | 反转后 |
|---|---:|---|---|
| 数码 | 1.16% | 🔴 红 | 🔴 红 |
| 食品 | 21.75% | 🟡 黄 | 🟡 黄 |
| 家居 | 27.22% | 🟡 黄 | 🟡 黄 |
| 服饰 | 38.00% | 🟢 浅绿 | 🟢 浅绿 |
| 美妆 | 49.47% | 🟢 绿 | 🟢 绿 |

**解析**：

本例中**默认配色恰好符合国内直觉**（低毛利=红=警告，高毛利=绿=健康），因为：

- 默认：最小值红色（1.16% 数码 → 红）✅ 符合"低毛利是问题"的认知
- 默认：最大值绿色（49.47% 美妆 → 绿）✅

**那什么时候需要反转？**

当你做的是**增长类指标**且面向中国用户时：

| 指标 | 国内习惯 | 默认配色 | 是否需要反转 |
|---|---|---|---|
| 毛利率 | 低=红（差） | 低=红 ✅ | 不需要 |
| 销售额同比增长 | 涨=**红**（好） | 涨=绿 ❌ | **需要反转** |
| 股价涨跌 | 涨=红 | 涨=绿 ❌ | **需要反转** |

> **判断方法**：问自己"**这个指标变大，是好事还是坏事？**"
> - 变大是好事（增长）→ 国内习惯用**红色**表示 → 需要把色阶反转（最大值设红色）
> - 变大是坏事（成本、退货率）→ 用红色 → 默认配色即可

**操作方法**：条件格式 → 背景色 → 自定义 → 把"最小值"和"最大值"的颜色互换。

> **FDE 视角**：这个细节在国内项目里**几乎必踩**。业务方看到"增长却是绿色"会觉得别扭，但往往说不出原因。你主动问一句"增长用红色还是绿色表示？"，专业度立刻体现。

### 练习 3：做一个"销售额 / 利润"切换按钮（考：书签）

**题目**：用书签做两个按钮，点击切换显示销售额或利润的条形图。

**步骤**：

1. 放两个条形图（省份 × 有效销售额、省份 × 有效利润），**完全重叠**
2. 视图 → 选择窗格 → 分别命名「图_销售额」「图_利润」
3. 显示「图_销售额」+ 隐藏「图_利润」→ 插入 → 书签 → 命名「书签_销售额」
4. 隐藏「图_销售额」+ 显示「图_利润」→ 新建书签「书签_利润」
5. 插入 → 按钮 → 空白，两个按钮，操作分别绑定这两个书签

**预期结果**：

点击「销售额」按钮 → 显示：

| 省份 | 有效销售额 |
|---|---:|
| 广东 | 1,078,152.70 |
| 浙江 | 849,660.63 |
| … | … |

点击「利润」按钮 → 显示：

| 省份 | 有效利润 |
|---|---:|
| 广东 | 237,770.02 |
| 浙江 | 210,290.78 |
| … | … |

**注意**：两个榜的排序**不一样**！

销售额第一是广东（1,078,152.70），利润第一也是广东（237,770.02）。但如果看**毛利率**，广东只有 22.05%，低于江苏（25.72%）。

> **这就是为什么要做切换视图** —— 让用户看到"销售额第一"和"赚钱最多"不一定是同一个。

**踩坑提醒**：

> 建完书签后**不要**再增删视觉对象，否则书签可能失效。
> 如果必须改，改完要**重新更新书签**（书签右键 → 更新）。

### 练习 4：做省份钻取页（考：钻取功能）

**题目**：建一个「省份明细」页，配置钻取字段为 `province_name`，让用户从总览页右键下钻。

**步骤**：

1. 新建页面，命名「省份明细」
2. 「筛选器」面板 → **钻取**区域 → 拖入 `dim_region[province_name]`
3. 页面上放：
   - 卡片：该省有效销售额、毛利率
   - 折线图：该省月度趋势
   - 矩阵：该省 × 各品类销售额
   - 条形图：该省 TOP 客户
4. 回到总览页，右键各省条形图里的"广东" → 钻取 → 省份明细

**预期结果**（以广东为例）：

| 元素 | 值 |
|---|---:|
| 有效销售额 | **1,078,152.70** |
| 有效利润 | 237,770.02 |
| 毛利率 | 22.05% |
| 订单数 | 352 |

**验证 SQL**：

```sql
SELECT COUNT(*) AS 订单数,
       ROUND(SUM(o.order_amount),2) AS 销售额,
       ROUND(SUM(o.order_profit),2) AS 利润,
       ROUND(SUM(o.order_profit)/SUM(o.order_amount)*100,2) AS 毛利率pct
FROM fact_order o JOIN dim_region r ON o.region_id=r.region_id
WHERE o.status='已完成' AND r.province_name='广东';
-- 预期：352 | 1078152.70 | 237770.02 | 22.05
```

**关键点**：

- 钻取字段必须在目标页的**钻取区域**（不是页面筛选器）
- Power BI 会自动生成**返回按钮**（左上角 ←），可以删除但建议保留
- 钻取会**继承**源页面的切片器状态（比如源页面选了 2024，钻取页也是 2024）

> **这是提升报表可用性最有效的功能**。业务方从"看全局"到"看单个省"只需右键两下，不用自己拉筛选器。

### 练习 5：诊断一页"不合格"的报表（考：综合评审）

**题目**：假设你接手一页报表，发现以下问题。分别说明怎么改：

| 问题 | 怎么改 |
|---|---|
| 一页有 14 个图表 | ？ |
| 用饼图展示 10 个省份占比 | ？ |
| 点一下柱状图，KPI 卡片数字就变了 | ？ |
| 用户切到第 2 页，切片器选择被重置 | ？ |
| 折线图的 X 轴是"客户姓名"（500 个） | ？ |
| 同比增长 +8.32%，但柱子是绿色的 | ？ |

**答案**：

| 问题 | 改法 |
|---|---|
| 一页有 14 个图表 | **拆成多页**，每页 ≤6 个图，用按钮导航 |
| 用饼图展示 10 个省份占比 | 改成**条形图**并降序排序（饼图超过 5 类就看不清了） |
| 点一下柱状图，KPI 卡片数字就变了 | 选中柱状图 → 编辑交互 → 把卡片设为「**无**」 |
| 切到第 2 页，切片器选择被重置 | 视图 → **同步切片器** → 勾选要同步的页面 |
| 折线图 X 轴是客户姓名（500 个） | 折线图只用于**时间/有序**维度；改成**条形图 + 前 N 筛选**（如 TOP 10） |
| 同比增长 +8.32% 但柱子是绿色的 | 国内习惯**涨=红**，把条件格式的色阶**反转**（最大值设红色） |

**评分标准（你自己的报表也该这样审）**：

| 维度 | 合格标准 |
|---|---|
| 图表数量 | 每页 ≤ 6 个 |
| 选型 | 趋势用线、比较用条、占比≤5 类用饼 |
| 交互 | KPI 卡片不受图表点击影响 |
| 多页 | 切片器已同步 |
| 高基数 | 不用折线图，用条形 + 前 N |
| 配色 | 符合目标用户习惯（国内：涨=红） |
