## 三、概念：变量不是盒子，是标签

Python 的变量**不装数据，只贴标签**：

```python
a = [1, 2, 3]      # 把标签 a 贴在 [1,2,3] 这个对象上
b = a              # 把标签 b 贴在同一个对象上（不是复制！）
b.append(4)
print(a)           # [1, 2, 3, 4] —— a 也变了
```

这个特性在 ch04 讲列表时会详细展开，这里先建立直觉：**赋值 = 贴标签，不是复印。**

### 数据类型一览

| 类型 | 例子 | 可变? | 典型用途 |
|---|---|---|---|
| `int` 整数 | `1200`、`-5` | 不可变 | 数量、天数、件数 |
| `float` 浮点 | `8.65`、`23.72` | 不可变 | 金额、比率、重量 |
| `bool` 布尔 | `True`、`False` | 不可变 | 是否完成、是否出口 |
| `str` 字符串 | `"ST-BD-42"` | 不可变 | 料号、名称、日期文本 |
| `NoneType` | `None` | — | 空值、缺失、未设置 |

> Python 是**动态类型**：变量不用声明类型，赋值什么就是什么，`type(变量)` 可以随时查。

## 四、实操

### 4.1 变量命名与赋值

```python
goggles_per_box = 12          # 每箱 12 只（小写 + 下划线，推荐）
boxes = 37
price = 8.65
product_name = "静音球"
is_export = True

total = goggles_per_box * boxes
print(f"{product_name} 共 {total} 只")
print(f"货值: {round(total * price, 2)} 元")
print(type(goggles_per_box), type(price), type(product_name), type(is_export))
```

**预期输出：**

```
静音球 共 444 只
货值: 3840.6 元
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>
```

**命名规则**（PEP 8 规范）：

- 只能用**字母、数字、下划线**，不能以数字开头
- 区分大小写：`Price` 和 `price` 是两个变量
- 变量 / 函数名：**小写 + 下划线** → `order_amount`、`is_export`
- 常量：**全大写** → `MAX_QTY = 9999`
- 类名：**大驼峰** → `class Product:`（ch10）
- ❌ 不要用拼音缩写、不要用 `l` / `O` 这种容易看错的字母

多个变量可以一起赋值：

```python
a = b = c = 0                 # 三个都是 0
x, y, z = 1, 2.5, "静音球"     # 一一对应解包
print(x, y, z)                # 1 2.5 静音球
```

### 4.3 ⚠️ 浮点陷阱：算钱的第一大坑

```python
print("0.1 + 0.2 =", 0.1 + 0.2)
print("是否等于 0.3:", 0.1 + 0.2 == 0.3)
```

**真实输出：**

```
0.1 + 0.2 = 0.30000000000000004
是否等于 0.3: False
```

**为什么？** 计算机用二进制存小数，`0.1` 在二进制里是**无限循环小数**（就像十进制里 1/3 = 0.333…），只能存近似值，累加后误差就冒出来了。

**三种正确姿势：**

```python
from decimal import Decimal, ROUND_HALF_UP
import math

# ① 比较用容差，不用 ==
print("math.isclose:", math.isclose(0.1 + 0.2, 0.3))       # True

# ② 金额用 Decimal（字符串初始化！）
amount = Decimal("8.65") * 1200
print("Decimal 金额:", amount)                              # 10380.00

# ③ 展示时 round 到 2 位
print("round:", round(0.1 + 0.2, 2))                        # 0.3
```

**预期输出：**

```
math.isclose: True
Decimal 金额: 10380.00
round: 0.3
```

> 🔴 **铁律**：
> - **算钱用 `Decimal`，初始化传字符串** `Decimal("8.65")` 而不是 `Decimal(8.65)`（后者会把浮点误差带进去）
> - **判断相等用 `math.isclose()`**，永远不要写 `float_a == float_b`
> - 日常分析用 `float` + `round(x, 2)` 够用；**财务对账、报价单**必须用 `Decimal`

### 4.4 四舍五入：Python 用的是「银行家舍入」

```python
print("round(2.5) =", round(2.5))        # 2 ← 不是 3！
print("round(3.5) =", round(3.5))        # 4
print("round(1.005, 2) =", round(1.005, 2))   # 1.0 ← 不是 1.01！
```

**真实输出：**

```
round(2.5) = 2
round(3.5) = 4
round(1.005, 2) = 1.0
```

`round()` 用的是**「四舍六入五取偶」**（banker's rounding）：遇到正好的 `.5`，取最近的**偶数**。这是统计学上更公平的做法，但**不符合财务习惯**。

要「四舍五入」，用 `Decimal`：

```python
from decimal import Decimal, ROUND_HALF_UP

def money_round(value, digits=2):
    """财务四舍五入（默认两位小数）"""
    q = Decimal(1).scaleb(-digits)          # digits=2 时就是 0.01
    return Decimal(str(value)).quantize(q, rounding=ROUND_HALF_UP)

print("round(2.675, 2)   =", round(2.675, 2))           # 2.67 ← 错！
print("money_round(2.675)=", money_round(2.675))        # 2.68 ← 对
print("money_round(1.005)=", money_round(1.005))        # 1.01
print("money_round(2.5)  =", money_round(2.5))          # 2.50
print("money_round(2.5,0)=", money_round(2.5, 0))       # 3    保留 0 位小数
print("money_round(10380.456)=", money_round(10380.456))# 10380.46
```

**预期输出：**

```
round(2.675, 2)   = 2.67
money_round(2.675)= 2.68
money_round(1.005)= 1.01
money_round(2.5)  = 2.50
money_round(2.5,0)= 3
money_round(10380.456)= 10380.46
```

注意 `2.675` 这个例子：`round()` 给出 2.67 而 `Decimal` 给出 2.68。原因是 `2.675` 在二进制里实际略小于 2.675，所以 round 舍掉了——**这不是四舍五入，这是错的**。`Decimal(str(value))` 先把数字变成十进制字符串再算，才拿到正确答案。

### 4.5 比较与逻辑运算符

```python
# 比较：返回 True / False
print(1200 > 400, 8.65 == 8.65, "ST" != "BD")

# 链式比较（Python 独有，其他语言要写 and 连接）
print("链式:", 1 < 3 <= 5)                 # True

# 逻辑：and / or / not
print(True and False, True or False, not True)

# 短路求值：or 前面为真就不再算后面
print(None or "默认值")                     # 默认值
print("有值" or "默认值")                   # 有值
```

**预期输出：**

```
True True True
链式: True
True False False
默认值
有值
```

> **短路求值（short-circuit）** 是实战高频技巧：
> ```python
> name = user_input or "未填写"          # 空字符串自动取默认
> rate = config.get("rate") or 0.02     # None / 0 都兜底
> ```

### 4.6 成员与身份运算

```python
codes = ["ST-BD-42", "ST-BD-60"]
print("ST-BD-42" in codes)              # in：成员判断，列表/字符串/字典都能用
print("M" in "MTO")                     # 子串判断

a = [1, 2]; b = [1, 2]
print("a == b:", a == b)                # True  值相等
print("a is b:", a is b)                # False 不是同一个对象

s1 = "abc"; s2 = "abc"
print("s1 is s2:", s1 is s2)            # True  字符串驻留，共用一个对象
```

**预期输出：**

```
True
True
a == b: True
a is b: False
s1 is s2: True
```

> **`==` 比「值」，`is` 比「身份证」（内存地址）。**
> 判断 `None` 必须用 `is`：`if x is None:`（这是唯一推荐的 `is` 用法）。

### 4.7 类型转换

```python
print(int("42"), float("3.14"), str(100), bool(0))

print("round:", round(3.5), round(4.5))         # 4  4（取偶）
print(float("1e3"), int(1e3))                   # 1000.0  1000
```

**预期输出：**

```

float 1e3: 1000.0 1000
```

字符串转数字失败会抛 `ValueError`：

```python
try:
    int("8.65")        # '8.65' 不是合法整数字面量
except ValueError as e:
    print("转换失败:", e)
# 转换失败: invalid literal for int() with base 10: '8.65'
```

> 从 Excel / 网页读来的数字**几乎都是字符串**，必须先转类型才能算，这是 ch08 和 ch12 的常见操作。

### 4.8 真假值：什么算「假」

```python
vals = [0, 0.0, "", None, [], {}, (), set(), False, "0", "False", [0], 1, -1]
for v in vals:
    print(f"  {type(v).__name__:6s} {str(v):8s} -> {bool(v)}")
```

**真实输出：**

```
  int      0        -> False
  float    0.0      -> False
  str               -> False
  NoneType None     -> False
  list     []       -> False
  dict     {}       -> False
  tuple    ()       -> False
  set      set()    -> False
  bool     False    -> False
  str      0        -> True      ← ⚠️
  str      False    -> True      ← ⚠️ 最坑的一个
  list     [0]      -> True      ← ⚠️
  int      1        -> True
  int      -1       -> True
```

**规律**：`0`、`0.0`、`""`（空字符串）、`None`、以及**所有空容器**都是假；其他全是真。

> 🔴 **血泪坑**：从 Excel / 配置文件读进来的 `"False"` 是**非空字符串 → 真**！
> ```python
> flag = "False"          # 假设这是从表格读来的
> if flag:                # 这里会执行！因为非空字符串是真
>     print("执行了不该执行的逻辑")
> ```
> 正解：先做类型转换 `flag = flag.strip().lower() == "true"`，ch08 会讲怎么稳健地处理。

### 4.9 运算符优先级（记不住就加括号）

```python
print("2+3*4   =", 2 + 3 * 4)          # 14
print("(2+3)*4 =", (2 + 3) * 4)        # 20
print("-3**2   =", -3 ** 2)            # -9  幂运算优先级最高，等价于 -(3**2)
print("2**3**2 =", 2 ** 3 ** 2)        # 512 右结合，等价于 2**(3**2)
print("10//3*3+10%3 =", 10 // 3 * 3 + 10 % 3)   # 10
print("or/and  :", True or False and False)      # True  and 优先于 or
```

**预期输出：**

```
2+3*4   = 14
(2+3)*4 = 20
-3**2   = -9
2**3**2 = 512
10//3*3+10%3 = 10
or/and  : True
```

优先级从高到低：`**` → `* / // %` → `+ -` → 比较 → `not` → `and` → `or`

> **建议**：除了最基础的四则运算，其他一律**加括号**。可读性 > 炫技。

### 4.10 复合赋值与海象运算符

```python
n = 10
n += 5; print("n += 5 ->", n)      # 15

# 海象运算符 := （Python 3.8+）：赋值的同时使用
```

## 五、验证：算一笔真实的报价

```python
from decimal import Decimal, ROUND_HALF_UP

def money(v):
    return Decimal(str(v)).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)

# 静音球报价：1200 只，单价 8.65，含税 13%，客户等级折扣 15%
qty = 1200
price = Decimal("8.65")
discount = Decimal("0.15")
tax_rate = Decimal("0.13")

subtotal = money(price * qty)                    # 小计
after_discount = money(subtotal * (1 - discount))# 折后
tax = money(after_discount * tax_rate)           # 税额
total = after_discount + tax                     # 含税总价

print(f"数量        : {qty} 只")
print(f"单价        : {price} 元")
print(f"小计        : {subtotal} 元")
print(f"折后(85折)  : {after_discount} 元")
print(f"税额(13%)   : {tax} 元")
print(f"含税总价    : {total} 元")
print(f"校验（折后+税=总价）: {after_discount + tax == total}")
```

**预期输出：**

```
数量        : 1200 只
单价        : 8.65 元
小计        : 10380.00 元
折后(85折)  : 8823.00 元
税额(13%)   : 1146.99 元
含税总价    : 9969.99 元
校验（折后+税=总价）: True
```

> 注意税额是 **1146.99** 而不是 1147.00 —— 8823 × 0.13 = 1146.99 整，正好两位，没有第三位可进。财务口径下这就是正确结果。

用 `float` 算，单笔看着没问题，但**多笔累加误差就藏不住了**：

```python
print("0.1 + 0.2        =", 0.1 + 0.2)        # 0.30000000000000004
print("0.7 + 0.1        =", 0.7 + 0.1)        # 0.7999999999999999
print("4.35 元 × 100 只 =", 4.35 * 100)       # 434.99999999999994 ← 单价 4.35 的常见场景

# 逐笔累加 1000 笔 0.1 元手续费
total = 0.0
for _ in range(1000):
    total += 0.1
print(repr(total), "| 是否等于 100.0:", total == 100.0)
```

**预期输出：**

```
0.1 + 0.2        = 0.30000000000000004
0.7 + 0.1        = 0.7999999999999999
4.35 元 × 100 只 = 434.99999999999994
99.9999999999986 | 是否等于 100.0: False
```

> 单笔的一分钱差距看不出来，但**对账时几千笔累加，误差会到几毛甚至几块**——财务会找你麻烦。
> 更危险的是 `4.35 * 100` 这种：你本想判断 `if amount == 435.0`，结果永远进不去分支。
>
> 结论：**分析探索可以用 float（配合 `round` 展示），但凡是要落在报价单、对账单、发票上的金额，必须用 `Decimal`。**

## 六、FDE 现场场景：客户给的数据永远是脏的

客户发来一张 Excel，你读进来发现：

| 你以为的 | 实际读到的 | 后果 |
|---|---|---|
| 数字 `8.65` | 字符串 `"8.65 "` | 直接相乘报 TypeError |
| 数字 `1200` | 字符串 `"1,200"` | `int()` 报 ValueError（有逗号） |
| 布尔 `False` | 字符串 `"False"` | `if flag:` 判断反了 |
| 空值 | 字符串 `""` 或 `"N/A"` | 参与计算全变 NaN |
| 日期 | 字符串 `"2026/9/4"` | 无法按日期排序 |

**所以每个数据脚本的第一步永远是「清洗 + 类型转换」**：

```python
def to_number(value, default=0.0):
    """把各种脏数据转成数字，失败返回默认值"""
    if value is None:
        return default
    if isinstance(value, (int, float)):
        return float(value)
    cleaned = str(value).strip().replace(",", "").replace("元", "")
    if cleaned in ("", "-", "N/A", "nan", "None"):
        return default
    try:
        return float(cleaned)
    except ValueError:
        return default

print(to_number("1,200"))     # 1200.0
print(to_number("8.65 元"))    # 8.65
print(to_number("N/A"))       # 0.0
print(to_number(None))        # 0.0
print(to_number("abc"))       # 0.0
```

这个函数建议存进你的工具箱（ch09 教你做成模块到处复用）。

## 八、练习题

### 练习 1：装箱计算（考：// 与 % ）

**题目**：1200 只静音球，每箱装 50 只，计算需要多少个整箱、余下多少只，以及总箱数（有余数要多一个箱）。

**答案：**

```python
total_qty = 1200
per_box = 50

full_boxes, rest = divmod(total_qty, per_box)
need_boxes = full_boxes + (1 if rest else 0)

print(f"整箱: {full_boxes} 箱，余: {rest} 只")
print(f"实际需要: {need_boxes} 箱")
```

**预期输出：**

```
整箱: 24 箱，余: 0 只
实际需要: 24 箱
```

**解析**：`divmod` 一次返回 `(商, 余数)`。`+ (1 if rest else 0)` 是「有零头就多一个箱」的标准写法。把 `per_box` 改成 45 试试：整箱 26 箱余 30 只 → 需要 27 箱。

### 练习 2：含税价计算（考：Decimal 与金额）

**题目**：用 `Decimal` 算：单价 12.30 元、数量 400、折扣 8%、税率 13%，输出折后价、税额、含税总价（保留两位，四舍五入）。

**答案：**

```python
from decimal import Decimal, ROUND_HALF_UP

def money(v):
    return Decimal(str(v)).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)

price = Decimal("12.30")
qty = 400
discount = Decimal("0.08")
tax_rate = Decimal("0.13")

subtotal = money(price * qty)
after = money(subtotal * (1 - discount))
tax = money(after * tax_rate)

print(f"小计    : {subtotal}")
print(f"折后    : {after}")
print(f"税额    : {tax}")
print(f"含税总价: {after + tax}")
```

**预期输出：**

```
小计    : 4920.00
折后    : 4526.40
税额    : 588.43
含税总价: 5114.83
```

**解析**：`Decimal` 之间运算自动保持精度，`money()` 统一收口到两位。注意 `str(v)` 那一步——如果传进去的是已经污染的 float，误差会被带进来。

### 练习 3：真假值陷阱（考：bool 判断）

**题目**：下面代码输出什么？为什么？

```python
values = [0, "", "0", "False", [], [0], None, "None"]
for v in values:
    print(f"{str(v):8s} -> {'真' if v else '假'}")
```

**预期输出：**

```
0        -> 假
         -> 假
0        -> 真
False    -> 真
[]       -> 假
[0]      -> 真
None     -> 假
None     -> 真
```

**解析**：`"0"`、`"False"`、`"None"` 都是**非空字符串**，一律为真。这是从 Excel / 网页表单读数据时的头号 Bug 来源。正确做法是显式转换：

```python
def to_bool(v):
    if isinstance(v, bool):
        return v
    if v is None:
        return False
    return str(v).strip().lower() in ("true", "1", "yes", "y", "是")
```

### 练习 4：脏数据清洗（考：类型转换综合）

**题目**：写一个 `to_number()`，能把 `"1,200"`、`"8.65元"`、`" 42 "`、`"N/A"`、`None`、`""` 分别转成数字，失败的给默认值 0.0。

**答案：**

```python
def to_number(value, default=0.0):
    if value is None:
        return default
    if isinstance(value, bool):          # bool 是 int 的子类，要先排除
        return default
    if isinstance(value, (int, float)):
        return float(value)
    cleaned = str(value).strip().replace(",", "").replace("元", "").replace("￥", "")
    if cleaned in ("", "-", "N/A", "nan", "None", "null"):
        return default
    try:
        return float(cleaned)
    except ValueError:
        return default

for v in ["1,200", "8.65元", " 42 ", "N/A", None, "", "abc", 1200, 8.65]:
    print(f"{str(v):10s} -> {to_number(v)}")
```

**预期输出：**

```
1,200      -> 1200.0
8.65元     -> 8.65
 42        -> 42.0
N/A        -> 0.0
None       -> 0.0
           -> 0.0
abc        -> 0.0
1200       -> 1200.0
8.65       -> 8.65
```

**解析**：三步走 —— ① 排除 `None` 和 `bool`（`True` 会被当 1）；② 字符串清洗去逗号单位；③ `try/except` 兜底。这个函数你可以直接用在实际项目里。

### 练习 5：毛利率与提价测算（考：综合运算）

**题目**：某款静音球成本 7.20 元，售价 8.65 元。计算当前毛利率；如果要把毛利率提到 25%，售价应定为多少？

**答案：**

```python
cost = 7.20
price = 8.65

margin = (price - cost) / price * 100
print(f"当前毛利率: {margin:.2f}%")

target_margin = 0.25
new_price = cost / (1 - target_margin)
print(f"目标毛利率 25% 时，售价应为: {round(new_price, 2)} 元")
print(f"需提价: {round(new_price - price, 2)} 元（{round((new_price/price - 1) * 100, 1)}%）")

# 验证
print(f"验证: {(new_price - cost) / new_price * 100:.2f}%")
```

**预期输出：**

```
当前毛利率: 16.76%
目标毛利率 25% 时，售价应为: 9.6 元
需提价: 0.95 元（11.0%）
验证: 25.00%
```

**解析**：毛利率公式是 `(售价-成本)/售价`，反解售价：`售价 = 成本 / (1 - 目标毛利率)`。
注意**毛利率和加价率不是一回事**：加价 25% 是 `成本 × 1.25 = 9.0`，但那只有 20% 毛利率。报价时说清楚是「毛利率」还是「成本加成」，能避免巨大争议。
