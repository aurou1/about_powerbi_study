# ch03 字符串与格式化 🔤

> 本章目标：把「料号清洗」「文本拆分」「中文报表排版」三件事彻底搞定。
> 真实工作里，**80% 的时间花在清洗文本上**——客户给的数据永远是带空格、大小写混乱、格式不统一的。

## 一、本章学习目标

1. 掌握字符串的**索引与切片**（`[2:5]`、`[::-1]`、`[::2]`）
2. 熟练使用**清洗五件套**：`strip` / `split` / `join` / `replace` / `upper`
3. 精通 **f-string** 全部常用格式：千分位、百分比、小数位、补零、对齐、日期
4. 理解字符串**不可变**，知道 `s.replace()` 为什么会「没效果」
5. 躲开 Windows 路径的反斜杠坑（`r"..."`）和中文判断坑（`isdigit` vs `isnumeric`）

## 二、为什么要学这个

客户发来的料号表长这样：

```
" st-bd-42 ", "ST_BD_42", "STBD42", "ST-BD-42 （停产）", "1,200只", "8.65元"
```

同一个东西六种写法。你要把它们统一成 `ST-BD-42` 才能和 ERP 对上。

还有报表：

```
"2026年8月静音球产量1200只，货值10380元，毛利率23.72%"
```

这一行字背后，是 5 个变量 + 4 种格式。学会 f-string，一行搞定。

## 三、概念：字符串是不可变的

```python
s = "ST-BD-42"
s[0] = "X"        # ❌ TypeError: 'str' object does not support item assignment
```

字符串**创建后不能修改**。所有「看起来在改」的方法，其实都是**返回一个新字符串**：

```python
s = "  ST-BD-42  "
s.strip()          # 返回新字符串 "ST-BD-42"，但 s 本身没变！
print(s)           # "  ST-BD-42  "  ← 还是原样

s = s.strip()      # ✅ 必须重新赋值
print(s)           # "ST-BD-42"
```

> 🔴 **新手第一大坑**：`s.strip()` 之后直接用 `s`，发现没效果。记住：**字符串方法都要重新赋值。**

## 四、实操

### 4.1 创建字符串：三种引号

```python
a = '单引号'
b = "双引号"
c = """三引号
可以换行"""

print(a, b)
print(c)
# 引号嵌套：外面双引号，里面就能直接写单引号
print("It's a ball")
print('他说:"这是静音球"')
```

> 三引号 `"""..."""` 有两个用途：**多行字符串** 和 **文档字符串**（ch01 见过）。

### 4.2 索引与切片

```python
s = "ST-BD-42"
print("长度:", len(s))          # 8
print("第1个:", s[0])            # S   （从 0 开始）
print("最后1个:", s[-1])          # 2   （负数从后往前）
print("切片[2:5]:", s[2:5])      # -BD  （左闭右开，取 2、3、4）
print("倒序[::-1]:", s[::-1])    # 24-DB-TS
print("隔一个[::2]:", s[::2])    # S-D4
print("从头[:5]:", s[:5])        # ST-BD
print("到尾[3:]:", s[3:])        # BD-42
```

**预期输出：**

```
长度: 8
第1个: S
最后1个: 2
切片[2:5]: -BD
倒序[::-1]: 24-DB-TS
隔一个[::2]: S-D4
从头[:5]: ST-BD
到尾[3:]: BD-42
```

**切片通式：`s[start:end:step]`** —— start 包含，end **不**包含，step 是步长。

> 中文同样按字符索引：`"静音球"[0]` 是 `"静"`，`len("静音球")` 是 3（不是 9，Python 3 的 str 是 Unicode 字符数）。

### 4.3 清洗五件套 ⭐

```python
s = "  静音球 ST-BD-42  "

print("原样      :", repr(s))
print("strip     :", repr(s.strip()))      # 去首尾空白
print("lstrip    :", repr(s.lstrip()))     # 只去左边
print("rstrip    :", repr(s.rstrip()))     # 只去右边
print("upper     :", "abc".upper())
print("lower     :", "ABC".lower())
print("replace   :", "ST-BD-42".replace("-", "_"))
```

**预期输出：**

```
原样      : '  静音球 ST-BD-42  '
strip     : '静音球 ST-BD-42'
lstrip    : '静音球 ST-BD-42  '
rstrip    : '  静音球 ST-BD-42'
upper     : ABC
lower     : abc
replace   : ST_BD_42
```

> `repr()` 是调试神器：它会把**看不见的空格、换行**显示出来。排查「明明一样却比不上」的问题时必用。

**split 与 join（互为逆操作）：**

```python
line = "A,B, C ,D"
print("split      :", line.split(","))                       # 按逗号切
print("split+去空 :", [x.strip() for x in line.split(",")])   # 顺手去掉每项空格
print("split()    :", "  多个   空格  ".split())              # 不传参数 = 按任意空白切
print("rsplit     :", "ST-BD-42".rsplit("-", 1))             # 从右边切，最多切 1 刀
print("splitlines :", "a\nb\n".splitlines())                 # 按行切
print("partition  :", "ST-BD-42".partition("-"))             # 切成 (前, 分隔符, 后)

print("join       :", "-".join(["2026", "09", "04"]))         # 用 - 连接列表
print("join 换行  :", "\n".join(["第一行", "第二行"]))
```

**预期输出：**

```
split      : ['A', 'B', ' C ', 'D']
split+去空 : ['A', 'B', 'C', 'D']
split()    : ['多个', '空格']
rsplit     : ['ST-BD', '42']
splitlines : ['a', 'b']
partition  : ('ST', '-', 'BD-42')
join       : 2026-09-04
join 换行  : 第一行
第二行
```

### 4.4 查找与判断

```python
s = "ST-BD-42"

print("find('BD')   :", s.find("BD"))        # 3   找不到返回 -1
print("find('XX')   :", s.find("XX"))        # -1  注意：不是报错
print("index('XX')  :", end=" ")
try:
    s.index("XX")
except ValueError as e:
    print("ValueError:", e)                  # 找不到会报错！

print("count('-')   :", s.count("-"))        # 2
print("startswith   :", s.startswith("ST"), "| endswith:", s.endswith("42"))
print("in 判断      :", "BD" in s, "| 不在:", "XX" in s)
```

**预期输出：**

```
find('BD')   : 3
find('XX')   : -1
index('XX')  : ValueError: substring not found
count('-')   : 2
startswith   : True | endswith: True
in 判断      : True | 不在: False
```

> **`find` vs `index`**：都一样，`find` 找不到返回 `-1`，`index` 找不到**抛异常**。
> 判断存在性就用 `in`；要位置就用 `find` 并判断 `!= -1`。

**数字/中文判断（容易踩坑）：**

```python
print("'123'.isdigit()   :", "123".isdigit())        # True
print("'12.3'.isdigit()  :", "12.3".isdigit())       # False  小数点不是数字
print("'一佰'.isnumeric():", "一佰".isnumeric())      # True   中文数字也算
print("'一佰'.isdigit()  :", "一佰".isdigit())        # False  isdigit 只认阿拉伯数字
print("'球'.isalpha()    :", "球".isalpha())          # True   中文算字母
print("'  '.isspace()    :", "  ".isspace())         # True
print("'ABC123'.isalnum():", "ABC123".isalnum())     # True   字母+数字
```

**预期输出：**

```
'123'.isdigit()   : True
'12.3'.isdigit()  : False
'一佰'.isnumeric(): True
'一佰'.isdigit()  : False
'球'.isalpha()    : True
'  '.isspace()    : True
'ABC123'.isalnum(): True
```

> 判断「这串能不能转成数字」，**别用 `isdigit()`**（负数、小数、中文数字都会误判），直接用 ch02 的 `try/except float()` 或 `to_number()`。

### 4.5 格式化三剑客：f-string / format / %

**f-string 是首选**（Python 3.6+），其他两个知道怎么写就行。

```python
qty, unit, amount = 1200, "只", 10380.0

# ① f-string（推荐）：直接在字符串里写变量和表达式
print(f"{qty}{unit}，金额 {amount:,.2f} 元")
print(f"计算过程: {qty} × {8.65} = {qty * 8.65:,.2f}")

# ② str.format()
print("{} {}，金额 {:,.2f} 元".format(qty, unit, amount))

# ③ % 旧式（老代码里常见，能看懂就行）
print("%d%s，金额 %.2f 元" % (qty, unit, amount))
```

**预期输出：**

```
1200只，金额 10,380.00 元
计算过程: 1200 × 8.65 = 10,380.00
1200 只，金额 10,380.00 元
1200只，金额 10380.00 元
```

### 4.6 f-string 格式大全 ⭐

```python
v = 1234567.8915

print(f"默认      : {v}")
print(f"两位小数  : {v:.2f}")
print(f"千分位    : {v:,.2f}")
print(f"百分比    : {0.2366:.2%}")          # 自动 ×100 加 %
print(f"一位百分比: {0.2366:.1%}")
print(f"科学计数  : {v:.2e}")
print(f"补零      : {42:05d}")               # 5 位，不足补 0
print(f"带正负号  : {v:+.2f} | {-v:+.2f}")
```

**预期输出：**

```
默认      : 1234567.8915
两位小数  : 1234567.89
千分位    : 1,234,567.89
百分比    : 23.66%
一位百分比: 23.7%
科学计数  : 1.23e+06
补零      : 00042
带正负号  : +1234567.89 | -1234567.89
```

**对齐（做报表排版必用）：**

```python
print(f"|{'左':<10}|{'中':^10}|{'右':>10}|")
print(f"|{'ST-BD-42':<10}|{'静音球':^10}|{'1200':>10}|")
print(f"|{'*' * 3:<10}|{'*' * 3:^10}|{'*' * 3:>10}|")
```

**预期输出：**

```
|左         |    中     |         右|
|ST-BD-42  |   静音球    |      1200|
|***       |   ***    |       ***|
```

> 同样的中文对不齐问题（ch01 练习 1 提过）：Python 按**字符数**补空格，终端按**显示宽度**渲染。
> 纯英文/数字列（`ST-BD-42`、`1200`）是对齐的，含中文的列会偏。需要严格对齐就用 ch01 的 `pad_cn()`，或者干脆导出 Excel（ch14）。

**日期格式化：**

```python
from datetime import datetime
```

**🔴 Windows 路径的坑：**

```python

```

```
D:\new\test
D:/new/test
```

> **建议一律用 `r"..."` 或正斜杠**。读文件路径、写正则表达式时必加 `r`。

## 五、验证：一次性清洗一批脏料号

```python
import re

raw_codes = [
    " st-bd-42 ", "ST_BD_42", "STBD42",
    "ST-BD-42（停产）", "st-bd-60 ", "  YG-01", "N/A", ""
]

def clean_code(raw):
    """把各种脏写法统一成 ST-BD-42 格式"""
    if not raw or not raw.strip():
        return None
    s = raw.strip().upper()                    # 去空格 + 转大写
    s = re.sub(r"（.*?）|\(.*?\)", "", s)       # 去掉括号备注
    s = s.replace("_", "-").replace(" ", "")   # 下划线空格统一成 -
    if not s or s == "N/A":
        return None
    return s

for raw in raw_codes:
    print(f"  {raw!r:20s} -> {clean_code(raw)}")
```

**预期输出：**

```
  ' st-bd-42 '         -> ST-BD-42
  'ST_BD_42'           -> ST-BD-42
  'STBD42'             -> STBD42
  'ST-BD-42（停产）'       -> ST-BD-42
  'st-bd-60 '          -> ST-BD-60
  '  YG-01'            -> YG-01
  'N/A'                -> None
  ''                   -> None
```

> 注意 `STBD42` 没被处理成 `ST-BD-42` —— **没有统一的规则就别硬猜**。这种情况应该单独列出来人工核对，或者做成「例外映射表」：
> ```python
> SPECIAL = {"STBD42": "ST-BD-42"}
> s = SPECIAL.get(s, s)
> ```
> **清洗的原则是：能规则化的规则化，不能规则化的列出来让人看。** 自动补全不确定的数据，比留空更危险。

## 六、FDE 现场场景：CSV 手工解析

客户给的是 txt，每行用 `|` 分隔（不是逗号），还有空行和注释行：

```python
text = """# 这是注释行
ST-BD-42|包布静音球|1200|8.65
ST-BD-60|滴胶静音球|400|12.30

YG-01|泳镜|250|45.00
"""

rows = []
for line in text.splitlines():
    line = line.strip()
    if not line or line.startswith("#"):     # 跳过空行和注释
        continue
    parts = [p.strip() for p in line.split("|")]
    if len(parts) != 4:                       # 字段数不对就跳过并告警
        print(f"⚠️ 跳过异常行: {line}")
        continue
    code, name, qty, price = parts
    rows.append({"code": code, "name": name,
                 "qty": int(qty), "price": float(price)})

for r in rows:
    print(f"  {r['code']:10s} {r['name']:8s} {r['qty']:>5d}只 × {r['price']:>6.2f} = {r['qty'] * r['price']:>10,.2f}")
print(f"合计: {sum(r['qty'] * r['price'] for r in rows):,.2f} 元")
```

**预期输出：**

```
  ST-BD-42   包布静音球     1200只 ×   8.65 =  10,380.00
  ST-BD-60   滴胶静音球      400只 ×  12.30 =   4,920.00
  YG-01      泳镜         250只 ×  45.00 =  11,250.00
合计: 26,550.00 元
```

这套「逐行 strip → 跳过空行注释 → 按分隔符 split → 校验字段数 → 转类型」的流程，是处理任何文本数据的万能套路。ch08 会教你用 `csv` 模块和 pandas 做得更优雅。

| 清洗原则 | 能规则化的规则化，不能规则化的列出来人工核对 |

### 练习 1：料号清洗（考：strip/upper/replace）

**题目**：把 `[" st-bd-42 ", "ST_BD_60", " yg-01 ", "ST-BD-42"]` 清洗成统一格式 `ST-BD-42`，并统计清洗后有多少个不同料号。

**答案：**

```python
raw = [" st-bd-42 ", "ST_BD_60", " yg-01 ", "ST-BD-42"]

cleaned = [s.strip().upper().replace("_", "-") for s in raw]
print("清洗后:", cleaned)
print("去重后:", sorted(set(cleaned)))
print("不同料号数:", len(set(cleaned)))
```

**预期输出：**

```
清洗后: ['ST-BD-42', 'ST-BD-60', 'YG-01', 'ST-BD-42']
去重后: ['ST-BD-42', 'ST-BD-60', 'YG-01']
不同料号数: 3
```

**解析**：三步链式调用 `strip().upper().replace()`，配合列表推导一行搞定。`set()` 去重，`sorted()` 排序（ch05 详讲集合，ch04 详讲推导式）。

### 练习 2：解析料号结构（考：split/切片）

**题目**：料号格式是 `系列-工艺-规格`，如 `ST-BD-42`。写代码拆出三个部分，并判断规格是否 ≥ 50（大球）。

**答案：**

```python
code = "ST-BD-42"
parts = code.split("-")
if len(parts) == 3:
    series, craft, spec = parts
    print(f"系列: {series} | 工艺: {craft} | 规格: {spec}")
    print("是否大球(≥50):", int(spec) >= 50)
else:
    print(f"⚠️ 料号格式异常: {code}")

# 用 partition 也能拆
head, sep, tail = "ST-BD-42".partition("-")
print("partition:", head, "|", tail)
```

**预期输出：**

```
系列: ST | 工艺: BD | 规格: 42
是否大球(≥50): False
partition: ST | BD-42
```

**解析**：`split` 适合「全部拆开」，`partition` 适合「只拆第一刀」。拆完一定要检查 `len(parts)`，客户数据里总会混进格式不对的行。

### 练习 3：f-string 排版报表（考：格式化综合）

**题目**：用 f-string 输出下面的表（金额千分位两位小数、毛利率百分比一位小数、数量右对齐）。

**答案：**

```python
rows = [
    ("ST-BD-42", "包布静音球", 1200, 8.65, 0.1676),
    ("ST-BD-60", "滴胶静音球", 400, 12.30, 0.2211),
    ("YG-01", "泳镜", 250, 45.00, 0.3125),
]

print(f"{'料号':<10}{'品名':<12}{'数量':>8}{'单价':>10}{'金额':>14}{'毛利率':>9}")
print("-" * 63)
total = 0
for code, name, qty, price, margin in rows:
    amount = qty * price
    total += amount
    print(f"{code:<10}{name:<12}{qty:>8,}{price:>10.2f}{amount:>14,.2f}{margin:>9.1%}")
print("-" * 63)
print(f"{'合计':<22}{'':>8}{'':>10}{total:>14,.2f}")
```

**实际输出：**

```
料号        品名                数量        单价            金额      毛利率
---------------------------------------------------------------
ST-BD-42  包布静音球          1,200      8.65     10,380.00    16.8%
ST-BD-60  滴胶静音球            400     12.30      4,920.00    22.1%
YG-01     泳镜               250     45.00     11,250.00    31.2%
---------------------------------------------------------------
合计                                           26,550.00
```

（中文列的对不齐是终端字宽问题，数字列 `1,200` / `8.65` / `10,380.00` / `16.8%` 是严格右对齐的——**数字对齐才是报表的关键**。）

**解析**：`{qty:>8,}` 右对齐 + 千分位；`{margin:>9.1%}` 自动 ×100 加百分号。毛利率存成小数（0.1676）比存成 16.76 更灵活——展示时再格式化。

### 练习 4：拼接与拆分（考：join/split）

**题目**：把 `["静音球", "泳镜", "篮球", "排球"]` 拼成 `"静音球/泳镜/篮球/排球"`，再拆回列表，并统计总字符数。

**答案：**

```python
items = ["静音球", "泳镜", "篮球", "排球"]
joined = "/".join(items)
print("拼接:", joined)
print("拆回:", joined.split("/"))
print("总字符数(不含分隔符):", sum(len(x) for x in items))
print("每个长度:", {x: len(x) for x in items})
```

**预期输出：**

```
拼接: 静音球/泳镜/篮球/排球
拆回: ['静音球', '泳镜', '篮球', '排球']
总字符数(不含分隔符): 9
每个长度: {'静音球': 3, '泳镜': 2, '篮球': 2, '排球': 2}
```

**解析**：`"分隔符".join(列表)` 是列表转字符串的标准写法；反过来用 `split`。注意 `join` 只能拼**字符串列表**，有数字要先 `str()` 或 `map(str, ...)`。

### 练习 5：转义与路径（考：raw 字符串 + 文件名生成）

**题目**：用 `r"..."` 写 Windows 路径，并生成带日期的报表文件名。

**答案：**

```python
from datetime import datetime

base = r"D:\WorkBudy\Work_project\outputs"      # raw 字符串，反斜杠不转义
today = datetime(2026, 9, 4)

filename = f"静音球生产标准_{today:%Y%m%d}.xlsx"
full_path = base + "\\" + filename

print("目录:", base)
print("文件名:", filename)
print("完整路径:", full_path)
print("文件名不含路径:", full_path.split("\\")[-1])
print("扩展名:", filename.split(".")[-1])
```

**预期输出：**

```
目录: D:\WorkBudy\Work_project\outputs
文件名: 静音球生产标准_20260904.xlsx
完整路径: D:\WorkBudy\Work_project\outputs\静音球生产标准_20260904.xlsx
文件名不含路径: 静音球生产标准_20260904.xlsx
扩展名: xlsx
```

**解析**：`r"..."` 让反斜杠保持原样；f-string 的 `{today:%Y%m%d}` 直接格式化日期对象。
ch09 会教你用 `pathlib` 的 `/` 运算符拼路径，比手动拼字符串安全得多（`Path(base) / filename`）。
