# ch04 列表与元组 📦

> 本章目标：学会用列表存「一批数据」，并躲开 Python 最著名的坑——**可变对象的引用陷阱**。
> 列表是你未来用得最多的结构：一批料号、一批订单、一批客户，全靠它。

## 一、本章学习目标

1. 掌握列表的**增删改查**：`append` / `insert` / `pop` / `remove` / 索引赋值
2. 分清 **`sort()`（原地改）** 与 **`sorted()`（返回新列表）**
3. 精通**切片**（`[1:3]` / `[::-1]` / `[::2]`）与**拆包**（`a, b, *rest = ...`）
4. 🔴 **理解引用陷阱**：`b = a` 不是复制，`[[0]]*3` 会互相串改，`copy()` 是浅拷贝
5. 理解**元组不可变**，知道什么时候用元组（字典键、函数多返回值、防误改）

---

## 二、为什么要学这个

现实数据从来不是一个值，而是**一批**：

```python
codes = ["ST-BD-42", "ST-BD-60", "YG-01", "BL-05"]      # 一批料号
quantities = [1200, 400, 250, 80]                        # 对应数量
orders = [("O001", 1200, "已完成"), ("O002", 800, "已取消")]  # 一批订单
```

而且列表是**可变**的，这带来便利，也带来最大的坑：

```python
a = [1, 2, 3]
b = a          # 你以为复制了一份
b.append(4)
print(a)       # [1, 2, 3, 4] ← a 也变了！
```

**不懂这个，你写的脚本迟早会把原始数据改坏。**

---

## 三、概念：可变 vs 不可变

| | 可变（mutable） | 不可变（immutable） |
|---|---|---|
| 类型 | `list` / `dict` / `set` | `int` / `float` / `str` / `bool` / `tuple` |
| 改内容 | 原地改，地址不变 | 只能创建新对象 |
| 能否作字典键 | ❌ 不能 | ✅ 能 |
| 传参给函数 | 函数内改动**会影响外部** | 函数内改动**不影响外部** |

```python
# 可变：list
a = [1, 2, 3]
print(id(a))
a.append(4)          # 原地改
print(id(a))         # id 没变，还是同一个对象

# 不可变：str
s = "abc"
print(id(s))
s = s + "d"          # 创建了新的
print(id(s))         # id 变了
```

## 四、实操：列表

### 4.1 创建与访问

```python
cats = ["数码", "食品", "家居", "服饰", "美妆"]

print("长度      :", len(cats))
print("第一个    :", cats[0])        # 从 0 开始
print("最后一个  :", cats[-1])       # 负数倒数
print("切片[1:3] :", cats[1:3])      # 取索引 1、2（不含 3）
print("切片[:2]  :", cats[:2])
print("切片[-2:] :", cats[-2:])
print("倒序[::-1]:", cats[::-1])
print("步长[::2] :", cats[::2])
```

**预期输出：**

```
长度      : 5
第一个    : 数码
最后一个  : 美妆
切片[1:3] : ['食品', '家居']
切片[:2]  : ['数码', '食品']
切片[-2:] : ['服饰', '美妆']
倒序[::-1]: ['美妆', '服饰', '家居', '食品', '数码']
步长[::2] : ['数码', '家居', '美妆']
```

**嵌套列表（二维）：**

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
print("取一行:", matrix[1])        # [4, 5, 6]
print("取一个:", matrix[1][2])      # 6  先取第 1 行，再取第 2 列
print("取一列:", [row[2] for row in matrix])   # [3, 6, 9]
```

### 4.2 增删改

```python
cats = ["数码", "食品", "家居", "服饰", "美妆"]

cats.append("运动")                 # 末尾加一个
print("append    :", cats)

cats.insert(1, "母婴")              # 在索引 1 处插入
print("insert    :", cats)

last = cats.pop()                   # 弹出最后一个，返回它
print("pop       :", last, "->", cats)

cats.pop(0)                         # 弹出指定位置
print("pop(0)    :", cats)

cats.remove("母婴")                 # 按值删除（只删第一个）
print("remove    :", cats)

del cats[1:3]                       # 按切片删除
print("del 切片  :", cats)

cats[0] = "数码家电"                 # 按索引改
print("索引赋值  :", cats)
```

**预期输出：**

```
append    : ['数码', '食品', '家居', '服饰', '美妆', '运动']
insert    : ['数码', '母婴', '食品', '家居', '服饰', '美妆', '运动']
pop       : 运动 -> ['数码', '母婴', '食品', '家居', '服饰', '美妆']
pop(0)    : ['母婴', '食品', '家居', '服饰', '美妆']
remove    : ['食品', '家居', '服饰', '美妆']
del 切片  : ['食品', '美妆']
索引赋值  : ['数码家电', '美妆']
```

> **⚠️ 遍历时不要删元素！** 会跳过元素：
> ```python
> # 错误示范
> nums = [1, 2, 3, 4, 5]
> for n in nums:
>     if n % 2 == 0:
>         nums.remove(n)
> print(nums)        # [1, 3, 5] 这次对了，但换个数据就错
>
> # 正确做法：用推导式生成新列表（ch06）
> nums = [n for n in nums if n % 2 != 0]
> ```

### 4.3 排序：`sort()` vs `sorted()`

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]

print("sorted      :", sorted(nums))                    # 返回新列表
print("sorted 降序 :", sorted(nums, reverse=True))
print("原列表没变  :", nums)                             # ✅ 还是原样

nums.sort()                                             # 原地排序，返回 None
print("sort 后     :", nums)
```

**预期输出：**

```
sorted      : [1, 1, 2, 3, 4, 5, 6, 9]
sorted 降序 : [9, 6, 5, 4, 3, 2, 1, 1]
原列表没变  : [3, 1, 4, 1, 5, 9, 2, 6]
sort 后     : [1, 1, 2, 3, 4, 5, 6, 9]
```

> `sorted()` 返回新列表，`sort()` 改原列表并**返回 `None`**。
> 🔴 经典错误：`nums = nums.sort()` → `nums` 变成 `None`！

**按自定义规则排序（`key` 参数）：**

```python
codes = ["ST-BD-42", "YG-01", "ST-BD-60-HEAVY", "BL-05"]
print("按长度     :", sorted(codes, key=len))
print("按长度倒序 :", sorted(codes, key=len, reverse=True))

names = ["静音球", "包布滴胶加重款静音球", "泳镜", "篮球"]
print("中文按长度 :", sorted(names, key=len))

# 按字典里的某个字段排序（实战最常用）
products = [
    {"code": "ST-BD-42", "price": 8.65},
    {"code": "YG-01", "price": 45.00},
    {"code": "ST-BD-60", "price": 12.30},
]
print("按价格     :", [p["code"] for p in sorted(products, key=lambda p: p["price"])])
print("按价格降序 :", [p["code"] for p in sorted(products, key=lambda p: -p["price"])])

# 多重排序：先按品类升序，同品类按金额降序
rows = [("数码", 100), ("数码", 50), ("食品", 200)]
print("多重排序   :", sorted(rows, key=lambda t: (t[0], -t[1])))
```

**预期输出：**

```
按长度     : ['YG-01', 'BL-05', 'ST-BD-42', 'ST-BD-60-HEAVY']
按长度倒序 : ['ST-BD-60-HEAVY', 'ST-BD-42', 'YG-01', 'BL-05']
中文按长度 : ['泳镜', '篮球', '静音球', '包布滴胶加重款静音球']
按价格     : ['ST-BD-42', 'ST-BD-60', 'YG-01']
按价格降序 : ['YG-01', 'ST-BD-60', 'ST-BD-42']
多重排序   : [('数码', 100), ('数码', 50), ('食品', 200)]
```

> `YG-01` 和 `BL-05` 长度都是 5，排序后保持了原顺序——Python 的排序是**稳定排序**（相同 key 的元素保持原有相对次序）。这个特性在多重排序时很有用：可以先按次要字段排一次，再按主要字段排一次。

> 多重排序的技巧：`key=lambda t: (t[0], -t[1])` —— 元组比较，**第二项取负实现降序**（数字才这么干，字符串不行）。

### 4.4 🔴 引用陷阱（本章最重要）

**陷阱 1：`b = a` 不是复制**

```python
a = [1, 2, 3]
b = a                # 只是给同一个对象贴了第二个标签
b.append(4)
print("a =", a)      # [1, 2, 3, 4] ← a 也被改了
print("a is b:", a is b)    # True 同一个对象
```

**三种正确的复制方式：**

```python
a = [1, 2, 3]

b1 = a.copy()        # ① 方法（推荐）
b2 = a[:]            # ② 切片（老写法，一样效果）
b3 = list(a)         # ③ 构造新列表

b1.append(99)
print("a  :", a)     # [1, 2, 3]  没被改
print("b1 :", b1)    # [1, 2, 3, 99]
```

**陷阱 2：`[[0]] * 3` 三个元素其实是一个**

```python
nested = [[0]] * 3
print("初始:", nested)          # [[0], [0], [0]]
nested[0].append(1)
print("改一个后:", nested)      # [[0, 1], [0, 1], [0, 1]] ← 三个全变了！
```

**正确做法：用推导式创建**

```python
safe = [[0] for _ in range(3)]
safe[0].append(1)
print("推导式创建:", safe)      # [[0, 1], [0], [0]] ✅
```

**陷阱 3：`copy()` 只是浅拷贝**

```python
import copy

a = [[1], [2]]
b = a.copy()          # 浅拷贝：只复制了外层
b[0].append(9)
print("浅拷贝后 a =", a)        # [[1, 9], [2]] ← 内层还是共享的！

c = copy.deepcopy(a)  # 深拷贝：里里外外全复制
c[0].append(99)
print("深拷贝后 a =", a)        # [[1, 9], [2]] ✅ 没被改
```

**预期输出：**

```
初始: [[0], [0], [0]]
改一个后: [[0, 1], [0, 1], [0, 1]]
推导式创建: [[0, 1], [0], [0]]
浅拷贝后 a = [[1, 9], [2]]
深拷贝后 a = [[1, 9], [2]]
```

> **规则**：
> - 一维列表 → `a.copy()` 足够
> - 嵌套列表 / 列表里放字典 → 用 `copy.deepcopy()`
> - 不确定就用 deepcopy（慢一点但安全）

### 4.5 常用操作与内置函数

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
cats = ["数码", "食品", "家居"]

print("count(1)  :", nums.count(1))          # 出现次数
print("index(9)  :", nums.index(9))          # 第一次出现的位置
print("in        :", 3 in nums, "| not in:", 99 not in nums)
print("sum       :", sum(nums))
print("max/min   :", max(nums), min(nums))
print("max key   :", max(cats, key=len))
print("sum 带初值:", sum([1, 2], 10))         # 13
print("any/all   :", any([0, 1, 0]), all([1, 2, 0]))
print("len       :", len(nums))

# 拼接与重复
print("+ 拼接    :", [1, 2] + [3, 4])
print("* 重复    :", ["x"] * 3)
print("extend    :", end=" ")
a = [1, 2]; a.extend([3, 4]); print(a)      # 原地追加多个
```

**预期输出：**

```
count(1)  : 2
index(9)  : 5
in        : True | not in: True
sum       : 31
max/min   : 9 1
max key   : 数码
sum 带初值: 13
any/all   : True False
len       : 8
+ 拼接    : [1, 2, 3, 4]
* 重复    : ['x', 'x', 'x']
extend    : [1, 2, 3, 4]
```

> `append(x)` 是把 x **作为一个元素**加进去；`extend([x, y])` 是把列表**拆开**逐个加进去。
> ```python
> a = [1, 2]; a.append([3, 4]); print(a)    # [1, 2, [3, 4]]  嵌套了！
> a = [1, 2]; a.extend([3, 4]); print(a)    # [1, 2, 3, 4]    平铺
> ```

### 4.6 `enumerate` / `zip` / 拆包

```python
cats = ["数码", "食品", "家居"]

# enumerate：同时拿到索引和值（写循环必备）
for i, cat in enumerate(cats, start=1):
    print(f"  {i}. {cat}")

# zip：把两个列表配对
codes = ["ST-BD-42", "ST-BD-60"]
qtys = [1200, 400]
for code, qty in zip(codes, qtys):
    print(f"  {code}: {qty} 只")

print("zip 成列表 :", list(zip(codes, qtys)))
print("zip 建字典 :", dict(zip(codes, qtys)))
print("解压 zip*  :", list(zip(*[("a", 1), ("b", 2)])))   # 行列转置
print("不等长截断 :", list(zip([1, 2, 3], ["a"])))         # 按短的来
```

**预期输出：**

```
  1. 数码
  2. 食品
  3. 家居
  ST-BD-42: 1200 只
  ST-BD-60: 400 只
zip 成列表 : [('ST-BD-42', 1200), ('ST-BD-60', 400)]
zip 建字典 : {'ST-BD-42': 1200, 'ST-BD-60': 400}
解压 zip*  : [('a', 'b'), (1, 2)]
不等长截断 : [(1, 'a')]
```

**拆包（解包赋值）：**

```python
first, second, third = ["数码", "食品", "家居"]
print(first, second, third)

first, *rest = [1, 2, 3, 4, 5]        # * 收集剩余
print("first:", first, "| rest:", rest)

first, *mid, last = [1, 2, 3, 4, 5]   # * 放中间
print("first:", first, "| mid:", mid, "| last:", last)

a, b = b, a if False else (0, 1)      # 交换变量
x, y = 10, 20
x, y = y, x                            # 一行交换
print("交换后:", x, y)
```

**预期输出：**

```

first: 1 | rest: [2, 3, 4, 5]
first: 1 | mid: [2, 3, 4] | last: 5
交换后: 20 10
```

## 五、实操：元组

### 5.1 元组 = 不可变列表

```python
t = ("数码", 1.16)
print("元组   :", t)
print("取值   :", t[0], t[1])
print("切片   :", t[:1])
print("长度   :", len(t))
print("count  :", (1, 1, 2).count(1))
print("index  :", (1, 2, 3).index(2))

try:
    t[0] = "食品"          # ❌ 不可变
except TypeError as e:
    print("修改元组 ->", type(e).__name__ + ":", e)
```

**预期输出：**

```
元组   : ('数码', 1.16)
取值   : 数码 1.16
切片   : ('数码',)
长度   : 2
count  : 2
index  : 1
修改元组 -> TypeError: 'tuple' object does not support item assignment
```

### 5.2 三个必知的细节

```python
# ① 单元素元组必须带逗号
print(type((1)))       # <class 'int'>   ← 不是元组！
print(type((1,)))      # <class 'tuple'> ← 这才对

# ② 元组可以比较（按元素依次比）
print((1, 2) < (1, 3))      # True
print(("a",) < ("b",))      # True

# ③ 元组可以作字典键（列表不行）
print({("数码", "2026"): 100})          # ✅
try:
    {["数码", "2026"]: 100}
except TypeError as e:
    print("列表作键 ->", type(e).__name__ + ":", e)
```

**预期输出：**

```
<class 'int'>
<class 'tuple'>
True
True
{('数码', '2026'): 100}
列表作键 -> TypeError: unhashable type: 'list'
```

### 5.3 什么时候用元组

| 场景 | 用元组的好处 |
|---|---|
| **函数返回多个值** | `return count, total, avg` —— 本质是返回元组 |
| **不想被人改的数据** | 配置常量、坐标、日期，防止误操作 |
| **字典的键** | 复合键 `{(省份, 年份): 金额}` |
| **格式化字符串** | `"%s: %d" % ("静音球", 1200)` |

```python
# 函数多返回值（实战最常见）
def analyze(rows):
    total = sum(rows)
    return len(rows), total, round(total / len(rows), 2)

n, total, avg = analyze([1200, 400, 250, 80])
print(f"共 {n} 项，合计 {total}，平均 {avg}")

# 命名元组：像对象一样访问，比索引可读
from collections import namedtuple
Product = namedtuple("Product", ["code", "name", "price"])
p = Product("ST-BD-42", "包布静音球", 8.65)
print(p.code, p.name, p.price)         # 按名字访问
print(p[0])                            # 也能按索引
print(p._asdict())                     # 转成字典
```

**预期输出：**

```
共 4 项，合计 1930，平均 482.5
ST-BD-42 包布静音球 8.65
ST-BD-42
{'code': 'ST-BD-42', 'name': '包布静音球', 'price': 8.65}
```

> `namedtuple` 是「轻量版类」，ch10 学的 `dataclass` 是它的完全体。
> 元组 vs 列表的选择口诀：**数据要改 → 列表；数据定了不改 → 元组。**

## 六、验证：处理一批订单数据

```python
orders = [
    ("O001", "数码", 1200, "已完成"),
    ("O002", "食品", 400, "已取消"),
    ("O003", "数码", 2500, "已完成"),
    ("O004", "美妆", 800, "已完成"),
    ("O005", "家居", 1500, "退款"),
]

# 1. 筛选有效订单
valid = [o for o in orders if o[3] == "已完成"]
print(f"有效订单: {len(valid)} / {len(orders)} 单")

# 2. 按品类汇总（先按品类去重）
categories = sorted(set(o[1] for o in valid))
print("\n品类汇总:")
for cat in categories:
    amounts = [o[2] for o in valid if o[1] == cat]
    print(f"  {cat}: {len(amounts)} 单，合计 {sum(amounts):,} 元")

# 3. 找金额最高的订单
top = max(valid, key=lambda o: o[2])
print(f"\n最大订单: {top[0]} {top[1]} {top[2]:,} 元")

# 4. 排序展示
print("\n按金额降序:")
for i, (oid, cat, amt, st) in enumerate(sorted(valid, key=lambda o: -o[2]), 1):
    print(f"  {i}. {oid}  {cat}  {amt:>6,}")
```

**预期输出：**

```
有效订单: 3 / 5 单

品类汇总:
  数码: 2 单，合计 3,700 元
  美妆: 1 单，合计 800 元

最大订单: O003 数码 2,500 元

按金额降序:
  1. O003  数码   2,500
  2. O001  数码   1,200
  3. O004  美妆     800
```

> 注意 `max(valid, key=lambda o: o[2])` 返回的是**整个元组**，不是金额。
> 这是 `key` 参数最实用的地方：**用某个字段比较，但返回整条记录。**

## 七、FDE 现场场景：改坏了原始数据

**事故**：你写了个函数「标记异常订单」，结果调用后原始订单列表被改了，后面所有分析全错。

```python
def mark_abnormal(data):        # ❌ 错误示范：直接改了传入的列表
    for i in range(len(data)):
        if data[i][2] > 2000:
            data[i] = (data[i][0], data[i][1], data[i][2], "异常")
    return data

orders = [("O001", "数码", 1200), ("O002", "数码", 2500)]
result = mark_abnormal(orders)
print("原始 orders:", orders)
```

**预期输出（出事了）：**

```
原始 orders: [('O001', '数码', 1200), ('O002', '数码', 2500, '异常')]
```

调用完之后，**原始 `orders` 被改了**——第二条订单从 3 元素变成 4 元素。后续任何按 `o[2]` 取金额的代码，拿到的就不再是数字了。

**正确做法：函数内不碰入参，返回新列表**

```python
def mark_abnormal_safe(data):
    """不改原始数据，返回新列表"""
    return [(o[0], o[1], o[2], "异常" if o[2] > 2000 else "正常")
            for o in data]

orders = [("O001", "数码", 1200), ("O002", "数码", 2500)]
result = mark_abnormal_safe(orders)
print("原始 orders:", orders)    # 原样不动 ✅
print("结果 result:", result)
```

**预期输出：**

```
原始 orders: [('O001', '数码', 1200), ('O002', '数码', 2500)]
结果 result: [('O001', '数码', 1200, '正常'), ('O002', '数码', 2500, '异常')]
```

> **FDE 铁律**：给客户写的数据处理函数，**绝不修改入参**。要么返回新对象，要么在函数第一行 `data = copy.deepcopy(data)`。
> 否则客户复用你的函数时，数据被悄悄改掉，排查三天都找不到原因。

## 八、本章小结

| 你学到了 | 关键点 |
|---|---|
| 列表增删改 | `append` / `insert` / `pop` / `remove` / `del` / 索引赋值 |
| `sort()` vs `sorted()` | `sort()` 原地改返回 `None`；`sorted()` 返回新列表 |
| `key` 参数 | `sorted(x, key=lambda p: p["price"])`；多重排序用元组 `(a, -b)` |
| 切片 | `[start:end:step]`，`[::-1]` 倒序；切片产生**新列表** |
| 🔴 `b = a` 不是复制 | 用 `a.copy()` / `a[:]` / `list(a)` |
| 🔴 `[[0]]*3` 共享引用 | 用 `[[0] for _ in range(3)]` |
| 🔴 浅拷贝陷阱 | 嵌套结构用 `copy.deepcopy()` |
| `enumerate` / `zip` | 循环拿索引、配对两个列表、`zip(*x)` 转置 |
| 拆包 | `a, b = ...`、`first, *rest = ...` |
| 元组 | 不可变，可作字典键，用于多返回值；单元素要写 `(1,)` |
| `namedtuple` | 带名字的元组，`p.code` 可读访问 |
| 函数不改入参 | 返回新列表，用推导式 |

## 九、练习题

### 练习 1：`sort()` 与 `sorted()` 的区别（考：原地 vs 新列表）

**题目**：下面代码输出什么？

```python
nums = [3, 1, 2]
r1 = nums.sort()
r2 = sorted(nums)
print(r1, r2, nums)
```

**答案与预期输出：**

```
None [1, 2, 3] [1, 2, 3]
```

**解析**：`sort()` 原地排序并**返回 `None`**，所以 `r1` 是 `None`。`sorted()` 返回排好的**新列表**。
最常见的 Bug 是写 `nums = nums.sort()`，结果 `nums` 直接变成 `None`，后面全崩。**要新列表就用 `sorted()`。**

---

### 练习 2：躲开引用陷阱（考：copy）

**题目**：下面代码想「复制一份再改」，但原列表被改了。修正它。

```python
config = {"折扣": [0.02, 0.08], "税率": 0.13}
backup = config          # ❌ 不是复制
backup["折扣"].append(0.20)
print(config)            # 原数据被污染
```

**答案：**

```python
import copy

config = {"折扣": [0.02, 0.08], "税率": 0.13}
backup = copy.deepcopy(config)     # ✅ 深拷贝
backup["折扣"].append(0.20)

print("原始 config:", config)      # 不变
print("backup     :", backup)
```

**预期输出：**

```
原始 config: {'折扣': [0.02, 0.08], '税率': 0.13}
backup     : {'折扣': [0.02, 0.08, 0.2], '税率': 0.13}
```

**解析**：字典里嵌套了列表，**必须 deepcopy**。`config.copy()` 也只是浅拷贝，内层列表还是共享的。

---

### 练习 3：二维列表取列（考：嵌套与推导式）

**题目**：下面的销售矩阵，每行是 `[品名, 1月, 2月, 3月]`。取出 **2 月销量**（索引 2）并算合计，再把它转置。

```python
sales = [
    ["数码", 100, 150, 120],
    ["食品", 200, 180, 220],
    ["美妆", 90, 130, 110],
]
```

**答案：**

```python
feb = [row[2] for row in sales]        # 索引 2 → 2 月那一列
print("2月销量:", feb)
print("合计    :", sum(feb))

# 转置：把 3×4 变成 4×3
transposed = list(zip(*sales))
print("转置后:", transposed)
```

**预期输出：**

```
2月销量: [150, 180, 130]
合计    : 460
转置后: [('数码', '食品', '美妆'), (100, 200, 90), (150, 180, 130), (120, 220, 110)]
```

**解析**：`[row[2] for row in sales]` 是取列的标准写法——注意**索引 0 是品名**，取数值列要从 1 开始数。
`zip(*sales)` 的 `*` 把列表「拆散」成多个参数，实现行列转置，转置后第 0 行是品名、第 1 行是 1 月、第 2 行是 2 月……ch12 学 pandas 后，这些操作会变成 `df.iloc[:, 2]` 和 `df.T`。

### 练习 4：拆包处理订单（考：元组拆包）

**题目**：用拆包遍历订单列表，输出每单的详情，并找出金额最大的订单号。

**答案：**

```python
orders = [
    ("O001", "ST-BD-42", 1200, 8.65),
    ("O002", "YG-01", 250, 45.00),
    ("O003", "ST-BD-60", 400, 12.30),
]

for oid, code, qty, price in orders:
    print(f"  {oid}  {code:10s} {qty:>5d} × {price:>6.2f} = {qty * price:>10,.2f}")

top = max(orders, key=lambda o: o[2] * o[3])
oid, code, qty, price = top
print(f"\n最大金额订单: {oid}（{code}），{qty * price:,.2f} 元")
```

**预期输出：**

```
  O001  ST-BD-42    1200 ×   8.65 =  10,380.00
  O002  YG-01        250 ×  45.00 =  11,250.00
  O003  ST-BD-60     400 ×  12.30 =   4,920.00

最大金额订单: O002（YG-01），11,250.00 元
```

**解析**：`for oid, code, qty, price in orders` 直接把元组拆成四个变量，比 `o[0]`、`o[1]` 可读得多。
**注意最大金额是 O002 不是 O001** —— 数量最多的不一定金额最高，做业务分析时容易凭直觉搞错。

### 练习 5：多维排序（考：key 与元组）

**题目**：把下面订单按「品类升序 + 金额降序」排列（同品类内金额高的在前）。

```python
orders = [("数码", 100), ("食品", 200), ("数码", 300), ("美妆", 150)]
```

**答案：**

```python
orders = [("数码", 100), ("食品", 200), ("数码", 300), ("美妆", 150)]

sorted_orders = sorted(orders, key=lambda o: (o[0], -o[1]))
for cat, amt in sorted_orders:
    print(f"  {cat}: {amt}")
```

**预期输出：**

```
  数码: 300
  数码: 100
  美妆: 150
  食品: 200
```

**解析**：`key=lambda o: (o[0], -o[1])` 返回元组，Python 先比第一项，相同再比第二项。
第二项取负 `-o[1]` 实现「金额降序」。品类是字符串，要降序就得用 `reverse=True` 或更复杂的写法——**数字降序用负号，字符串降序用 `reverse`**。

> ch12 的 pandas 里，这个需求就是 `df.sort_values(["品类", "金额"], ascending=[True, False])`，一行搞定。
