# ch05 字典与集合 🔑

> 本章目标：学会用**字典按名字取值**，用**集合去重**，用 **`Counter` 一行完成分组计数**。
> 字典是 Python 里用得第二多的结构（第一是列表），也是 JSON / Excel / 数据库记录的自然映射。

---

## 一、本章学习目标

1. 掌握字典的**增删改查**，以及为什么 **`d.get(k)` 比 `d[k]` 安全**
2. 会用**字典推导式**、`setdefault`、嵌套字典
3. 用 **字典做分组统计**（`defaultdict`）和**计数**（`Counter`）—— 这是数据分析的核心操作
4. 掌握**集合**的去重与交并差运算
5. 理解**可哈希**（hashable）—— 什么能当字典的键

---

## 二、为什么要学这个

列表按位置取值：`orders[0]` 是什么？不知道，得看第 0 项长啥样。

字典按名字取值：`product["price"]` —— 一眼就知道是价格。

真实数据天然就是字典形态：

```python
# 一条产品记录
product = {"code": "ST-BD-42", "name": "包布静音球", "price": 8.65, "stock": 1200}
# 一条订单记录
order = {"order_id": "O001", "customer": "梁诗", "amount": 1200, "status": "已完成"}
# Excel 一行、数据库一条记录、JSON 一个对象 —— 都是字典
```

而且**分组统计**这个数据分析最高频的操作，用字典最顺手：

```python
# 按品类汇总金额
by_category = {}
for row in rows:
    by_category[row["品类"]] = by_category.get(row["品类"], 0) + row["金额"]
```

## 三、概念：字典是键值映射

| 特性 | 说明 |
|---|---|
| 结构 | `{键: 值, 键: 值}`，键唯一 |
| 查找速度 | **极快**，无论字典多大，查找都是几乎瞬时（哈希表实现） |
| 键的要求 | 必须**可哈希**（不可变）：`str` / `int` / `float` / `bool` / `tuple` ✅；`list` / `dict` / `set` ❌ |
| 有序性 | Python 3.7+ **保持插入顺序** |
| 可变 | 是（可以增删改） |

```python
# 列表查找：从头扫到尾，数据越多越慢
codes = ["ST-BD-42", "YG-01", ...]     # 1 万个
"ST-BD-42" in codes                     # 最坏要扫 1 万次

# 字典查找：直接定位，跟大小无关
price_map = {"ST-BD-42": 8.65, "YG-01": 45.00}   # 1 万个
price_map.get("ST-BD-42")                        # 1 次命中
```

> **性能提示**：需要在大量数据里反复查找某个值，先把列表转成字典（或集合），能把 O(n) 变成 O(1)。ch13 处理几千行数据时你会明显感受到差别。

## 四、实操：字典

### 4.1 创建与访问

```python
product = {"code": "ST-BD-42", "name": "包布静音球", "price": 8.65, "stock": 1200}

print("整个字典 :", product)
print("取值     :", product["name"])
print("长度     :", len(product))

# 🔴 取值两种方式
print("有这个键 :", product.get("price"))        # 8.65
print("没这个键 :", product.get("color"))        # None（不报错！）
print("带默认值 :", product.get("color", "无"))  # 无
print("in 判断  :", "name" in product, "| 'color' 在吗:", "color" in product)

# ❌ 用 [] 取不存在的键会报错
try:
    product["color"]
except KeyError as e:
    print("KeyError:", e)
```

**预期输出：**

```
整个字典 : {'code': 'ST-BD-42', 'name': '包布静音球', 'price': 8.65, 'stock': 1200}
取值     : 包布静音球
长度     : 4
有这个键 : 8.65
没这个键 : None
带默认值 : 无
in 判断  : True | 'color' 在吗: False
KeyError: 'color'
```

> 🔴 **铁律**：**不确定的键一律用 `get()`**。客户数据里永远可能有你没预料到的字段。

### 4.2 增删改

```python
product = {"code": "ST-BD-42", "name": "包布静音球", "price": 8.65, "stock": 1200}

product["weight"] = 42                    # 新增/修改（键在就改，不在就加）
print("新增后  :", product)

product.setdefault("unit", "只")           # 键不存在才设置（存在则不动）
print("setdefault:", product["unit"])

product.update({"price": 9.10, "color": "蓝"})   # 批量更新
print("update  :", product)

removed = product.pop("stock")            # 弹出并返回值
print("pop     :", removed, "| 剩下:", list(product.keys()))

last = product.popitem()                  # 弹出最后一对（3.7+ 是最后插入的）
print("popitem :", last)

del product["unit"]                       # 直接删（键不存在会报错）
print("del 后  :", product)
```

**预期输出：**

```
新增后  : {'code': 'ST-BD-42', 'name': '包布静音球', 'price': 8.65, 'stock': 1200, 'weight': 42}
setdefault: 只
update  : {'code': 'ST-BD-42', 'name': '包布静音球', 'price': 9.1, 'stock': 1200, 'weight': 42, 'unit': '只', 'color': '蓝'}
pop     : 1200 | 剩下: ['code', 'name', 'price', 'weight', 'unit', 'color']
popitem : ('color', '蓝')
del 后  : {'code': 'ST-BD-42', 'name': '包布静音球', 'price': 9.1, 'weight': 42}
```

> 注意执行顺序：`popitem()` 已经把最后插入的 `('color', '蓝')` 弹走了，所以后面 `del` 的是 `unit` 而不是 `color`——再删 `color` 会 `KeyError`。字典操作是**有状态的**，看示例时按顺序走一遍。

> `setdefault` 的经典用途：**给字典里的列表追加元素**（分组时常用）
> ```python
> groups = {}
> groups.setdefault("数码", []).append("ST-BD-42")   # 键不存在就先建个空列表
> ```

### 4.3 遍历

```python
product = {"code": "ST-BD-42", "name": "包布静音球", "price": 8.65}

print("keys  :", list(product.keys()))
print("values:", list(product.values()))
print("items :", list(product.items()))

print("\n遍历键值对（最常用）:")
for key, value in product.items():
    print(f"  {key:8s} = {value}")

print("\n只遍历键（for k in d 等价 for k in d.keys()）:")
for key in product:
    print(f"  {key}")
```

**预期输出：**

```
keys  : ['code', 'name', 'price']
values: ['ST-BD-42', '包布静音球', 8.65]
items : [('code', 'ST-BD-42'), ('name', '包布静音球'), ('price', 8.65)]

遍历键值对（最常用）:
  code     = ST-BD-42
  name     = 包布静音球
  price    = 8.65

只遍历键（for k in d 等价 for k in d.keys()）:
  code
  name
  price
```

> ⚠️ **遍历时不能改字典大小**（会 RuntimeError）。要删元素先 `list(d.keys())` 快照一份：
> ```python
> for k in list(d.keys()):
>     if d[k] is None:
>         del d[k]
> ```

### 4.4 字典推导式与排序

```python
margin = {"数码": 1.16, "食品": 21.75, "家居": 27.22, "服饰": 38.00, "美妆": 49.47}

# 推导式：对每个键值做变换
print("全部+1   :", {k: round(v + 1, 2) for k, v in margin.items()})
print("筛选>25  :", {k: v for k, v in margin.items() if v > 25})
print("键值互换 :", {v: k for k, v in margin.items()})

# 按值排序（返回元组列表）
print("\n按值降序 :", sorted(margin.items(), key=lambda kv: kv[1], reverse=True))
print("按值升序 :", sorted(margin.items(), key=lambda kv: kv[1]))
print("最大值键 :", max(margin, key=margin.get))
print("前3名    :", sorted(margin.items(), key=lambda kv: -kv[1])[:3])

# 排序后仍要字典（Python 3.7+ 字典保序）
top = dict(sorted(margin.items(), key=lambda kv: -kv[1])[:3])
print("TOP3 字典:", top)
```

**预期输出：**

```
全部+1   : {'数码': 2.16, '食品': 22.75, '家居': 28.22, '服饰': 39.0, '美妆': 50.47}
筛选>25  : {'家居': 27.22, '服饰': 38.0, '美妆': 49.47}
键值互换 : {1.16: '数码', 21.75: '食品', 27.22: '家居', 38.0: '服饰', 49.47: '美妆'}

按值降序 : [('美妆', 49.47), ('服饰', 38.0), ('家居', 27.22), ('食品', 21.75), ('数码', 1.16)]
按值升序 : [('数码', 1.16), ('食品', 21.75), ('家居', 27.22), ('服饰', 38.0), ('美妆', 49.47)]
最大值键 : 美妆
前3名    : [('美妆', 49.47), ('服饰', 38.0), ('家居', 27.22)]
TOP3 字典: {'美妆': 49.47, '服饰': 38.0, '家居': 27.22}
```

### 4.5 合并字典

```python
base = {"code": "ST-BD-42", "price": 8.65}
extra = {"stock": 1200, "price": 9.10}      # 同键会被覆盖

print("① ** 解包  :", {**base, **extra})     # 后面的覆盖前面的
print("② | 运算   :", base | extra)           # Python 3.9+
print("③ update   :", end=" ")
m = base.copy(); m.update(extra); print(m)
print("④ 原字典未变:", base)
```

**预期输出：**

```
① ** 解包  : {'code': 'ST-BD-42', 'price': 9.1, 'stock': 1200}
② | 运算   : {'code': 'ST-BD-42', 'price': 9.1, 'stock': 1200}
③ update   : {'code': 'ST-BD-42', 'price': 9.1, 'stock': 1200}
④ 原字典未变: {'code': 'ST-BD-42', 'price': 8.65}
```

### 4.6 ⭐ `Counter`：一行完成计数

```python
from collections import Counter

votes = ["数码", "食品", "数码", "美妆", "数码", "食品"]
cnt = Counter(votes)

print("计数结果  :", cnt)
print("最多的2个 :", cnt.most_common(2))
print("某个值    :", cnt["数码"], "| 不存在的:", cnt["不存在的品类"])   # 不存在返回 0，不报错
print("全部键    :", list(cnt.keys()))
print("转成字典  :", dict(cnt))

# Counter 的运算
a = Counter(["a", "b", "a"])
b = Counter(["a", "c"])
print("相加      :", a + b)
print("相减      :", a - b)
print("取最大交集:", a & b)
print("取并集    :", a | b)
```

**预期输出：**

```
计数结果  : Counter({'数码': 3, '食品': 2, '美妆': 1})
最多的2个 : [('数码', 3), ('食品', 2)]
某个值    : 3 | 不存在的: 0
全部键    : ['数码', '食品', '美妆']
转成字典  : {'数码': 3, '食品': 2, '美妆': 1}
相加      : Counter({'a': 3, 'b': 1, 'c': 1})
相减      : Counter({'a': 1, 'b': 1})
取最大交集: Counter({'a': 1})
取并集    : Counter({'a': 2, 'b': 1, 'c': 1})
```

> **`Counter` 是数据分析的分水岭**：
> - 统计「每个品类多少个」「每个省份多少单」「每个状态多少条」→ 一行 `Counter(列表)`
> - 普通字典`get` 不存在的键要处理 `None`，**`Counter` 直接返回 0**，不会崩

### 4.7 ⭐ `defaultdict`：分组神器

```python
from collections import defaultdict

# 普通字典分组：要先判断键存不存在
groups = {}
for cat, amt in [("数码", 100), ("食品", 200), ("数码", 150)]:
    if cat not in groups:
        groups[cat] = []
    groups[cat].append(amt)
print("普通字典:", groups)

# defaultdict：不存在的键自动生成默认值
groups2 = defaultdict(list)          # 默认空列表
for cat, amt in [("数码", 100), ("食品", 200), ("数码", 150)]:
    groups2[cat].append(amt)
print("defaultdict:", dict(groups2))

# 默认值是 0 → 直接累加
totals = defaultdict(int)
for cat, amt in [("数码", 100), ("食品", 200), ("数码", 150)]:
    totals[cat] += amt
print("累加:", dict(totals))

# 不存在的键自动创建（不会 KeyError）
print("访问不存在的键:", groups2["美妆"])
```

**预期输出：**

```
普通字典: {'数码': [100, 150], '食品': [200]}
defaultdict: {'数码': [100, 150], '食品': [200]}
累加: {'数码': 250, '食品': 200}
访问不存在的键: []
```

> ⚠️ 注意：`defaultdict` 访问不存在的键会**自动创建**这个键。如果你只是想「查一下」，别用 `defaultdict`（会污染数据），用 `dict.get()`。

### 4.8 嵌套字典

```python
# 二维结构：品类 → 月份 → 金额
sales = {
    "数码": {"1月": 100, "2月": 150, "3月": 120},
    "食品": {"1月": 200, "2月": 180, "3月": 220},

print("取一层:", sales["数码"])

print("安全取(整个品类不存在):", sales.get("玩具", {}).get("1月", 0))

```

## 五、实操：集合

### 5.1 集合 = 去重 + 数学运算

```python
# 去重
nums = [1, 2, 3, 3, 2, 1]
print("列表  :", nums)
print("去重  :", set(nums))
print("去重后个数:", len(set(nums)))

# 保序去重（保持原来的顺序）
print("保序去重:", list(dict.fromkeys(nums)))

A = {"数码", "食品", "家居"}
B = {"食品", "美妆"}
print("\nA     :", A)
print("B     :", B)
print("并集 | :", A | B)
print("交集 & :", A & B)
print("差集 - :", A - B)          # 在 A 里但不在 B 里
print("对称差^:", A ^ B)          # 只在其中一个里
print("子集   :", {"数码"} <= A, "| 超集:", A >= {"数码"})
```

**预期输出（集合部分的顺序可能与你看到的不同）：**

```
列表  : [1, 2, 3, 3, 2, 1]
去重  : {1, 2, 3}
去重后个数: 3
保序去重: [1, 2, 3]

A     : {'食品', '家居', '数码'}
B     : {'食品', '美妆'}
并集 | : {'食品', '美妆', '家居', '数码'}
交集 & : {'食品'}
差集 - : {'家居', '数码'}
对称差^: {'数码', '家居', '美妆'}
子集   : True | 超集: True
```

> ⚠️ **集合是无序的**。上面 `A` 打印出 `{'食品', '家居', '数码'}`，但**你跑出来可能是别的顺序，甚至每次运行都不一样**——这是正常的，集合内部用哈希表存储，不保证顺序。
>
> 两条铁律：
> 1. **永远不要依赖集合的打印顺序**
> 2. 要确定的顺序就 `sorted(集合)`，要保序去重就用 `list(dict.fromkeys(列表))`

### 5.2 集合的增删与推导式

```python
s = {"数码", "食品"}
s.add("美妆")                  # 加一个
s.add("数码")                  # 已存在，无效果（不会重复）
print("add 后:", s)

s.remove("食品")               # 删（不存在会报错）
s.discard("不存在的")           # 删（不存在也不报错，更安全）
print("删后  :", s)

print("in 判断:", "数码" in s)   # 集合的 in 极快，比列表快得多

# 集合推导式
evens = {x for x in range(10) if x % 2 == 0}
print("集合推导:", evens)
print("字符串去重:", set("静音球静音球"))
```

**预期输出：**

```
add 后: {'美妆', '食品', '数码'}
删后  : {'美妆', '数码'}
in 判断: True
集合推导: {0, 2, 4, 6, 8}
字符串去重: {'音', '球', '静'}
```

> `字符串去重` 那行：字符串是可迭代的，`set("静音球静音球")` 会把每个**字**拆开去重，得到 3 个字。
> 想按「词」去重，得先 `split()`：`set("数码 食品 数码".split())`。

### 5.3 可哈希：什么能当键

```python
# ✅ 可以当键（不可变）
print({("数码", "2026"): 100})         # 元组
print({"ST-BD-42": 8.65})              # 字符串
print({1: "一", 2: "二"})               # 数字

# ❌ 不能当键（可变）
for bad in [[1, 2], {"a": 1}, {1, 2}]:
    try:
        {bad: "值"}
    except TypeError as e:
        print(f"{type(bad).__name__:5s} 不能当键 -> {e}")

# frozenset：不可变集合，可以当键
fs = frozenset([1, 2])
print("frozenset:", fs, "| 可以当键:", {fs: "值"})
```

**预期输出：**

```
{('数码', '2026'): 100}
{'ST-BD-42': 8.65}
{1: '一', 2: '二'}
list  不能当键 -> unhashable type: 'list'
dict  不能当键 -> unhashable type: 'dict'
set   不能当键 -> unhashable type: 'set'
frozenset: frozenset({1, 2}) | 可以当键: {frozenset({1, 2}): '值'}
```

> **判断口诀**：能用 `hash(x)` 不报错的，就能当键。
> 列表/字典/集合可变 → 内容变了哈希就变了 → 不允许当键。

## 六、验证：用字典做一份分组报表

```python
from collections import Counter, defaultdict

orders = [
    {"id": "O001", "cat": "数码", "province": "广东", "amount": 1200, "status": "已完成"},
    {"id": "O002", "cat": "食品", "province": "浙江", "amount": 340,  "status": "已完成"},
    {"id": "O003", "cat": "数码", "province": "广东", "amount": 2500, "status": "已取消"},
    {"id": "O004", "cat": "美妆", "province": "上海", "amount": 800,  "status": "已完成"},
    {"id": "O005", "cat": "数码", "province": "上海", "amount": 1500, "status": "已完成"},
    {"id": "O006", "cat": "食品", "province": "广东", "amount": 620,  "status": "退款"},
]

valid = [o for o in orders if o["status"] == "已完成"]
print(f"总订单 {len(orders)} 单，有效 {len(valid)} 单")

# ① 状态计数（Counter 一行）
print("\n① 状态分布:")
for status, n in Counter(o["status"] for o in orders).most_common():
    print(f"   {status}: {n} 单")

# ② 按品类汇总金额（defaultdict）
by_cat = defaultdict(float)
by_cat_n = Counter()
for o in valid:
    by_cat[o["cat"]] += o["amount"]
    by_cat_n[o["cat"]] += 1
print("\n② 品类汇总（有效订单）:")
for cat, amt in sorted(by_cat.items(), key=lambda kv: -kv[1]):
    print(f"   {cat}: {by_cat_n[cat]} 单，{amt:,.2f} 元，均 {amt / by_cat_n[cat]:,.2f}")

# ③ 按省份汇总 + 嵌套字典
by_prov = defaultdict(lambda: defaultdict(float))
for o in valid:
    by_prov[o["province"]][o["cat"]] += o["amount"]
print("\n③ 省份 × 品类交叉表:")
for prov, cats in by_prov.items():
    detail = "，".join(f"{k} {v:,.0f}" for k, v in sorted(cats.items()))
    print(f"   {prov}: {detail} | 小计 {sum(cats.values()):,.0f}")

# ④ 所有出现过的省份（集合去重）
provinces = sorted(set(o["province"] for o in orders))
print(f"\n④ 涉及省份（去重排序）: {provinces}")
print(f"   有效订单覆盖: {sorted(set(o['province'] for o in valid))}")
print(f"   有单但全部无效的省份: {sorted(set(provinces) - set(o['province'] for o in valid))}")
```

**预期输出：**

```
总订单 6 单，有效 4 单

① 状态分布:
   已完成: 4 单
   已取消: 1 单
   退款: 1 单

② 品类汇总（有效订单）:
   数码: 2 单，2,700.00 元，均 1,350.00
   美妆: 1 单，800.00 元，均 800.00
   食品: 1 单，340.00 元，均 340.00

③ 省份 × 品类交叉表:
   广东: 数码 1,200 | 小计 1,200
   浙江: 食品 340 | 小计 340
   上海: 数码 1,500，美妆 800 | 小计 2,300

④ 涉及省份（去重排序）: ['上海', '广东', '浙江']
   有效订单覆盖: ['上海', '广东', '浙江']
   有单但全部无效的省份: []
```

> 注意 ② 里食品只有 **340 元**：O006 那笔 620 元是**退款**单，被 `status == "已完成"` 过滤掉了。
> 这正是 SQL 教程里强调的「有效销售必须过滤 `status='已完成'`」——**口径不统一，数字就永远对不上**。
> 品类汇总 ② 的合计（2,700 + 800 + 340 = 3,840）与 ③ 省份小计之和（1,200 + 340 + 2,300 = 3,840）必须相等，这是一个很好的自检方法。

这四段代码就是**「手工版 groupby」**。ch12 学 pandas 之后，同样的结果只要：
> ```python
> df[df.status == "已完成"].groupby("cat")["amount"].agg(["count", "sum", "mean"])
> ```
> 但**理解底层怎么做到的，比会调用更重要**——pandas 卡壳时，你还能退回字典手写。

## 七、FDE 现场场景：两份料号表对不上

客户给的料号表和 ERP 导出的对不上，你要找出差异：

```python
erp_codes = {"ST-BD-42", "ST-BD-60", "YG-01", "BL-05", "PQ-88"}
customer_codes = {"ST-BD-42", "YG-01", "BL-05", "XX-99"}

print("两边都有（可直接匹配）:", sorted(erp_codes & customer_codes))
print("ERP 有、客户没有（多余）:", sorted(erp_codes - customer_codes))
print("客户有、ERP 没有（待建）:", sorted(customer_codes - erp_codes))
print("只在其中一边（全部差异）:", sorted(erp_codes ^ customer_codes))
print(f"匹配率: {len(erp_codes & customer_codes) / len(customer_codes):.1%}")
```

**预期输出：**

```
两边都有（可直接匹配）: ['BL-05', 'ST-BD-42', 'YG-01']
ERP 有、客户没有（多余）: ['PQ-88', 'ST-BD-60']
客户有、ERP 没有（待建）: ['XX-99']
只在其中一边（全部差异）: ['PQ-88', 'ST-BD-60', 'XX-99']
匹配率: 75.0%
```

一行集合运算搞定「对账」，用列表要写嵌套循环还容易漏。**凡是「两份名单比对」的需求，第一反应就应该是集合。**

## 八、本章小结

| 你学到了 | 关键点 |
|---|---|
| 字典 | 键值对，查找 O(1)，3.7+ 保持插入顺序 |
| **安全取值** | 不确定就用 `d.get(k, 默认值)`，别用 `d[k]` |
| 增删改 | `d[k]=v` / `setdefault` / `update` / `pop` / `popitem` / `del` |
| 遍历 | `d.items()` 拿键值对；**遍历时别改大小** |
| 排序 | `sorted(d.items(), key=lambda kv: kv[1], reverse=True)` |
| 合并 | `{**a, **b}` 或 `a \| b`（3.9+）；`a.update(b)` 是原地改 |
| ⭐ `Counter` | 一行计数；不存在的键返回 **0** 不是报错；`most_common(n)` |
| ⭐ `defaultdict` | 分组神器；`defaultdict(list)` / `defaultdict(int)` |
| 嵌套字典 | 安全访问 `d.get(k1, {}).get(k2, 0)` |
| 集合 | 去重 `set()`；保序去重 `dict.fromkeys()`；交 `&` 并 `\|` 差 `-` 对称差 `^` |
| 可哈希 | `str`/`int`/`tuple` 能当键；`list`/`dict`/`set` 不能；`frozenset` 可以 |
| 对账场景 | 两份名单比对 = 集合运算 |

## 九、练习题

### 练习 1：`get()` 安全取值（考：避免 KeyError）

**题目**：下面代码第 3 行会崩，改成不崩且能给出默认值。

```python
product = {"code": "ST-BD-42", "price": 8.65}
print(product["stock"])
```

**答案：**

```python
product = {"code": "ST-BD-42", "price": 8.65}

print("stock:", product.get("stock"))           # None
print("stock:", product.get("stock", 0))        # 0
print("stock:", product.get("stock", "未录入"))  # 未录入

# 或者先判断
if "stock" in product:
    print("库存:", product["stock"])
else:
    print("⚠️ 该字段不存在，按 0 处理")
```

**预期输出：**

```
stock: None
stock: 0
stock: 未录入
⚠️ 该字段不存在，按 0 处理
```

**解析**：处理外部数据时，字段缺失是常态。用 `get()` + 默认值，让程序「缺数据也能跑完」而不是中途崩溃。

### 练习 2：词频统计（考：Counter）

**题目**：统计字符串 `"数码 食品 数码 美妆 数码 食品 数码"` 中各品类出现次数，输出前三名和占比。

**答案：**

```python
from collections import Counter

text = "数码 食品 数码 美妆 数码 食品 数码"
words = text.split()
cnt = Counter(words)
total = sum(cnt.values())

print("计数:", dict(cnt))
print("前三:", cnt.most_common(3))
print(f"\n总共 {total} 次")
for word, n in cnt.most_common():
    print(f"  {word}: {n} 次，占比 {n / total:.1%}")
```

**预期输出：**

```
计数: {'数码': 4, '食品': 2, '美妆': 1}
前三: [('数码', 4), ('食品', 2), ('美妆', 1)]

总共 7 次
  数码: 4 次，占比 57.1%
  食品: 2 次，占比 28.6%
  美妆: 1 次，占比 14.3%
```

**解析**：`Counter` 的 `most_common()` 自动按次数降序排好。`sum(cnt.values())` 拿总数算占比。

### 练习 3：按品类分组（考：defaultdict）

**题目**：把订单按品类分组，每组列出金额，并算出每组的合计与平均。

**答案：**

```python
from collections import defaultdict

orders = [("数码", 1200), ("食品", 340), ("数码", 2500), ("美妆", 800), ("数码", 1500)]

groups = defaultdict(list)
for cat, amt in orders:
    groups[cat].append(amt)

print("分组结果:")
for cat, amounts in groups.items():
    print(f"  {cat}: {amounts}")

print("\n汇总:")
for cat, amounts in sorted(groups.items()):
    print(f"  {cat}: {len(amounts)} 单，合计 {sum(amounts):,} 元，平均 {sum(amounts) / len(amounts):,.2f} 元")
```

**预期输出：**

```
分组结果:
  数码: [1200, 2500, 1500]
  食品: [340]
  美妆: [800]

汇总:
  数码: 3 单，合计 5,200 元，平均 1,733.33 元
  美妆: 1 单，合计 800 元，平均 800.00 元
  食品: 1 单，合计 340 元，平均 340.00 元
```

**解析**：`defaultdict(list)` 让你直接 `append`，不用先判断键存不存在。这是「分组」操作的标准写法。
汇总部分用 `sorted(groups.items())` 按品类名排序（中文按 Unicode 码点：数 6570 < 美 7F8E < 食 98DF）。要按金额排就换成 `sorted(groups.items(), key=lambda kv: -sum(kv[1]))`。

### 练习 4：字典按值排序取 TOP（考：sorted + lambda）

**题目**：已知各品类毛利率，找出毛利率最高和最低的品类，以及高于 25% 的品类。

**答案：**

```python
margin = {"数码": 1.16, "食品": 21.75, "家居": 27.22, "服饰": 38.00, "美妆": 49.47}

ranked = sorted(margin.items(), key=lambda kv: kv[1], reverse=True)
print("降序排名:", ranked)
print(f"最高: {ranked[0][0]} {ranked[0][1]}%")
print(f"最低: {ranked[-1][0]} {ranked[-1][1]}%")

above = {k: v for k, v in margin.items() if v > 25}
print("高于25%的品类:", above)
print(f"占全部品类的 {len(above)}/{len(margin)}")
```

**预期输出：**

```
降序排名: [('美妆', 49.47), ('服饰', 38.0), ('家居', 27.22), ('食品', 21.75), ('数码', 1.16)]
最高: 美妆 49.47%
最低: 数码 1.16%
高于25%的品类: {'家居': 27.22, '服饰': 38.0, '美妆': 49.47}
占全部品类的 3/5
```

**解析**：`sorted(d.items(), key=lambda kv: kv[1])` 是字典排序的固定套路——`items()` 变成 `(键, 值)` 元组列表，`key` 指定按元组第 1 项（值）排。

### 练习 5：名单比对（考：集合运算）

**题目**：本月在职员工名单和上个月名单，找出新入职的、离职的、一直在职的。

**答案：**

```python
last_month = {"张伟", "李娜", "王芳", "刘洋", "陈静"}
this_month = {"李娜", "王芳", "陈静", "赵敏", "孙强"}

joined = this_month - last_month          # 本月有、上月无
left = last_month - this_month            # 上月有、本月无
stayed = this_month & last_month          # 两边都有
all_people = this_month | last_month      # 出现过所有人

print("新入职:", sorted(joined))
print("已离职:", sorted(left))
print("一直在职:", sorted(stayed))
print(f"\n上月 {len(last_month)} 人，本月 {len(this_month)} 人")
print(f"留存率: {len(stayed) / len(last_month):.1%}")
print(f"净增 {len(this_month) - len(last_month)} 人")
```

**��期输出：**

```
新入职: ['孙强', '赵敏']
已离职: ['刘洋', '张伟']
一直在职: ['李娜', '王芳', '陈静']

上月 5 人，本月 5 人
留存率: 60.0%
净增 0 人
```

**解析**：集合的差集 `-` 有方向性 —— `A - B` 是「在 A 但不在 B」，顺序反了结果就反了。
同一个需求用列表写要两层循环，用集合三行搞定，而且**不会有重复元素干扰**。
