## 三、概念：缩进就是语法

Python 用**缩进**（4 个空格）表示代码块，不用 `{}`：

```python
if x > 10:
    print("大于10")       # ← 缩进 4 空格，属于 if 块
    print("还是 if 块")
print("不属于 if 块")      # ← 回到顶层
```

> 🔴 **缩进不一致会报 `IndentationError`**。
> 规则：同一层级必须完全对齐；**只用空格，别混 Tab**（PyCharm 默认把 Tab 转成 4 空格，很省心）。

## 四、实操：条件判断

### 4.1 if / elif / else

```python
score = 23.72

if score >= 30:
    grade = "优秀"
elif score >= 20:
    grade = "合格"
else:
    grade = "偏低"

print(f"毛利率 {score}% -> {grade}")
```

**预期输出：**

```
毛利率 23.72% -> 合格
```

**要点：**

- `elif` 可以有很多个，`else` 最多一个且可选
- **从上往下判断，命中第一个就停**（所以条件顺序要合理：严格的条件写前面）
- 判断的是**真假值**（ch02 讲过：`0` / `""` / `None` / 空容器都是假）

### 4.2 三元表达式（一行 if-else）

```python
score = 23.72
result = "达标" if score >= 20 else "未达标"
print(result)                    # 达标

# 嵌套三元（可读性差，慎用）
level = "高" if score >= 30 else ("中" if score >= 20 else "低")
print(level)                     # 中

# 实战：给缺失值兜底
qty = None
show = qty if qty else 0
print("数量:", show)              # 0
```

**预期输出：**

```
达标
中
数量: 0
```

> 三元表达式适合**简单的二选一**。逻辑超过一层就老老实实写 `if/elif`，可读性优先。

### 4.3 链式比较与多条件

```python
margin = 23.72
qty = 1200

# and / or / not
if margin > 20 and qty > 1000:
    print("高毛利 + 大批量：重点客户")

# 链式比较（Python 特色，比 and 更简洁）
if 20 <= margin < 30:
    print("毛利率处于合理区间 20%~30%")

# 成员判断 + 逻辑组合
status = "已完成"
if status in ("已完成", "待发货"):
    print("计入有效订单")

if status not in ("已取消", "退款"):
    print("非异常订单")
```

**预期输出：**

```
高毛利 + 大批量：重点客户
毛利率处于合理区间 20%~30%
计入有效订单
非异常订单
```

## 五、实操：循环

### 5.1 `for` 遍历各种对象

```python
# 遍历列表
for code in ["ST-BD-42", "YG-01", "BL-05"]:
    print(f"  料号: {code}")

# 遍历字符串（逐字符）
print("逐字符:", [c for c in "静音球"])

# 遍历 range
print("range(3):", list(range(3)))
print("range(1,10,3):", list(range(1, 10, 3)))
print("range(5,0,-1):", list(range(5, 0, -1)))

# 遍历字典
product = {"code": "ST-BD-42", "price": 8.65}
for k, v in product.items():
    print(f"  {k} = {v}")

# enumerate：带索引遍历（最常用）
for i, code in enumerate(["ST-BD-42", "YG-01"], start=1):
    print(f"  {i}. {code}")

# zip：同时遍历多个列表
for code, qty in zip(["ST-BD-42", "YG-01"], [1200, 250]):
    print(f"  {code}: {qty} 只")
```

**预期输出：**

```
  料号: ST-BD-42
  料号: YG-01
  料号: BL-05
逐字符: ['静', '音', '球']
range(3): [0, 1, 2]
range(1,10,3): [1, 4, 7]
range(5,0,-1): [5, 4, 3, 2, 1]
  code = ST-BD-42
  price = 8.65
  1. ST-BD-42
  2. YG-01
  ST-BD-42: 1200 只
  YG-01: 250 只
```

> `range(start, end, step)` —— **含 start，不含 end**。

### 5.2 `while` 循环

```python
# 计数循环
n = 0
while n < 3:
    n += 1
print("while 计数:", n)              # 3

# 条件循环（不知道要跑多少次时用）
stock = 1200
shipped = 0
box_size = 500
while stock > 0:
    take = min(stock, box_size)
    stock -= take
    shipped += 1
    print(f"  第 {shipped} 箱装 {take} 只，剩余 {stock}")
print(f"共 {shipped} 箱")
```

**预期输出：**

```
while 计数: 3
  第 1 箱装 500 只，剩余 700
  第 2 箱装 500 只，剩余 200
  第 3 箱装 200 只，剩余 0
共 3 箱
```

> **`for` vs `while`**：
> - 知道要遍历什么（列表/字典/固定次数）→ 用 `for`
> - 不知道循环几次，靠条件退出 → 用 `while`
> - `while True:` + `break` 是「一直跑到满足条件」的常见写法

### 5.3 `break` / `continue` / `pass`

```python
# break：满足条件立刻跳出整个循环
orders = [("O001", 1200), ("O002", 800), ("O003", 3400)]
for oid, amt in orders:
    if amt > 3000:
        print(f"  发现大额订单 {oid} {amt}，停止检查")
        break
    print(f"  检查 {oid}: {amt}")

# continue：跳过本次，继续下一轮
print("\n有效订单（跳过已取消）:")
for oid, amt, status in [("O001", 1200, "已完成"), ("O002", 800, "已取消"), ("O003", 3400, "已完成")]:
    if status != "已完成":
        continue
    print(f"  {oid}: {amt}")

# pass：占位符，什么都不做（避免语法错误）
for x in range(3):
    pass        # 待实现
```

**预期输出：**

```
  检查 O001: 1200
  检查 O002: 800
  发现大额订单 O003 3400，停止检查

有效订单（跳过已取消）:
  O001: 1200
  O003: 3400
```

### 5.4 `for-else`（很多人不知道）

`else` 跟在 `for`/`while` 后面：**循环正常跑完（没被 break）才执行**。

```python
# 场景：找异常值，找到就报警，没找到就报平安
amounts = [1200, 800, 1500]

for amt in amounts:
    if amt > 10000:
        print("发现异常大额订单！")
        break
else:
    print("全部订单金额正常")

# 被 break 时 else 不执行
for i in range(5):
    if i == 3:
        print("  遇到 3，break")
        break
else:
    print("  这行不会执行")
```

**预期输出：**

```
全部订单金额正常
  遇到 3，break
```

> 这个语法可以替代「设个 flag 变量标记有没有找到」的写法，代码更干净。

### 5.5 嵌套循环与提前退出

```python
# 在 3×3 网格里找 r*c == 4
found = False
for r in range(3):
    for c in range(3):
        if r * c == 4:
            found = True
            print(f"  找到 r={r} c={c}")
            break          # 只跳出内层
    if found:
        break              # 跳出外层

# 更优雅：用 for-else 或直接写成推导式
result = [(r, c) for r in range(3) for c in range(3) if r * c == 4]
print("推导式找:", result)
```

**预期输出：**

```
  找到 r=2 c=2
推导式找: [(2, 2)]
```

## 六、实操：推导式 ⭐

推导式（comprehension）= **把「建空列表 + for 循环 + if 判断 + append」压缩成一行**。

### 6.1 列表推导式

```python
# 传统写法
result = []
for x in range(5):
    result.append(x * 2)

# 推导式（等价，一行）
result = [x * 2 for x in range(5)]
print("基本形式  :", result)                       # [0, 2, 4, 6, 8]

# 带条件（只保留满足的）
print("带 if     :", [x for x in range(10) if x % 2 == 0])

# if-else（每个元素都处理，走不同分支）
print("带 if-else:", ["偶" if x % 2 == 0 else "奇" for x in range(5)])

# 对字符串批量处理
words = ["  静音球 ", "泳镜 ", " 篮球"]
print("批量清洗  :", [w.strip() for w in words])

# 对字典列表取字段
rows = [{"code": "ST-BD-42", "price": 8.65}, {"code": "YG-01", "price": 45.0}]
print("取字段    :", [r["code"] for r in rows])
print("计算字段  :", [round(r["price"] * 1.13, 2) for r in rows])
```

**预期输出：**

```
基本形式  : [0, 2, 4, 6, 8]
带 if     : [0, 2, 4, 6, 8]
带 if-else: ['偶', '奇', '偶', '奇', '偶']
批量清洗  : ['静音球', '泳镜', '篮球']
取字段    : ['ST-BD-42', 'YG-01']
计算字段  : [9.77, 50.85]
```

### 6.2 `if` 放前面还是后面？

```python
# ① if 在 for 后面 = 筛选（不满足的不要）
print("筛选  :", [x for x in range(10) if x % 2 == 0])

# ② if-else 在 for 前面 = 变换（每个都要，走不同分支）
print("变换  :", [x if x % 2 == 0 else -x for x in range(5)])
```

**预期输出：**

```
筛选  : [0, 2, 4, 6, 8]
变换  : [0, -1, 2, -3, 4]
```

> 记忆法：**`if` 在后面是「筛子」，在前面是「变形器」。**

### 6.3 嵌套推导式

```python
# 双重循环（相当于两层 for）
pairs = [(x, y) for x in range(2) for y in "ab"]
print("双重循环:", pairs)                    # [(0,'a'), (0,'b'), (1,'a'), (1,'b')]

# 带条件的双重循环
print("带条件  :", [(x, y) for x in range(3) for y in range(3) if x != y][:4])

# 二维：生成矩阵
matrix = [[x * y for y in range(3)] for x in range(3)]
print("矩阵    :", matrix)

# 扁平化：把二维压成一维
flat = [y for row in [[1, 2], [3, 4]] for y in row]
print("扁平化  :", flat)

# 转置
print("转置    :", [[row[i] for row in matrix] for i in range(3)])
```

**预期输出：**

```
双重循环: [(0, 'a'), (0, 'b'), (1, 'a'), (1, 'b')]
带条件  : [(0, 1), (0, 2), (1, 0), (1, 2)]
矩阵    : [[0, 0, 0], [0, 1, 2], [0, 2, 4]]
扁平化  : [1, 2, 3, 4]
转置    : [[0, 0, 0], [0, 1, 2], [0, 2, 4]]
```

### 6.4 字典推导式 & 集合推导式

```python
# 字典推导式
squares = {x: x ** 2 for x in range(4)}
print("字典推导:", squares)                     # {0: 0, 1: 1, 2: 4, 3: 9}

# 从两个列表造字典
print("zip 建字典:", {k: v for k, v in zip(["a", "b"], [1, 2])})

# 键值变换 + 筛选
margin = {"数码": 1.16, "食品": 21.75, "美妆": 49.47}
print("值翻倍  :", {k: round(v * 2, 2) for k, v in margin.items()})
print("筛 >20  :", {k: v for k, v in margin.items() if v > 20})

# 集合推导式（自动去重）
print("集合推导:", {x % 3 for x in range(10)})     # {0, 1, 2}
print("料号后缀:", {c.split("-")[-1] for c in ["ST-BD-42", "YG-01", "ST-BD-42"]})
```

**预期输出：**

```
字典推导: {0: 0, 1: 1, 2: 4, 3: 9}
zip 建字典: {'a': 1, 'b': 2}
值翻倍  : {'数码': 2.32, '食品': 43.5, '美妆': 98.94}
筛 >20  : {'食品': 21.75, '美妆': 49.47}
集合推导: {0, 1, 2}
料号后缀: {'42', '01'}
```

### 6.5 生成器表达式（省内存）

把 `[]` 换成 `()` 就是生成器表达式——**不立即生成所有值，要一个给一个**：

```python
# 列表推导：立刻生成 100 万个数字，占内存
big_list = [x * x for x in range(1000000)]

# 生成器表达式：几乎不占内存，边用边算
big_gen = (x * x for x in range(1000000))

import sys
print(f"列表占用  : {sys.getsizeof(big_list):,} 字节")
print(f"生成器占用: {sys.getsizeof(big_gen):,} 字节")
```

**预期输出：**

```
列表占用  : 8,448,728 字节
生成器占用: 200 字节
```

> **差了 4 万倍。** 处理大文件时用生成器能避免内存爆炸（ch11 详细讲）。
> 生成器可以直接喂给 `sum()` / `max()` / `min()` / `any()` / `all()` 这些聚合函数：
> ```python
> total = sum(x * x for x in range(1000000))     # 不用先建列表
> ```

### 6.6 性能：推导式比 append 快

```python
import timeit

loop_t = timeit.timeit("res=[]\nfor x in range(10000):\n    res.append(x*2)", number=1000)
comp_t = timeit.timeit("[x*2 for x in range(10000)]", number=1000)

print(f"append 循环: {loop_t:.4f}s")
print(f"列表推导式 : {comp_t:.4f}s")
print(f"推导式快 {loop_t / comp_t:.2f} 倍")
```

**本机预期输出（数值会有波动）：**

```
append 循环: 0.4861s
列表推导式 : 0.4040s
推导式快 1.20 倍
```

> 推导式快是因为省掉了每次循环都调用 `append` 方法的开销。
> **但别为了性能把复杂逻辑塞进一行**——三层以上的嵌套推导式，还是拆成循环更好维护。

## 七、验证：处理一批订单

```python
orders = [
    {"id": "O001", "cat": "数码", "amount": 1200, "status": "已完成"},
    {"id": "O002", "cat": "食品", "amount": 340,  "status": "已取消"},
    {"id": "O003", "cat": "数码", "amount": 3400, "status": "已完成"},
    {"id": "O004", "cat": "美妆", "amount": 800,  "status": "已完成"},
    {"id": "O005", "cat": "数码", "amount": 250,  "status": "退款"},
    {"id": "O006", "cat": "家居", "amount": 1500, "status": "已完成"},
]

# ① 筛选有效订单
valid = [o for o in orders if o["status"] == "已完成"]
print(f"有效订单: {len(valid)} / {len(orders)} 单")

# ② 计算总金额
total = sum(o["amount"] for o in valid)
print(f"有效销售额: {total:,} 元，客单价 {total / len(valid):,.2f} 元")

# ③ 按品类汇总（推导式 + set 去重）
cats = sorted(set(o["cat"] for o in valid))
print("\n品类汇总:")
for cat in cats:
    amounts = [o["amount"] for o in valid if o["cat"] == cat]
    print(f"  {cat}: {len(amounts)} 单，{sum(amounts):,} 元")

# ④ 标记异常订单（>2000 或 <500）
print("\n异常订单标记:")
for o in orders:
    if o["status"] != "已完成":
        tag = "— 已过滤"
    elif o["amount"] > 2000:
        tag = "⚠️ 金额异常高"
    elif o["amount"] < 500:
        tag = "⚠️ 金额异常低"
    else:
        tag = "正常"
    print(f"  {o['id']}  {o['cat']}  {o['amount']:>6,}  {tag}")

# ⑤ 找第一笔大额订单
first_big = next((o for o in valid if o["amount"] > 3000), None)
print(f"\n第一笔 >3000 的订单: {first_big['id'] if first_big else '无'}")
```

**预期输出：**

```
有效订单: 4 / 6 单
有效销售额: 6,900 元，客单价 1,725.00 元

品类汇总:
  家居: 1 单，1,500 元
  数码: 2 单，4,600 元
  美妆: 1 单，800 元

异常订单标记:
  O001  数码   1,200  正常
  O002  食品     340  — 已过滤
  O003  数码   3,400  ⚠️ 金额异常高
  O004  美妆     800  正常
  O005  数码     250  — 已过滤
  O006  家居   1,500  正常

第一笔 >3000 的订单: O003
```

> 第 ⑤ 行的 `next((生成器), None)` 是「找第一个满足条件的元素」的高效写法——**找到就停，不遍历全部**。等价的 `for` 循环要写 5 行。
> 注意品类汇总里**数码是 2 单 4,600 元**（O001 的 1200 + O003 的 3400），O005 的 250 元是退款被排除了。

## 八、FDE 现场场景：数据校验流水线

交付脚本前，先跑一遍数据体检，把问题一次性列出来：

```python
rows = [
    {"code": "ST-BD-42", "qty": 1200, "price": 8.65},
    {"code": "",         "qty": 400,  "price": 12.30},
    {"code": "YG-01",    "qty": None, "price": 45.00},
    {"code": "BL-05",    "qty": 80,   "price": -5.0},
    {"code": "ST-BD-60", "qty": 300,  "price": 0},
]

problems = []

for i, row in enumerate(rows, start=1):
    if not row.get("code"):
        problems.append(f"第 {i} 行：料号为空")
    if not row.get("qty"):
        problems.append(f"第 {i} 行：数量缺失或为 0")
    if row.get("price") is None or row["price"] <= 0:
        problems.append(f"第 {i} 行：单价异常（{row.get('price')}）")

if problems:
    print(f"发现 {len(problems)} 处问题：")
    for p in problems:
        print(f"  - {p}")
else:
    print("数据校验通过")

# 只保留干净的行
clean_rows = [r for r in rows
              if r.get("code") and r.get("qty") and (r.get("price") or 0) > 0]
print(f"\n有效数据 {len(clean_rows)} / {len(rows)} 行")
for r in clean_rows:
    print(f"  {r['code']:10s} {r['qty']:>5d} × {r['price']:>6.2f} = {r['qty'] * r['price']:>10,.2f}")
```

**预期输出：**

```
发现 4 处问题：
  - 第 2 行：料号为空
  - 第 3 行：数量缺失或为 0
  - 第 4 行：单价异常（-5.0）
  - 第 5 行：单价异常（0）

有效数据 1 / 5 行
  ST-BD-42       1200 ×   8.65 =  10,380.00
```

> **为什么要先校验再处理？**
> 客户拿到「输出了 3 行」的结果，不知道另外 2 行为什么没了，会来问你。
> 提前把问题列清楚发出去，是**专业交付**和「能跑就行」的区别。ch14 会把这套校验封装成可复用的函数。

## 九、本章小结

| 你学到了 | 关键点 |
|---|---|
| `if/elif/else` | 从上往下，命中即停；严格条件写前面 |
| 三元表达式 | `a if 条件 else b`，只适合简单二选一 |
| 链式比较 | `20 <= x < 30`（Python 特有，比 `and` 简洁） |
| `for` | 遍历列表/字典/`range`/`enumerate`/`zip` |
| `while` | 不知道循环次数时用；`while True` + `break` |
| `break` / `continue` | 跳出整个循环 / 跳过本轮 |
| `for-else` | **没被 break 才执行**，可替代 flag 变量 |
| **列表推导式** | `[expr for x in 列表 if 条件]`；`if` 在后=筛选、在前=变换 |
| 嵌套推导式 | 双重循环、矩阵、扁平化、转置 |
| 字典/集合推导式 | `{k: v for ...}` / `{x for ...}` |
| **生成器表达式** | `(x for x in ...)`，几乎不占内存，可直接喂给 `sum()` |
| `next(gen, None)` | 找第一个满足条件的元素，找到即停 |
| 性能 | 推导式比 append 快约 1.2 倍，且更简洁 |

### 练习 1：成绩分级（考：if/elif）

**题目**：把毛利率映射成等级：≥40% 优秀、≥25% 良好、≥15% 合格、其余偏低。用列表测试 5 个值。

**答案：**

```python
def grade(margin):
    if margin >= 40:
        return "���秀"
    elif margin >= 25:
        return "良好"
    elif margin >= 15:
        return "合格"
    else:
        return "偏低"

for m in [49.47, 38.00, 27.22, 21.75, 1.16]:
    print(f"  {m:>6.2f}% -> {grade(m)}")
```

**预期输出：**

```
   49.47% -> 优秀
   38.00% -> 良好
   27.22% -> 良好
   21.75% -> 合格
    1.16% -> 偏低
```

**解析**：`if/elif` **从大到小**排列，一旦命中就返回，不会继续判断。顺序反了（从小到大）会导致所有值都命中第一档。

### 练习 2：FizzBuzz 变体（考：循环 + 条件）

**题目**：遍历 1~15，3 的倍数打印「静音」，5 的倍数打印「球」，同时是打印「静音球」，否则打印数字本身。

**答案：**

```python
for i in range(1, 16):
    if i % 15 == 0:
        print("静音球", end=" ")
    elif i % 3 == 0:
        print("静音", end=" ")
    elif i % 5 == 0:
        print("球", end=" ")
    else:
        print(i, end=" ")
```

**预期输出：**

```
1 2 静音 4 球 静音 7 8 静音 球 11 静音 13 14 静音球
```

**解析**：**15 的倍数必须最先判断**，否则会先命中 3 的倍数打印「静音」就结束了。这是 `if/elif` 顺序的经典陷阱。

### 练习 3：推导式改写循环（考：推导式）

**题目**：把下面的循环改写成一行列表推导式。

```python
result = []
for code in ["ST-BD-42", "YG-01", "BL-05", "PQ-88"]:
    if code.startswith("ST"):
        result.append(code.lower())
```

**答案：**

```python
codes = ["ST-BD-42", "YG-01", "BL-05", "PQ-88"]
result = [c.lower() for c in codes if c.startswith("ST")]
print(result)
```

**预期输出：**

```
['st-bd-42']
```

**解析**：结构固定：**`[变换 for 变量 in 可迭代对象 if 筛选]`**。
对比原循环：`for` 部分照抄，`if` 部分照抄，中间的 `append(...)` 内容提到最前面。

### 练习 4：二维数据处理（考：嵌套推导式）

**题目**：把 `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` 中大于 4 的数全部取出，并算它们的和。

**答案：**

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# 保持二维结构
filtered = [[x for x in row if x > 4] for row in matrix]
print("保持二维:", filtered)

# 扁平化成一维
flat = [x for row in matrix for x in row if x > 4]
print("扁平化  :", flat)
print("合计    :", sum(flat))
```

**预期输出：**

```
保持二维: [[], [5, 6], [7, 8, 9]]
扁平化  : [5, 6, 7, 8, 9]
合计    : 35
```

**解析**：两种写法的**循环顺序不同**：
- 保持二维：`[[处理每行] for row in matrix]` —— `for row` 在外层
- 扁平化：`[x for row in matrix for x in row]` —— 两个 `for` 平铺，外层在前

### 练习 5：找第一个满足条件的（考：next + 生成器）

**题目**：从订单列表中找出第一笔金额超过 2000 的订单，没有就返回 `None`。要求**不要遍历完整个列表**。

**答案：**

```python
orders = [
    {"id": "O001", "amount": 1200},
    {"id": "O002", "amount": 800},
    {"id": "O003", "amount": 3400},
    {"id": "O004", "amount": 5600},
]

first_big = next((o for o in orders if o["amount"] > 2000), None)
print("第一笔大额:", first_big)

# 对比：用列表推导式会遍历全部
all_big = [o for o in orders if o["amount"] > 2000]
print("全部大额  :", all_big)

# 验证 next 只取第一个
print("最高金额  :", max(orders, key=lambda o: o["amount"]))
```

**预期输出：**

```
第一笔大额: {'id': 'O003', 'amount': 3400}
全部大额  : [{'id': 'O003', 'amount': 3400}, {'id': 'O004', 'amount': 5600}]
最高金额  : {'id': 'O004', 'amount': 5600}
```

**解析**：`next(生成器, 默认值)` 找到第一个就**立刻停止**，处理几十万行数据时能省大量时间。
注意区别：**第一笔**是 O003（3400），**最高**是 O004（5600）——业务上「第一个满足条件的」和「最优的」经常不是同一个，问需求时要问清楚。
