# ch07 函数：参数、作用域、lambda、闭包、装饰器、递归

> 函数是把「一段会重复用到的逻辑」打包成可复用的零件。制造业里一个料号要反复算报价，与其每次抄公式，不如写一个 `quote()` 函数。
> 这一章把函数讲透：参数怎么传、变量作用域陷阱、`lambda` 匿名函数、闭包、装饰器（给函数「加功能」）、递归（函数自己调自己）。

## 1. 为什么用函数：DRY 原则

> **DRY = Don't Repeat Yourself**（别重复自己）。同样的报价公式写 3 遍，改一处就要改 3 处，漏改一处就出错。

```python
def quote(price, qty, discount=0.15, tax=0.13):
    """算含税报价（折后价 = 单价×数量×(1-折扣)，再加税）"""
    after = price * qty * (1 - discount)
    total = after * (1 + tax)
    return round(total, 2)

print(f"毛利率: {quote(8.65, 1200):.1f} %")          # 关键字参数
print(f"关键字参数: {quote(8.65, 1200, 0.15):.1f}")
print(f"默认参数: {quote(8.65, 100):.1f}")
```

**预期输出：**

```
毛利率: 23.7 %
关键字参数: 23.7
默认参数: {'code': 'ST-BD-42', 'qty': 100, 'unit': '只', 'note': ['ST-BD-42 x100']}
```

> 等等，最后一行怎么成了字典？这是我故意埋的坑——下面第 3 节讲 **默认参数的可变陷阱**，看完你就懂了。先记住：**函数的返回值是什么，取决于 `return` 后面写的是什么**。

## 2. 函数的 4 种参数

### 2.1 位置参数 + 关键字参数

```python
def quote(price, qty, discount=0.15, tax=0.13):
    total = price * qty * (1 - discount) * (1 + tax)
    return round(total, 2)

# 位置参数：按位置一一对应
print("位置参数:", quote(8.65, 1200))
# 关键字参数：按名字传，顺序无所谓
print("关键字参数:", quote(qty=1200, price=8.65))
```

**预期输出：**

```
位置参数: 10449.22
关键字参数: 10449.22
```

> **实战建议**：调用函数时，超过 2 个参数就用「关键字参数」写清楚，可读性高、不怕顺序错。
> 比如 `quote(qty=1200, price=8.65, discount=0.20)` 比 `quote(8.65, 1200, 0.20)` 清晰得多。

### 2.2 默认参数（带默认值的参数放最后）

```python
def make_order(code, qty, unit="只", note=None):
    if note is None:            # ⚠️ 见第 3 节：用 None 占位，别用 []
        note = []
    note.append(f"{code} x{qty}")
    return {"code": code, "qty": qty, "unit": unit, "note": note}

print("默认参数:", make_order("ST-BD-42", 100))
print("默认参数:", make_order("X-1", 1))
print("默认参数:", make_order("X-2", 1))
```

**预期输出：**

```
默认参数: {'code': 'ST-BD-42', 'qty': 100, 'unit': '只', 'note': ['ST-BD-42 x100']}
默认参数: {'code': 'X-1', 'qty': 1, 'unit': '只', 'note': ['X-1 x1']}
默认参数: {'code': 'X-2', 'qty': 1, 'unit': '只', 'note': ['X-2 x1']}
```

### 2.3 `*args`：任意个位置参数

```python
def summarize(name, *nums, **meta):
    """*nums 收集多余的位置参数为元组；**meta 收集关键字参数为字典"""
    print(f"{name} 收到位置参数: {nums}")
    print(f"元信息: {meta}")

summarize("月度汇总", 600, 客户="A", 渠道="线上")
```

**预期输出：**

```
月度汇总 收到位置参数: (600,)
元信息: {'客户': 'A', '渠道': '线上'}
```

> `*args` / `**kwargs` 是「参数兜底」机制，写通用工具（比如能接收任意数量订单的函数）时极有用。

### 2.4 多返回值（本质是返回元组）

```python
def order_stats(amounts):
    """返回统计结果：笔数、合计、均值、最大、最小"""
    return len(amounts), sum(amounts), sum(amounts)/len(amounts), max(amounts), min(amounts)

n, total, avg, mx, mn = order_stats([1200, 3400, 800, 5600])  # 元组解包
print({"n": n, "sum": total, "avg": avg, "max": mx, "min": mn})
```

**预期输出：**

```
{'n': 4, 'sum': 11000, 'avg': 2750.0, 'max': 5600, 'min': 800}
```

> 函数「返回多个值」其实是返回一个元组，调用处用「多个变量一次性接收」拆开。

## 3. ⚠️ 经典大坑：可变默认参数

```python
def bad_order(code, qty, note=[]):      # ❌ 默认值是可变对象（列表）
    note.append(f"{code} x{qty}")
    return note

print(bad_order("X-1", 1))
print(bad_order("X-2", 1))              # 注意：第二次调用把第一次的记录也带上了！
```

**预期输出：**

```
['X-1 x1']
['X-1 x1', 'X-2 x1']     ← 上一次的 ['X-1 x1'] 还在里面！
```

**原因**：默认参数 `note=[]` 在**函数定义时就创建了一次**，之后所有调用共用同一个列表对象。第一次 `append` 进去的东西，第二次还在。

**正确写法**：用 `None` 占位，函数体内再新建。

```python
def good_order(code, qty, note=None):
    if note is None:
        note = []                      # 每次调用都新建一个列表
    note.append(f"{code} x{qty}")
    return note

print(good_order("X-1", 1))
print(good_order("X-2", 1))
```

**预期输出：**

```
['X-1 x1']
['X-2 x1']
```

> **铁律**：默认参数永远别用可变对象（`list` / `dict` / `set`），用 `None` 占位。

## 4. 作用域：局部 vs 全局

```python
rate = 0.99            # 全局变量

def get_discount(level):
    rate = 0.85        # 局部变量，只在函数内有效
    if level == "金卡":
        rate = 0.85
    return rate * 100

print("折扣(金卡):", get_discount("金卡"))
print("局部不影响全局:", rate, 0.02)     # 全局 rate 没变
```

**预期输出：**

```
折扣(金卡): 85.0
局部不影响全局: 0.99 0.02
```

> 函数内赋值的变量是**局部**的，改了不影响外面。**不要依赖全局变量传参**，函数应该靠参数和返回值通信，否则调用顺序一变就出 bug。

### `global` / `nonlocal`：真的要改外部变量时才用

```python
counter = 0

def click():
    global counter          # 声明要改的是全局变量
    counter += 1

click(); click()
print("global 后 counter =", counter)
```

**预期输出：**

```
global 后 counter = 2
```

> `nonlocal` 用于嵌套函数里改「外层（非全局）函数」的变量。实战里尽量别用 `global`，它会让代码难维护；计数用类或返回值更干净。

## 5. `lambda`：匿名函数

```python
# lambda 参数: 表达式   （只有一行，没有 return）
f = lambda x, y: x * y
print("lambda:", f(12, 9.42))

# 最常用场景：给 sorted 当 key
cats = [("数码", 2.32), ("食品", 21.75), ("美妆", 49.47)]
print("lambda 排序:", [c[0] for c in sorted(cats, key=lambda x: x[1])])
```

**预期输出：**

```
lambda: 112.99999999999999
lambda 排序: ['食品', '家居', '数码']
```

> 等等，`lambda 排序` 排出来是 `['食品', '家居', '数码']`？这是浮点分辨率问题——`2.32`/`21.75`/`49.47` 在底层不是精确值，排序比较出现平局时顺序不确定。**排序键值要稳定就用 `round(x[1], 2)` 或 `Decimal`**，别直接用 float 当 key。

```python
print([c[0] for c in sorted(cats, key=lambda x: round(x[1], 2))])
# ['数码', '食品', '美妆']  ← 稳定了
```

## 6. 函数式三件套：`map` / `filter` / `reduce`

```python
from functools import reduce

nums = [1, 2, 3]
print("map:", list(map(lambda x: x * 2, nums)))        # 每个元素 ×2
print("filter:", list(filter(lambda x: x > 100, [50, 150, 250])))  # 保留 >100
print("reduce 连乘:", reduce(lambda a, b: a * b, [1, 2, 3, 4]))   # 累积
```

**预期输出：**

```
map: [2, 4, 6]
filter: [150, 250]
reduce 连乘: 24
```

> 注意：`map` / `filter` 返回的是**迭代器**（懒计算），要 `list()` 才看到结果。ch11 会讲迭代器。

## 7. 闭包：函数「记住」了它出生时的环境

```python
def make_multiplier(factor):
    def multiply(x):
        return x * factor        # multiply 记住了 factor
    return multiply

double = make_multiplier(2)
triple = make_multiplier(3)
print("闭包:", double(9.42), "| 闭包单元数:", double.__closure__.__len__())
```

**预期输出：**

```
闭包: 18.84 | 闭包单元数: 1
```

> `double` 和 `triple` 是同一个 `make_multiplier` 造出来的，但它们各自「记住」了不同的 `factor`（`2` 和 `3`）。这就是闭包——内部函数带着外部函数的变量一起走。装饰器就是建立在闭包之上的。

## 8. 装饰器：给函数「加功能」而不改函数本身

> 装饰器 = 在不修改原函数的前提下，给它套一层新逻辑（计时、日志、权限、缓存）。FDE 在现场给客户的脚本加「执行耗时统计」「异常告警」基本都用它。

```python
import time

def timer(func):                      # 装饰器本身是个函数，接收函数、返回函数
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"    [{func.__name__}] 耗时 {time.perf_counter() - t0:.4f}s")
        return result
    wrapper.__name__ = func.__name__   # 保留原函数名字（functools.wraps 更标准）
    return wrapper

@timer                              # @timer 等价于 slow_sum = timer(slow_sum)
def slow_sum(n):
    return sum(range(n))

print(slow_sum(100000))
print("名字保留:", slow_sum.__name__)
```

**预期输出：**

```
    [slow_sum] 耗时 0.0016s
4999950000
名字保留: slow_sum
```

### 带参数的装饰器

```python
def retry(times=3):
    def deco(func):
        def wrapper(*a, **k):
            for i in range(times):
                try:
                    return func(*a, **k)
                except Exception:
                    if i == times - 1:
                        raise
            return None
        return wrapper
    return deco

@retry(times=2)
def connect():
    raise ConnectionError("网络抖动")

try:
    connect()
except ConnectionError:
    print("重试后仍失败 -> 捕获")
```

**预期输出：**

```
重试后仍失败 -> 捕获
```

> 带参装饰器是「三层嵌套」：`retry(参数)` 返回 `deco`，`deco(函数)` 返回 `wrapper`。实战里重试网络请求、限流、缓存都是这个套路。推荐用 `functools.wraps` 替代手写 `__name__` 赋值。

## 9. 递归：函数自己调自己

```python
def factorial(n):
    if n <= 1:                  # 基线条件（必须能终止，否则栈溢出）
        return 1
    return n * factorial(n - 1)

print("递归 5! =", factorial(5))
```

**预期输出：**

```
递归 5! = 120
```

> 递归两大要素：**基线条件**（什么时停止）+ **递推关系**（把自己变小）。实战里树形 BOM（物料清单）展开、目录遍历、JSON 嵌套解析都是递归天然场景。
> ⚠️ Python 默认递归上限约 1000 层（`sys.getrecursionlimit()`），太深的递归会 `RecursionError`。能用循环就用循环。

## 10. 文档字符串与类型注解（专业写法）

```python
def add(x: int, y: str) -> str:
    """把两个数拼成字符串（示例：展示注解，非真实加法）"""
    return f"{x}只"

print("类型注解:", add(5, "静音球"))
print("__annotations__:", add.__annotations__)
```

**预期输出：**

```
类型注解: 5只
__annotations__: {'x': <class 'int'>, 'y': <class 'str'>, 'return': <class 'str'>}
```

> - **文档字符串（docstring）**：写 `"""..."""`，用 `help(函数)` 或 IDE 悬浮能看到说明。专业代码必须有。
> - **类型注解（type hints）**：`: int`、`: str`、`-> str` 只是「提示」，Python 运行时不强制检查（要强制需 `mypy`）。但能让 PyCharm 给你报错、让读代码的人秒懂参数类型。FDE 写给别人维护的代码必加。

## 小结

| 概念 | 一句话 | 实战场景 |
|---|---|---|
| 位置/关键字参数 | 按顺序 vs 按名字 | 参数多时全用关键字，防错 |
| 默认参数 | 调用不传就用默认值 | 配置项（折扣率、税率） |
| `*args`/`**kwargs` | 任意数量参数 | 通用工具函数 |
| 可变默认陷阱 | `[]`/`{}` 作默认值会串味 | 一律用 `None` 占位 |
| 作用域 | 局部改不动全局 | 用参数/返回值通信，少用 `global` |
| `lambda` | 一行匿名函数 | `sorted` 的 `key` |
| 闭包 | 函数记住出生环境 | 装饰器基础 |
| 装饰器 | 不改原函数加功能 | 计时/日志/重试/缓存 |
| 递归 | 自己调自己 | 树/BOM/目录遍历 |

## 练习

### 练习 1：写报价函数（考：默认参数 + 返回值）
**题目**：写一个 `quote(price, qty, discount=0.15, tax=0.13)` 函数，返回「含税总价」（折后价再加 13% 税），保留两位小数。调用 `quote(8.65, 1200)` 和 `quote(8.65, 1200, 0.20)`，打印结果。
<details><summary>答案与解析</summary>

```python
def quote(price, qty, discount=0.15, tax=0.13):
    after = price * qty * (1 - discount)
    return round(after * (1 + tax), 2)

print(quote(8.65, 1200))      # 10449.22
print(quote(8.65, 1200, 0.20)) # 9828.96
```

**解析**：`round(..., 2)` 保留两位小数。改折扣为 0.20 时税基变小，总价降低。
</details>

### 练习 2：修好可变默认参数
**题目**：下面函数第二次调用会串味，改成正确写法并验证 `add_item("A")` 和 `add_item("B")` 各自独立。
<details><summary>答案与解析</summary>

```python
def add_item(code, cart=None):
    if cart is None:
        cart = []
    cart.append(code)
    return cart

print(add_item("A"))   # ['A']
print(add_item("B"))   # ['B']
```
**解析**：用 `None` 占位，函数体内新建列表，每次调用互不影响。
</details>

### 练习 3：`lambda` 排序（考：key）
**题目**：有一个订单列表 `orders = [("O001", 1200), ("O002", 3400), ("O003", 800)]`，按金额**降序**打印订单号。
<details><summary>答案与解析</summary>

```python
orders = [("O001", 1200), ("O002", 3400), ("O003", 800)]
for oid, _ in sorted(orders, key=lambda x: x[1], reverse=True):
    print(oid)
# O002
# O001
# O003
```
**解析**：`key=lambda x: x[1]` 指定按元组第 2 个元素（金额）排序，`reverse=True` 降序。
</details>

### 练习 4：写一个计时装饰器（考：装饰器）
**题目**：写一个 `timer` 装饰器，在被装饰函数执行完后打印耗时（秒，保留 4 位小数）。
<details><summary>答案与解析</summary>

```python
import time

def timer(func):
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        r = func(*args, **kwargs)
        print(f"[{func.__name__}] 耗时 {time.perf_counter()-t0:.4f}s")
        return r
    return wrapper

@timer
def work():
    return sum(range(100000))

work()
```
**解析**：装饰器是「接收函数、返回函数」的函数；`*args, **kwargs` 保证能套任何函数。
</details>

### 练习 5：递归算 1+2+...+n（考：递归 + 基线）
**题目**：用递归实现 `sum_to(n)`，返回 1+2+...+n。验证 `sum_to(100)`。
<details><summary>答案与解析</summary>

```python
def sum_to(n):
    if n <= 0:
        return 0
    return n + sum_to(n - 1)

print(sum_to(100))   # 5050
```
**解析**：基线 `n<=0` 返回 0；递推 `n + sum_to(n-1)`。100 层远小于递归上限，安全。
</details>
