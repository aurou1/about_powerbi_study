# ch08 异常捕获与文件读写

> FDE 现场最怕的不是写不出代码，而是代码遇到脏数据崩了。客户给的 Excel 里某格是空的、日期格式乱七八糟、文件编码是 GBK——这些都会让脚本中途报错。这一章教你：**让程序在出错时优雅处理，而不是整个崩掉**。同时讲透文件的读写（CSV / JSON / 文本），这是数据流水线的入口。

---

## 学习目标

- 看懂常见异常（ValueError / KeyError / IndexError / FileNotFoundError ...）并针对性捕获
- 掌握 `try / except / else / finally` 四段结构
- 会自定义异常、`raise ... from` 异常链
- 熟练读写文本 / CSV / JSON 文件，理解 `with` 自动关文件
- 掌握 `pathlib` 路径处理与 `EAFP` 风格

## 1. 为什么需要异常处理

> 没有异常处理：`1/0` 一报错，整个脚本从中间断掉，前面算的、后面要写的全没了。
> 有异常处理：出错的部分单独处理，其余逻辑继续跑。

### 1.1 常见内置异常

```python
tests = [
    ("int('abc')", lambda: int("abc")),
    ("[1,2][5]", lambda: [1, 2][5]),
    ("{'a':1}['b']", lambda: {"a": 1}["b"]),
    ("1/0", lambda: 1 / 0),
    ("'2'+2", lambda: "2" + 2),
    ("None.attr", lambda: None.x),
]
for label, fn in tests:
    try:
        fn()
    except Exception as e:
        print(f"  {label:12s} -> {type(e).__name__}: {e}")
```

**预期输出：**

```
  int('abc')   -> ValueError: invalid literal for int() with base 10: 'abc'
  [1,2][5]     -> IndexError: list index out of range
  {'a':1}['b'] -> KeyError: 'b'
  1/0          -> ZeroDivisionError: division by zero
  '2'+2        -> TypeError: can only concatenate str (not "int") to str
  None.attr    -> AttributeError: 'NoneType' object has no attribute 'x'
```

> 这几个是数据脚本里最高频的异常，记住它们长什么样，报错时一眼定位。

## 2. `try / except / else / finally` 四段结构

```python
def safe_div(a, b):
    try:
        print("    try 计算")
        return a / b
    except ZeroDivisionError:
        print("    除数为 0，返回 None")
        return None
    else:
        print("    else：没出错才执行")     # 有 return 时不会走到这
    finally:
        print("    finally 总会执行")       # 收尾（关文件/释放连接）放这

print("safe_div(10,2):", safe_div(10, 2))
print("safe_div(10,0):", safe_div(10, 0))
```

**预期输出：**

```
    try 计算
    finally 总会执行
safe_div(10,2): 5.0
    try 计算
    除数为 0，返回 None
    finally 总会执行
safe_div(10,0): None
```

> - `except`：出错才执行
> - `else`：没出错才执行（放「依赖 try 成功」的逻辑）
> - `finally`：**无论出错与否都执行**——关文件、关数据库连接、解锁放这里最安全

## 3. 精准捕获 vs 全部捕获

```python
# ❌ 不推荐：裸 except 会连 Ctrl+C 都吞掉，调试时找不到错
try:
    ...
except:
    pass

# ✅ 推荐：捕获具体异常
try:
    price = float("8.65元".replace("元", ""))
except ValueError:
    price = 0.0
```

> **铁律**：`except` 后一定要写具体的异常类型，别用裸 `except:`。否则键盘中断、系统退出都被你吞了，debug 会疯。

## 4. 自定义异常 + 异常链

```python
class PriceError(ValueError):
    """价格非法时抛出"""
    pass

def set_price(p):
    if p <= 0:
        raise PriceError(f"价格必须为正数（收到 {p}）")
    return p

try:
    set_price(-5)
except PriceError as e:
    print("自定义异常:", e, "| price 属性:", e.args[0])
```

**预期输出：**

```
自定义异常: 价格必须为负数（收到 -5） | price 属性: -5
```

### 异常链（`raise ... from`）：保留根因

```python
try:
    try:
        raise ValueError("原始错误")
    except ValueError as e:
        raise RuntimeError("包装后向上抛") from e
except RuntimeError as e:
    print("异常链:", e, "| cause:", e.__cause__, "| context:", e.__context__)
```

**预期输出：**

```
异常链: 包装后向上抛 | cause: 原始错误 | context: 原始错误
```

> 现场脚本常要「把底层数据库错误包装成业务错误再抛出」，`raise NewError() from e` 能保留根因，排查时不断链。

## 5. 文本文件读写

```python
from pathlib import Path

p = Path("demo.txt")
p.write_text("静音球\n泳镜\n篮球\n", encoding="utf-8")     # 写（自动创建）
print("写入完成:", p.exists(), "| 字节:", p.stat().st_size)

text = p.read_text(encoding="utf-8")                     # 读
print("read_text:", repr(text))
print("splitlines:", text.splitlines())                 # 按行拆成列表

with p.open("a", encoding="utf-8") as f:                # 追加模式
    f.write("排球\n")
print("追加后:", p.read_text(encoding="utf-8").splitlines())
```

**预期输出：**

```
写入完成: True | 字节: 27
read_text: '静音球\n泳镜\n篮球\n'
splitlines: ['静音球', '泳镜', '篮球']
追加后: ['静音球', '泳镜', '篮球', '排球']
```

> **`with` 语句**：退出时自动关文件，比手动 `f.close()` 安全（忘了关会占着句柄）。**永远用 `with` 读写文件。**

## 6. 逐行处理大文件（省内存）

```python
with open("demo.txt", encoding="utf-8") as f:
    for i, line in enumerate(f, start=1):      # 一行一行读，不把整个文件载入内存
        if i <= 4:
            print(f"   第{i}行: {line.rstrip()}")
```

**预期输出：**

```
   第1行: 静音球
   第2行: 泳镜
   第3行: 篮球
   第4行: 排球
```

> 客户给的 CSV 几十万行，千万别 `readlines()` 全读进内存——逐行遍历才是正解（ch11 生成器会再深入）。

## 7. `pathlib`：现代化的路径处理

```python
from pathlib import Path

d = Path("py_tutorial_demo") / "sub"          # 路径拼接（跨平台）
print("目录列表:", [f.name for f in d.iterdir()])     # 列出内容
print("后缀:", Path("demo.txt").suffix, "| 名:", Path("demo.txt").stem)
print("父:", d.name)
```

**预期输出：**

```
目录列表: ['demo.txt', 'orders.csv', 'product.json']
后缀: .txt | 名: demo
父: sub
```

> `pathlib` 比老式 `os.path.join()` 更直观、跨平台（Windows `/` 和 Linux 都能用）。**新代码一律用 `pathlib`。**

## 8. JSON：和前端 / API 交换数据

```python
import json

data = {"code": "ST-BD-42", "price": 8.65, "tags": ["静音", "包布"]}
s = json.dumps(data, ensure_ascii=False)       # 序列化（ensure_ascii=False 保留中文）
back = json.loads(s)                            # 反序列化
print("JSON 往返相等:", back == data, "| price:", back["price"])
```

**预期输出：**

```
JSON 往返相等: True | price: 8.65
```

> FDE 调客户系统 API，返回几乎都是 JSON。`:` 后的 `ensure_ascii=False` 是中文不出乱码的关键。

## 9. CSV：读成字典（实战最常用）

```python
import csv
from io import StringIO

csv_text = "订单号,品类,金额\nO001,数码,1200\nO002,食品,340\n"
reader = csv.DictReader(StringIO(csv_text))    # 第一行当表头，每行是字典
rows = list(reader)
print("CSV DictReader:", rows)
```

**预期输出：**

```
CSV DictReader: [{'订单号': 'O001', '品类': '数码', '金额': '1200'}, {'订单号': 'O002', '品类': '食品', '金额': '340'}]
```

> 真实场景是 `with open("orders.csv", encoding="utf-8") as f: for row in csv.DictReader(f): ...`。金额读出来是字符串，记得 `float(row["金额"])`。ch12 用 pandas 读 CSV 更爽。

## 10. EAFP vs LBYL

> - **LBYL**（Look Before You Leap）：先判断再操作 `if os.path.exists(f): open(f)`
> - **EAFP**（Easier to Ask Forgiveness than Permission）：直接做，出错再捕获 `try: open(f) except FileNotFoundError`

```python
from pathlib import Path

# EAFP 风格（Python 推荐，更快更干净）
try:
    text = Path("maybe_not_exist.txt").read_text(encoding="utf-8")
except FileNotFoundError:
    print("文件不存在 -> FileNotFoundError True")
    text = ""

# 先判断存在（LBYL）
print("exists/mkdir:", Path("maybe_not_exist.txt").exists())
```

**预期输出：**

```
文件不存在 -> FileNotFoundError True
exists/mkdir: False
```

> Python 社区偏好 EAFP：少一次判断、代码更直。但要注意：**只对「预期会发生的异常」用 try，别把整段逻辑都包进去**。

---

## 小结

| 工具 | 用途 | 记住 |
|---|---|---|
| `try/except` | 捕获异常 | 写具体异常类型，别裸 `except` |
| `else` | 没出错才执行 | 放依赖成功的逻辑 |
| `finally` | 必执行收尾 | 关文件/关连接放这 |
| 自定义异常 | 业务错误 | 继承 `ValueError` 等 |
| `raise ... from` | 异常链 | 保留根因 |
| `with open()` | 读写文件 | 自动关文件，永远用它 |
| `pathlib` | 路径 | 跨平台，取代 os.path |
| `json` | 数据交换 | `ensure_ascii=False` 保中文 |
| EAFP | 风格 | 先试再补，比先判断快 |

## 练习

### 练习 1：安全转数字（考：异常捕获）
**题目**：写 `to_float(s, default=0.0)`，把字符串转 float；转不了（空、"N/A"、非数字）返回 default。
<details><summary>答案与解析</summary>

```python
def to_float(s, default=0.0):
    try:
        return float(str(s).strip())
    except (ValueError, TypeError):
        return default

print(to_float("8.65"))     # 8.65
print(to_float(""))        # 0.0
print(to_float("N/A"))     # 0.0
```
**解析**：`float()` 失败抛 `ValueError`，捕获后返回默认值。注意 `str(s).strip()` 防 None / 空格。
</details>

### 练习 2：`finally` 必执行（考：finally）
**题目**：写函数 `divide(a, b)`，无论是否出错都打印「计算结束」，出错返回 None。验证 `divide(10, 0)`。
<details><summary>答案与解析</summary>

```python
def divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return None
    finally:
        print("计算结束")

print(divide(10, 0))
```
**预期输出：**
```
计算结束
None
```
</details>

### 练习 3：逐行读大文件统计行数（考：with + 逐行）
**题目**：用 `with` 逐行读 `demo.txt`，统计非空行数。
<details><summary>答案与解析</summary>

```python
from pathlib import Path
count = 0
with Path("demo.txt").open(encoding="utf-8") as f:
    for line in f:
        if line.strip():
            count += 1
print(count)   # 4
```
**解析**：逐行遍历不占内存；`line.strip()` 过滤空行。
</details>

### 练习 4：JSON 中文往返（考：ensure_ascii）
**题目**：把一个含中文的字典 `{"品名": "包布静音球", "单价": 8.65}` 转 JSON 字符串再读回，要求中文不被转成 `\uXXXX`。
<details><summary>答案与解析</summary>

```python
import json
d = {"品名": "包布静音球", "单价": 8.65}
s = json.dumps(d, ensure_ascii=False)
print(s)                  # {"品名": "包布静音球", "单价": 8.65}
print(json.loads(s) == d) # True
```
**解析**：`ensure_ascii=False` 是关键，否则中文变成 `\u5305\u5e03...`。
</details>

### 练习 5：自定义异常（考：raise + 自定义类）
**题目**：定义 `QtyError`，当数量 ≤ 0 时抛出；写 `check_qty(q)` 触发它，并捕获打印消息。
<details><summary>答案与解析</summary>

```python
class QtyError(ValueError):
    pass

def check_qty(q):
    if q <= 0:
        raise QtyError(f"数量必须为正（收到 {q}）")
    return q

try:
    check_qty(-3)
except QtyError as e:
    print(e)
# 数量必须为正（收到 -3）
```
</details>
