## 1. 模块与 `import`

> 一个 `.py` 文件就是一个**模块**；一堆模块组成**包**（带 `__init__.py` 的文件夹）。`import` 就是把别人的代码拿来用。

```python
import math
import random
import statistics as stats

print("math.ceil(3.2) =", math.ceil(3.2), "| floor =", math.floor(3.2), "| sqrt(16) =", math.sqrt(16))
print("math.isclose(0.1+0.2, 0.3) =", math.isclose(0.1 + 0.2, 0.3))   # 浮点比较用 isclose！
```

**预期输出：**

```
math.ceil(3.2) = 4 | floor = 3 | sqrt(16) = 4.0
math.isclose(0.1+0.2, 0.3) = True
```

> ⚠️ **浮点别用 `==` 比较**，`0.1 + 0.2 == 0.3` 是 `False`。比较浮点一律用 `math.isclose()`。

### `from ... import`：只拿要用的名字

```python
from math import ceil, sqrt
print(ceil(2.1), sqrt(9))     # 2 3.0
```

> 两种写法都行。`import math` 好处是代码里能看到 `math.` 前缀，知道函数来自哪；`from math import ceil` 写法短但名字来源不清。大型项目推荐 `import math`。

## 2. `__name__ == "__main__"`：让文件既能跑又能被导入

```python
# demo.py
def main():
    print("我是被直接运行的")

if __name__ == "__main__":
    main()
    print("__name__ =", __name__)
```

**预期输出（直接运行该文件时）：**

```
我是被直接运行的
__name__ = __main__
```

> - 直接运行：`__name__` 是 `"__main__"`
> - 被 `import`：模块里 `__name__` 是它的文件名（不是 `__main__`），`if` 块不执行
>
> **作用**：把「测试代码 / 主流程」放进 `if __name__ == "__main__":`，这样文件既能当脚本跑，又能被别的模块安全 `import` 而不触发副作用。FDE 写的每个 `.py` 都应遵守这个约定。

## 3. `random`：可复现的随机

```python
import random

random.seed(42)                  # 设种子 → 随机序列可复现（调试/复现必备）
print("random.seed(42) sample:", random.sample(range(100), 5))

# 不调 seed 时，每次运行结果不同
random.seed(42)
print("随机可复现:", random.sample(range(100), 5))
```

**预期输出：**

```
random.seed(42) sample: [81, 14, 3, 94, 35]
随机可复现: [81, 14, 3, 94, 35]
```

> 抽样模拟订单、造测试数据时用 `seed(42)` 锁死，别人跑出来和你一样，排查才方便。

## 4. `statistics`：均值中位数标准差

```python
import statistics as stats

data = [1, 2, 3, 4]
print("statistics.mean:", stats.mean(data), "| median:", stats.median(data))
print("statistics.stdev:", round(stats.stdev(data), 3))
```

**预期输出：**

```
statistics.mean: 2.5 | median: 2.5
statistics.stdev: 1.291
```

> 小样本描述统计直接用标准库，不用上 pandas。注意 `stdev` 是样本标准差（除以 n-1）。

## 5. `itertools`：迭代器工具

```python
import itertools

print("combinations:", list(itertools.combinations("ABC", 2)))
print("chain:", list(itertools.chain([1, 2], [3, 4])))
```

**预期输出：**

```
combinations: [('A', 'B'), ('A', 'C'), ('B', 'C')]
chain: [1, 2, 3, 4]
```

> `combinations`（组合）、`chain`（拼接多个迭代器）在批量组合测试场景、合并多数据源时极好用。`groupby` 需先排序（见 ch11 生成器章节实战）。

## 6. `collections`：增强容器

```python
from collections import ChainMap, OrderedDict

# OrderedDict：记住插入顺序的字典（Python 3.7+ 普通 dict 也保序，但语义更明确）
od = OrderedDict([("b", 2), ("a", 1)])
print("OrderedDict:", dict(od))

# ChainMap：把多个字典当成一个查（优先级从左往右）
defaults = {"unit": "只", "tax": 0.13}
user = {"tax": 0.15}
cm = ChainMap(user, defaults)
print("ChainMap 查 tax:", cm["tax"], "| unit:", cm["unit"])
```

**预期输出：**

```
OrderedDict: {'b': 2, 'a': 1}
ChainMap 查 tax: 0.15 | unit: 只
```

> `Counter`（计数）、`defaultdict`（ch05 用过）、`deque`（双端队列）也是高频。`ChainMap` 适合「用户配置覆盖默认配置」的场景。

## 7. `re`：正则表达式

```python
import re

text = "料号 ST-BD-42 数量1200 料号 ST-BD-60"
print("findall 数字:", re.findall(r"\d+", text))
print("sub 替换:", re.sub(r"\d+", "N", "ST-BD-42"))        # 把数字换成 N

m = re.match(r"(ST)-(\w+)-(\d+)", "ST-BD-42")              # 分组提取
print("match/search:", bool(m), bool(re.search(r"42", text)))
print("分组:", m.groups(), "| group(1):", m.group(1))
```

**预期输出：**

```
findall 数字: ['42', '1200', '60']
sub 替换: ST-BD-N
match/search: True True
分组: ('ST', 'BD', '42') | group(1): ST
```

> 正则用来从乱七八糟的文本里**提取结构化字段**（料号、金额、日期）。`(\w+)` 捕获字母数字，`\d+` 匹配数字，`groups()` 拿所有分组。FDE 清洗客户脏数据必备。

## 8. `datetime`：日期计算

```python
from datetime import date, datetime, timedelta

# 两个日期相差天数
print("日期差:", (date(2026, 1, 1) - date(2025, 1, 1)).days, "天")   # 365

# 字符串 → 日期对象
dt = datetime.strptime("2026-09-04", "%Y-%m-%d")
print("strptime:", dt.date())
print("timedelta +30天:", (dt + timedelta(days=30)).date())          # 2026-10-04
print("周几:", dt.strftime("%A"), "| isoweekday:", dt.isoweekday())  # Friday | 5
```

**预期输出：**

```
日期差: 365 天
strptime: 2026-09-04
timedelta +30天: 2026-10-04
周几: Friday | isoweekday: 5
```

> `%Y` 年、`%m` 月、`%d` 日、`%A` 星期名。`timedelta` 做「加 N 天 / 算账期」超方便。注意 `datetime.now()` 每次跑都不同，教程里别依赖它的具体值。

## 9. `timeit`：给代码计时

```python
import timeit

t = timeit.timeit("sorted(x)", setup="x=list(range(100))", number=10000)
print(f"timeit 排序: {t:.4f}s / 10000次")
```

**预期输出（机器相关，仅数量级参考）：**

```
timeit 排序: 0.0018s / 10000次
```

> 想知道哪段快哪段慢，用 `timeit` 量化，别靠猜。注意绝对数值随机器变，看**相对大小**才有意义。

## 10. `os` / `pathlib` / `shutil`：系统交互

```python
import os
from pathlib import Path
import shutil

print("cpu 核数:", os.cpu_count())
print("当前目录名:", Path.cwd().name)
print("HOME 环境变量存在:", "HOME" in os.environ)
print("python 可执行文件存在:", shutil.which("python") is not None)
```

**预期输出（部分随环境）：**

```
cpu 核数: 12
当前目录名: python-tutorial
HOME 环境变量存在: True
python 可执行文件存在: True
```

> FDE 在客户机器上跑脚本，常用 `os` / `pathlib` 探查环境、找文件路径、判断依赖在不在。

## 11. 标准库 vs 第三方库 vs 虚拟环境

| 类型 | 例子 | 怎么装 | 说明 |
|---|---|---|---|
| 标准库 | `math` `json` `datetime` `re` `pathlib` | 不用装，Python 自带 | 开箱即用 |
| 第三方库 | `pandas` `matplotlib` `pymysql` | `pip install` | 社区维护 |
| 虚拟环境 | `venv` | `python -m venv xxx` | 隔离依赖 |

> 本教程的隔离环境路径：`C:\Users\HC\.workbuddy\binaries\python\envs\default\`。你用 PyCharm 时把解释器指到这里，就能复现本教程所有示例。第三方库装在 venv 里，**不要污染系统 Python**。

## 小结

- `import` 模块、`__name__ == "__main__"` 让文件可跑可导入
- 浮点比较用 `math.isclose`，别用 `==`

## 练习

### 练习 1：浮点比较（考：isclose）
**题目**：判断 `0.1 + 0.2` 与 `0.3` 是否「相等」（用 `math.isclose`）。
<details><summary>答案与解析</summary>

```python
import math
print(math.isclose(0.1 + 0.2, 0.3))   # True
```
**解析**：直接 `==` 会得到 `False`（浮点误差），用 `isclose` 才对。
</details>

### 练习 2：正则提取金额（考：re.findall）
**题目**：从字符串 `"订单 O001 金额1200元，O002 金额340元"` 中提取所有金额数字。
<details><summary>答案与解析</summary>

```python
import re
s = "订单 O001 金额1200元，O002 金额340元"
print(re.findall(r"\d+", s))   # ['1200', '340']
```
**解析**：`\d+` 匹配连续数字。注意返回的是字符串，要算数记得 `int()`。
</details>

### 练习 3：日期差（考：datetime）
**题目**：算 `2026-09-04` 到 `2026-10-01` 相差多少天。
<details><summary>答案与解析</summary>

```python
from datetime import date
print((date(2026,10,1) - date(2026,9,4)).days)   # 27
```
</details>

### 练习 4：可复现随机（考：seed）
**题目**：用 `seed(7)` 从 `range(50)` 抽 3 个数，再跑一次确认结果相同。
<details><summary>答案与解析</summary>

```python
import random
random.seed(7)
print(random.sample(range(50), 3))
random.seed(7)
print(random.sample(range(50), 3))   # 和上一行完全相同
```
</details>

### 练习 5：Counter 计数（考：collections）
**题目**：用 `collections.Counter` 统计 `['数码','食品','数码','美妆','食品','数码']` 各品类出现次数，并取出现最多的品类。
<details><summary>答案与解析</summary>

```python
from collections import Counter
c = Counter(['数码','食品','数码','美妆','食品','数码'])
print(c)                 # Counter({'数码': 3, '食品': 2, '美妆': 1})
print(c.most_common(1))  # [('数码', 3)]
```
</details>
